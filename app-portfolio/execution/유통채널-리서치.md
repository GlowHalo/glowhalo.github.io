# 앱 유통채널 리서치 — 2026-08-12

> 목적: 편입 앱 9개를 판매용으로 정비하기 위해, "어디에 올릴지" 전수 조사. 회장이 각 채널에 **최초 가입 1회**만 하면, 그 이후 등록·갱신은 시우(AI)가 API로 자동 진행하는 걸 목표로 함(`niche-templates/README.md` 원칙 6 — 채널의 "AI 직접 운영 가능 여부" 확인 필수). 이미 GlowHalo 1(A2 PromptDeck)이 검증해둔 채널(Gumroad·itch.io·Firefox Add-ons)은 재조사하지 않고 그대로 재활용.

## 채널별 상세

### 1. Google Play Console — Circle Heroes 최우선

- **비용**: $25 1회성 등록비, 연갱신 없음. 그 외엔 판매수익의 15%(연 $100만까지)/30% 수수료만.
- **사업자등록 불필요**: 개인(Personal) 계정으로 등록 가능, 한국은 연락처(공개 전화번호) 정도만 추가 요구.
- **회장이 직접 해야 하는 것(1회)**: 정부 신분증(운전면허/여권) 사진, 전화번호 SMS 인증, 주소 증빙, **Play Console 모바일 앱으로 기기 인증**(신규 개인 계정은 필수) — 전부 실물 신분증·회장 명의 휴대폰이 있어야 하는 단계라 AI가 대행 불가. 이후 결제 프로필에 국내 은행계좌 연결(월 정산, 최소 지급액 약 $100 상당).
- **그 이후 자동화**: Google Play Developer API — Google Cloud 서비스 계정을 만들어 Play Console에 권한만 부여하면(이것도 회장이 웹 UI에서 클릭 몇 번), 빌드 업로드·트랙 관리(내부/비공개/공개/프로덕션)·리스팅 텍스트/이미지 수정까지 시우가 전부 API로 처리 가능.
- **심사**: 신규 앱 1~3일(신규 계정은 최대 1~2주 걸릴 수 있음), 업데이트는 대개 몇 시간~1~3일.
- **주의**: 2026-08-31부터 신규 제출은 Android 16(API 36) 타겟 필수(연장 시 11/1까지), 가챠/확률형 아이템은 확률 고지가 앱 내에 필수(구글 정책, 한국 매출 1억원 미만은 법적 고지의무는 면제되나 구글 자체 정책은 별개로 적용됨) — Circle Heroes 정비 시 확률 고지 UI 반영 필요.

### 2. Amazon Appstore — 손쉬운 2순위

- **비용**: 무료.
- **사업자등록 불필요**: 개인 판매자 명시적으로 지원, 세금 인터뷰도 SSN/ITIN 없이 개인 신분으로 W-8BEN(비거주 외국인용) 작성.
- **회장 액션(1회)**: 신분증 앞뒤 사진 업로드(수 분 내 처리), 세금 인터뷰, 전화번호 2단계 인증 설정.
- **자동화**: App Submission API(REST) — CI/CD 파이프라인 전제로 설계돼 있어 APK 업로드·메타데이터·기기 타겟팅까지 전부 자동.
- **심사**: 보통 3~5일.
- **트래픽**: Fire 태블릿/Fire TV 약 2억 대 — 구글플레이보다 훨씬 작지만 경쟁도 적고 설정비용이 거의 0이라 "밑져야 본전"인 채널.

### 3. itch.io — 이미 있는 계정, Android 채널만 추가하면 됨

- A2 PromptDeck 작업에서 이미 계정(`tossneon0`)·API 키(`itchio_api_key`) 확보 완료, butler CLI 사용법도 검증됨.
- **막히는 지점(기존에 이미 확인됨)**: butler는 **업로드만** 자동화하고, **최초 프로젝트 페이지 생성은 API로 안 되고 회장이 `itch.io/game/new`에서 웹 폼으로 1회 직접 만들어야 함**(PromptDeck 때 실측 확인된 제약, 로그인 자동화도 하네스가 차단해서 우회 시도 안 하고 멈췄던 사례 있음).
- **이번에 새로 확인**: butler가 `.apk` 파일도 문제없이 업로드 지원(virtual folder로 처리) — Circle Heroes를 itch.io Android 채널로 올리는 것도 가능.
- **회장 액션(1회, Circle Heroes용 프로젝트 신규 생성)**: `itch.io/game/new`에서 제목/URL slug(`circle-heroes` 고정 권장)/분류(Game)/Kind(Downloadable, Android 태그)만 채우면 됨. 그 이후 버전 갱신은 `butler push circle-heroes.apk tossneon0/circle-heroes:android` 반복 실행으로 완전 자동.
- **트래픽**: PC/웹 인디게임 이용자 위주라 모바일 가챠게임 발견 트래픽은 낮음 — "무료 배포용 백업 채널"로 보는 게 정확.

### 4. Microsoft Store (PWA) — 2026년에 진입장벽이 사실상 사라짐

- **비용 변경 확인**: 기존엔 개인 $19 1회성 수수료가 있었으나, **2026년 새 온보딩 플로우부터 개인 계정 수수료가 완전히 폐지되어 무료**로 확인됨(Microsoft 공식 문서 2026-04/07 갱신).
- **사업자등록 불필요**: 개인용 계정이 정식으로 유지됨(취미/개인프로젝트 명시).
- **회장 액션(앱마다 1회)**: 신분증+실시간 셀카 인증(계정 최초 1회, 이후 앱마다 반복 아님), 앱 이름 예약과 최초 제출은 Partner Center 웹 UI에서 해야 함 — 웹앱(HTML/JS)을 그대로 올리는 게 아니라 **PWABuilder로 MSIX 패키지로 변환**해야 하는 게 실제 절차(URL만 등록하는 방식 아님).
- **그 이후 자동화**: Microsoft Store Submission API(Azure AD 앱 등록 후 OAuth) — 메타데이터·패키지 갱신은 API로 가능, 최초 앱 생성만 수동.
- **솔직한 평가**: 스토어 자체의 발견 트래픽은 거의 없다고 봐야 함(공식 문서도 "스토어 검색만으론 유의미한 신규 유입 기대 금지"에 가까운 뉘앙스) — 그래도 **설치 가능한 앱이라는 신뢰 신호 + 시작 메뉴 노출**을 무료로 얻는 것이므로, 비용 대비는 남는 장사. 앱 5개 정도를 한 번에 이 방식으로 등록해두는 걸 추천.

### 5. GitHub Marketplace — Code Review Board Action 전용

- **비용**: 무료, 심사 없음(요건만 맞으면 즉시 게시) — 요건: 공개 저장소, `action.yml`이 **저장소 루트**, 워크플로 파일 없음, **게시 계정에 2FA 켜져 있을 것**.
- **막히는 지점(이미 알고 있던 것 재확인)**: 지금 이 모노레포 구조로는 등록 불가 — `git subtree split`로 독립 저장소로 분리하고 `action.yml`을 루트로 옮겨야 함.
- **결제**: GitHub Marketplace는 **Action 자체의 유료 판매를 지원 안 함**(과금 인프라는 App 전용) — 지금처럼 무료로 올리고 Gumroad 라이선스 키로 Pro 잠금하는 기존 방식이 유일한 정답, 그대로 유지.
- **자동화**: 릴리스는 `git tag` + push로 대부분 자동인데, **GitHub App 토큰으로 릴리스하면 2FA 확인 단계 때문에 마켓플레이스에 새 버전이 자동 반영 안 되는 사례가 2026-05에도 재발 보고됨** — 개인 PAT(2FA 계정)로 릴리스하는 경로로 실제 검증 필요.
- **트래픽**: "AI PR 리뷰" 카테고리가 이미 경쟁이 치열해서(CodeRabbit 등) 주요 유입 채널은 아니고, 신뢰 신호 정도로 기대.

### 6. Gumroad — 이미 검증된 주력 채널, 웹앱에도 그대로 적용 가능

- A1(템플릿)·A2(PromptDeck)에서 이미 상품 생성·설명/커버/할인코드까지 API로 완전 자동화 검증 완료, 계좌 직접입금 정산도 확인됨.
- 웹앱(아기랑갈곳/체크노트/배당현황/KPC코칭챗봇)에 그대로 쓸 수 있는 패턴: PromptDeck과 동일하게 **"무료로 웹에 공개 + Gumroad 라이선스 키로 프리미엄 기능 잠금"** 모델. 백엔드 없이 Gumroad 공개 라이선스 검증 API(`POST /v2/licenses/verify`)를 클라이언트에서 직접 호출하면 됨.
- 대안: "완성 소스코드 판매"(Notion 템플릿처럼 코드 자체를 다운로드 상품으로 판매) — 이 경우 앱마다 어떤 모델(구독형 프리미엄 잠금 vs 소스코드 판매)을 쓸지는 제품 기획 단계에서 앱별로 정해야 함(다음 라운드 과제로 표시).

### 7. AppSumo — 유료 티어가 생긴 뒤에 고려

- **셀프서브 마켓플레이스**(승인 문턱 낮음, 실적 없어도 신청 가능)와 **Select**(엄격한 심사, MRR·트래픽 실적 요구 — 지금 우리 앱들은 통과 못 함) 두 트랙이 있음. **셀프서브만 현실적.**
- 무료 등록, 판매액의 대략 70%가 우리 몫(구체적 비율은 딜마다 협상 여지 있음), 정산은 Net-60(두 달 뒤 지급) — 느림.
- **전제조건**: "유료 요금제가 있는 실제 동작하는 웹앱"이어야 신청 가능 — 지금 9개 앱은 전부 무료라 유료 티어부터 만들어야 신청 자격이 생김.
- 자동화 불가(매번 웹폼으로 수동 제출) — 시우가 로그인해서 진행 가능(회장 재가입 불필요, 표준 자동화 계정으로 가능할 가능성 높음, 실제 가입 시 확인).

### 8. Product Hunt — 무료 트래픽 이벤트, 판매채널 아님

- 무료, "메이커(개인)" 계정 필요(회사 계정 불가) — 표준 자동화 계정으로 개설 가능.
- 판매 기능은 없음, 하루짜리 트래픽/투표 이벤트일 뿐이라 완성도 있는 앱을 "알리는 용도"로만.
- 2026년 트렌드는 "솔로/소규모 개발자에게 예전만큼 효과적이지 않다"는 평가가 많음 — 비용이 0이니 밑져야 본전이지만 우선순위는 낮게.
- 자동화 API 없음(제출은 상업적 용도 금지 명시) — 매번 수동.

### 9. Apple App Store — 지금은 보류

- **비용**: $99/년(개인 계정도 동일 요금, 매년 갱신).
- **사업자등록 불필요**: 개인(Individual) 계정 명시적으로 지원.
- **회장이 반드시 직접 해야 하는 것**: 신분증 사진 + **생체인증(Face ID/Touch ID)** 을 Apple Developer 앱으로 **회장 본인 아이폰/아이패드**에서 처리 — 이건 구조적으로 사람만 가능(기기·계정에 종속된 인증이라 AI가 절대 대행 불가).
- **빌드**: Mac을 직접 살 필요는 없음(Codemagic·GitHub Actions macOS 러너·Expo EAS 같은 클라우드 Mac CI로 빌드 가능) — 다만 **Circle Heroes는 현재 Android(Capacitor)만 빌드되고 iOS 타겟 자체가 아직 없음**, 여기서부터 새로 작업해야 함.
- **보류 이유**: 비용($99/년)·회장의 물리적 개입(아이폰 인증)·iOS 빌드 신규 작업까지 3중으로 진입장벽이 높음 — Circle Heroes가 Android/Amazon/itch.io에서 실제 반응을 좀 확인한 뒤에 투자할지 판단하는 게 합리적.

### 10. Samsung Galaxy Store — 사실상 차단

- 등록 자체는 무료지만, **Commercial Seller 자격에 D-U-N-S 넘버가 필요하고, 한국에서 D-U-N-S 발급은 사업자등록증(최근 90일 이내 발급분)이 있어야 가능** — 회장이 사업자등록을 못 내는 현재 제약과 정면으로 충돌.
- 삼성 셀러 포털에 "Contact us"로 개인 예외를 요청할 수는 있으나 결과 불확실.
- **결론**: 지금 단계에선 시도하지 않고 보류. 사업자등록 제약이 풀리면 그때 재검토(다른 채널처럼 "파킹" 상태로 기록).

## 다음 단계 (회장 확인 필요한 부분만)

1. **Google Play Console 가입** — https://play.google.com/console/signup ($25, 신용/체크카드 필요) → 신분증·전화·주소 인증 + Play Console 앱으로 기기 인증까지 진행해주시면, 이후 API 연동(서비스 계정 발급·권한 부여)은 시우가 안내해드리는 대로 클릭 몇 번만 하시면 완료됩니다.
2. **Amazon Appstore 개발자 등록** — https://developer.amazon.com/apps-and-games (무료) → 신분증 업로드 + 세금 인터뷰(W-8BEN, 개인 자격으로 가능).
3. **itch.io에 Circle Heroes 프로젝트 페이지 1회 생성** — https://itch.io/game/new (계정은 이미 있음, `tossneon0`으로 로그인) → 제목/슬러그(`circle-heroes` 권장)만 채우면 이후는 시우가 자동 갱신.
4. **Microsoft Partner Center 개인 계정 가입** — https://partner.microsoft.com/dashboard/registration (2026년부터 무료) → 신분증+셀카 인증.
