## ⚠️ 확인 필요(회장 대기) — 나다컴퍼니1 A5 · 나다컴퍼니9 E2와의 관계

나다컴퍼니1(정연)의 A5(니치 유료 뉴스레터, 컨셉명 "The Independent Board")가 **이미 콘텐츠·가격·창간호 초안까지 완성돼 있고**, 결제 수단으로 **스티비(Stibee)**를 쓰기로 검증까지 끝난 상태였다([company1/candidates.md](../company1/candidates.md) A5 항목, [company1/execution/A5-newsletter.md](../company1/execution/A5-newsletter.md)). 게다가 나다컴퍼니9(다연)의 Round 1 서칭에서도 독립적으로 "E2 니치 AI 뉴스레터"가 Beehiiv 전제로 Tier A 확정됐다([company9/candidates.md](../company9/candidates.md) E2). 세 갈래(A5/E2/나다컴퍼니10)가 사실상 같은 방향을 가리키고 있다.

**2026-08-12 은우 1차 조사 완료** — A5 콘텐츠 검토 + Beehiiv 공식 문서 조사를 마치고 3개 옵션(그대로 승계/병행/무료로 먼저 승계 후 유료화는 나중)을 정리해 [`candidates.md`](candidates.md)에 올렸다. **결제(Beehiiv Scale 플랜 $43/월)가 걸린 판단이라 임의로 확정하지 않고 회장 확인 대기 중.**

## Beehiiv를 쓰는 이유 (회장 지정) — 자동화 범위 재검증 완료(2026-08-12)

Beehiiv는 뉴스레터 발행·구독관리·유료구독·광고 네트워크까지 통합 지원하는 플랫폼. 은우가 공식 문서로 확인한 핵심 사실은 [`candidates.md`](candidates.md#beehiiv-자동화-범위-조사-2026-08-12-은우-공식-문서-기준) 참고 — 요약: (1) API는 공식 지원하나 "발행(Create Post) API가 정확히 몇 플랜부터 되는지"는 문서 상충으로 미확정, (2) 결제는 개인 Stripe 계정 연결 방식으로 계좌 직접입금이라 원칙 5에 부합, (3) **유료구독 기능은 무료 플랜에 없고 Scale 플랜($43/월)부터 활성화** — 스티비(플랫폼 자체 무료)와 다른 새로운 고정비 변수.
