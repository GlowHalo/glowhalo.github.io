## ⚠️ 확인 필요 — 나다컴퍼니1 A5와의 관계

나다컴퍼니1(정연)의 A5(니치 유료 뉴스레터, 컨셉명 "The Independent Board")가 **이미 콘텐츠·가격·창간호 초안까지 완성돼 있고**, 결제 수단으로 **스티비(Stibee)**를 쓰기로 검증까지 끝난 상태였다([company1/candidates.md](../company1/candidates.md) A5 항목, [company1/execution/A5-newsletter.md](../company1/execution/A5-newsletter.md)). 회장이 이번에 별도로 나다컴퍼니10을 만들면서 플랫폼을 **Beehiiv**로 지정했는데, 이게 (a) A5를 대체하는 것인지(플랫폼만 스티비→Beehiiv로 교체), (b) A5와 무관한 새 뉴스레터 사업인지 이 시점엔 불명확하다.

**은우의 첫 확인 작업**: A5 자료를 검토해서 Beehiiv로 그대로 이어받을 수 있는지 판단하고(콘텐츠·컨셉은 재사용 가능할 가능성 높음, 결제 플랫폼만 교체), 판단이 서면 회장에게 "A5를 나다컴퍼니10으로 흡수해도 될지" 확인받는다 — 애매하면 임의로 정하지 말고 회장에게 물어본다(CLAUDE.md 자율성 원칙 2번).

## Beehiiv를 쓰는 이유 (회장 지정)

Beehiiv는 뉴스레터 발행·구독관리·유료구독·광고 네트워크까지 통합 지원하는 플랫폼으로, 스티비 대비 해외 크리에이터 이코노미 생태계에 가깝고 API 지원 범위도 넓다고 알려져 있다 — 정확한 자동화 범위(리스트 관리, 발행, 유료구독 처리가 API로 되는지)는 은우가 공식 문서로 재검증해야 한다.
