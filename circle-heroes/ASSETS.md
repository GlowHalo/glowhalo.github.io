# Circle Heroes — 이미지 에셋 규격서 (Rev.B — 애니메이션풍)

주인님이 이미지 파일을 제작·제공하면 Claude가 이 규격에 맞춰 게임에 조립한다.

> **Rev.B 변경사항**: 아트 방향이 도트(픽셀아트)에서 **애니메이션풍 일러스트**로 변경됨에 따라 전면 개정.
> 도트는 작게 그려 확대하는 방식이었지만, 애니풍은 **크게 그려서 게임이 축소**하는 방식이다.
> 원본이 게임 표시 크기의 2배 이상이어야 고해상도 폰에서 또렷하다.

## 공통 규칙

- **캐릭터/아이콘**: PNG + 투명배경. **배경 그림**: PNG 또는 JPG 무관.
- 아래 표의 크기 **이상**으로 제작 (더 커도 됨 — 축소는 제가 처리. 작으면 흐릿해져서 못 씀).
- 캐릭터는 **오른쪽을 바라보는 방향** 기준 (왼쪽 보기는 코드에서 반전).
- 광원 왼쪽 위 통일. **그림체(선 굵기·채색 톤·눈 스타일)를 전 캐릭터 동일하게 유지** — AI 생성 시 스타일 프롬프트를 고정해두는 걸 추천.
- 등급 테두리, 별점, 번쩍임/홀로그램 연출, NEW! 배지 등은 Claude가 코드로 입힘 — **그림만** 주면 됨.
- 전달: 채팅에 파일 첨부 + 어느 슬롯의 누구인지 한 줄. 저장 경로·파일명은 Claude가 처리.

## 파일 이름 규칙 (Claude가 저장할 때 사용)

```
assets/sprites/heroes/<영웅id>/battle.png   ← 슬롯1
assets/sprites/heroes/<영웅id>/card.png     ← 슬롯2
assets/sprites/heroes/<영웅id>/icon.png     ← 슬롯3
assets/sprites/enemies/<몬스터id>.png       ← 슬롯4·5
assets/sprites/items/<장비id>.png           ← 슬롯6
assets/sprites/ui/<이름>.png                ← 슬롯7·8·11
assets/backgrounds/<장소/테마>.png           ← 슬롯9·10
```

영웅 id는 Notion 마스터데이터의 `id` 컬럼과 일치 (예: `mage_star_001`).

## 지금 당장 필요한 것 (프로토타입 교체분)

1. 영웅 전투 캐릭터 3종 — 이그니스(불 탱커)·실피(바람 궁수)·클라라(빛 사제) — 512×512 ×3
2. 일반 몬스터 1종 (슬라임 또는 고블린) — 512×512
3. 보스 1종 (슬라임 킹 또는 드래곤) — 768×768

이 5장이면 전투 화면이 목업처럼 보이기 시작한다. 캐릭터 콘셉트는 그림에 맞춰 마스터데이터를 고치면 되므로 자유롭게 제작해도 됨.

> **주의**: 위 "파일 이름 규칙"의 `assets/sprites/...` 중첩 경로는 초기 설계 당시 문서다 — 실제로는
> `vite.config.ts`의 `SERVED_ASSET_DIRS`가 `assets/{characters,monsters,backgrounds,icons,effects,cards-webp}/`
> 를 평평하게 서빙하는 방식으로 굳어졌다(2026-07-25 진행 중 변경, 이 문서 미반영). 아래 스테이지
> 지역 전환 목록은 **실제 현재 규칙**(평평한 폴더 + 파일명만)을 따른다.

## 영웅 공격 포즈 일러스트 (2026-07-29, "공격모션 B안" 채택 — 진행 확정)

`PROMPTS.md`의 공격 모션 4안 비교에서 **B안(포즈 추가 일러스트)으로 진행 확정**. 코드 쪽 하이브리드
배선은 이미 끝났다(`BattleScene.ts` — 공격 타이밍에 `<영웅id>-attack.png`가 있으면 잠깐 그걸로
바꿔치기하고 없으면 지금처럼 정지 그림 스쿼시&스트레치만 그대로 유지). **영웅별로 하나씩 도착하는
대로 순서 상관없이 바로 활성화**되니, 71종을 한 번에 몰아서 만들 필요 없다.

- **파일명**: `assets/characters/<영웅id>-attack.png` (기존 `<영웅id>.png` 정지 초상화와 같은 폴더)
- **크기**: 512×512 (기존 정지 초상화와 동일 규격)
- **포즈**: 무기를 휘두르거나 찌르는 순간처럼 "타격 임팩트 정점" 한 컷. 정지 초상화와 같은 캐릭터
  디자인·색·비율 유지(같은 그림체여야 두 이미지 전환이 어색하지 않음), 오른쪽을 보는 방향 기준
  (왼쪽 보기 예외는 코드가 자동 반전 처리하므로 그림은 항상 오른쪽 기준으로 제작)
- **대상**: 영웅 71종 전원(`data/master/heroes.json`의 `id` 컬럼 기준). 우선순위 필요하면 등급
  높은 순(UR→SSR→SR)이나 인기 영웅부터 먼저 요청하는 것도 가능

## UI 아이콘/버튼 (2026-07-29, 전수조사 + 신규 백로그)

캐릭터/배경 말고 **화면 자체를 이루는 자잘한 아이콘·버튼**을 코드 세션이 전수조사했다. 기존 산출물
5개 중 2개(버튼 배경 2종)는 실제로 코드에 연결까지 마쳤고, 나머지는 지금 이모지(⚔️🛡️✨🔒 등)로
때워둔 상태라 실제 그림으로 바꾸면 바로 체감 품질이 오른다. 전부 `assets/icons/`에 파일명만
맞춰 넣으면 코드 수정 없이 바로 적용되게(또는 최소 수정만 필요하게) 준비해뒀다.

### 이미 반영 완료 (추가 작업 불필요)
- `btn-primary-bg.png`(금색 캡슐 버튼), `btn-danger-bg.png`(적색 캡슐 버튼) — 이번에 실제로
  9-slice로 코드에 연결함. 모든 주요 CTA 버튼과 "세이브 초기화" 버튼에 적용 완료.

### 재작업 필요 (파일은 있지만 모양이 용도에 안 맞음)
- `chip-bg.png` — 지금 파일은 동그란 3D 렌즈/조약돌 모양인데, 실제 쓰이는 곳(하단 서브메뉴 칩)은
  버튼처럼 **캔버스 좌우 끝까지 꽉 찬 가로 캡슐** 모양이어야 9-slice가 가능하다. `btn-primary-bg.png`
  와 같은 구도(가로 캡슐, 좌우 끝까지 채움)로 다시 제작해주면 바로 연결 가능. 640×192 사이즈는 유지.
- `icon-close.png`, `icon-speed.png` — 파일 자체는 정상(투명배경 확인함)이지만, 코드에서 텍스트
  버튼("닫기", "▶ x2")을 이미지+숫자 조합으로 바꾸는 별도 작업이 필요해서 이번엔 보류. 원하시면
  다음에 바로 붙일 수 있음.
