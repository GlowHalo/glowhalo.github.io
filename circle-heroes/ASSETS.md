# Circle Heroes — 이미지 에셋 규격서 (Rev.B — 애니메이션풍)

주인님이 이미지 파일을 제작·제공하면 Claude가 이 규격에 맞춰 게임에 조립한다.

> **Rev.B 변경사항**: 아트 방향이 도트(픽셀아트)에서 **애니메이션풍 일러스트**로 변경됨에 따라 전면 개정.
> 도트는 작게 그려 확대하는 방식이었지만, 애니풍은 **크게 그려서 게임이 축소**하는 방식이다.
> 원본이 게임 표시 크기의 2배 이상이어야 고해상도 폰에서 또렷하다.

## 공통 규칙

- **캐릭터/아이콘**: PNG + 투명배경. **배경 그림**: PNG 또는 JPG 무관.
- 아래 표의 크기 **이상**으로 제작 (더 커도 됨 — 축소는 제가 처리. 작으면 흐릿해져서 못 씀).
- 캐릭터는 **오른쪽을 바라보는 방향** 기준 (왼쪽 보기는 코드에서 반전).
- 광원 왼쪽 위 통일. **그림체(선 굵기·채색 톤·눈 스타일)를 전 캐릭터 동일하게 유지** — AI 생성 시 스타일 프롬프트를 고정해두는 걸 추천.
- 등급 테두리, 별점, 번쩍임/홀로그램 연출, NEW! 배지 등은 Claude가 코드로 입힘 — **그림만** 주면 됨.
- 전달: 채팅에 파일 첨부 + 어느 슬롯의 누구인지 한 줄. 저장 경로·파일명은 Claude가 처리.

## 파일 이름 규칙 (Claude가 저장할 때 사용)

```
assets/sprites/heroes/<영웅id>/battle.png   ← 슬롯1
assets/sprites/heroes/<영웅id>/card.png     ← 슬롯2
assets/sprites/heroes/<영웅id>/icon.png     ← 슬롯3
assets/sprites/enemies/<몬스터id>.png       ← 슬롯4·5
assets/sprites/items/<장비id>.png           ← 슬롯6
assets/sprites/ui/<이름>.png                ← 슬롯7·8·11
assets/backgrounds/<장소/테마>.png           ← 슬롯9·10
```

영웅 id는 Notion 마스터데이터의 `id` 컬럼과 일치 (예: `mage_star_001`).

## 지금 당장 필요한 것 (프로토타입 교체분)

1. 영웅 전투 캐릭터 3종 — 이그니스(불꽃 탱커)·실피(바람 궁수)·클라라(빛 사제) — 512×512 ×3
2. 일반 몬스터 1종 (슬라임 또는 고블린) — 512×512
3. 보스 1종 (슬라임 킹 또는 드래곤) — 768×768

이 5장이면 전투 화면이 목업처럼 보이기 시작한다. 캐릭터 콘셉트는 그림에 맞춰 마스터데이터를 고치면 되므로 자유롭게 제작해도 됨.
