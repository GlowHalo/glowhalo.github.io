# Circle Heroes — 이미지 에셋 규격서

주인님이 이미지 파일을 제작·제공하면 Claude가 이 규격에 맞춰 게임에 조립한다.
모든 값은 **원본 도트 해상도** 기준. 업스케일 없이 원본 그대로 주면 게임 쪽에서 정수배 확대(nearest neighbor)로 또렷하게 표시한다.

## 공통 규칙

- **포맷**: PNG, 배경 투명(알파 채널). JPG 금지(배경이 붙어버림).
- **해상도**: 아래 표의 원본 크기 그대로. 이미 확대해서 그렸다면 정수배(×2, ×4...)면 OK — 알려만 주면 처리함.
- **방향**: 캐릭터류는 **오른쪽을 바라보는 방향** 기준 (아군이 왼쪽에서 오른쪽으로 공격). 왼쪽 보기는 코드에서 반전 처리.
- **광원**: 왼쪽 위에서 비추는 기준으로 통일 (그림자 우하단).
- **여백**: 캔버스 가장자리에 1~2px 여백 (발밑 그림자 공간 포함).
- **전달 방법**: 채팅에 파일 첨부 + "어떤 슬롯의 누구인지"만 알려주면 됨. 이름 규칙(아래)에 맞춰 저장은 Claude가 처리.

|---|---|---|---|---|

## 파일 이름 규칙 (Claude가 저장할 때 사용)

```
assets/sprites/heroes/<영웅id>/battle.png   ← 슬롯1
assets/sprites/heroes/<영웅id>/card.png     ← 슬롯2
assets/sprites/heroes/<영웅id>/icon.png     ← 슬롯3
assets/sprites/enemies/<몬스터id>.png       ← 슬롯4·5
assets/sprites/items/<장비id>.png           ← 슬롯6
assets/sprites/ui/<이름>.png                ← 슬롯7·8·10
assets/backgrounds/<스테이지테마>.png        ← 슬롯9
```

영웅 id는 Notion 마스터데이터의 `id` 컬럼과 일치시킨다 (예: `succubus_dark_001`).

## 제작 우선순위 (추천)

1. **영웅 3~5종의 전투 스프라이트(32×48)** — 이것만 있으면 프로토타입 화면이 확 달라짐
2. 같은 영웅들의 카드 일러스트(64×96) — 가챠 연출용
3. 슬라임 등 몬스터 2~3종(32×48)
4. 재화·장비 아이콘
5. 배경, 로고, 앱 아이콘
