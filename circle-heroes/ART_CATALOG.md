# Circle Heroes — 아트 리소스 마스터 카탈로그 (2026-08-03)

**목적**: "아트 생성 툴을 교체해서 전체 리소스를 다시 뽑을 수도 있다"는 계획에 대비해, 지금
쓰이는 모든 그림 자산을 **규격 + 프롬프트(또는 재현 정보) + 쓰이는 곳 + 현재 상태** 한 곳에서
확인할 수 있게 정리한 인덱스다. 이미 완료된 자산도 재생성 대비 목록에 포함한다.

이 문서는 **인덱스**다 — 각 그림의 세부 제작 히스토리(반려/재작업 사유 등)는 `ASSETS.md`(결정
기록)와 `PROMPTS.md`(실제 프롬프트 원문)에 있으므로 중복 기재하지 않고 해당 위치를 가리킨다.
새 카테고리(탑/아레나/요일던전 배경·몬스터)처럼 아직 다른 문서에 프롬프트가 없는 것만 여기서
바로 방향을 제시한다.

## 0. 공통 스타일 블록 (모든 캐릭터 프롬프트 앞에 고정)

`PROMPTS.md` "STYLE BLOCK"(약 1470번째 줄) 원문:

```
Vibrant anime-style mobile gacha RPG character art. Clean bold dark outlines,
glossy cel shading with soft gradients, chibi-heroic 3-head proportions,
rich saturated colors, subtle rim lighting from the upper left.
Match the exact art style of the attached reference image: same line weight,
same eye style, same color saturation, same level of detail.
```

새 생성 툴로 바꾸더라도 이 스타일 블록(또는 기준 이미지 1~2장 첨부)만 유지하면 71종+몬스터가
지금과 같은 톤으로 나온다. 몬스터/배경도 같은 선굵기·채색 톤을 맞추는 걸 권장(`ASSETS.md` 공통
규칙 참고).

전체 슬롯별 정식 규격표는 `ASSETS.md` "슬롯별 규격" 참고. 여기서는 아래 표에서 바로 쓰는 것만 요약:

| 슬롯 | 크기(px) | 비고 |

## 7. 갱신 방법

새 카테고리(영웅/몬스터/배경 등)가 추가되거나 마스터데이터가 바뀌면:
1. 영웅 표(§2)는 `data/master/heroes.json`에서 `id/nameKr/grade/faction/heroClass/notes`
   6개 필드만 등급→진영 순 정렬해 재생성(수작업 편집 대신 스크립트로 뽑을 것 — 손으로 옮기면
   오타/누락 위험).
2. 몬스터/배경(§3~4)은 `ASSETS.md`의 각 절이 1차 기록이므로, 새 항목이 그쪽에 추가되면 이
   문서 표에도 파일명·상태만 동기화.
3. UI/사운드(§5~6)는 `ASSETS.md`/`CREDITS.md`가 원본이라 이 문서는 요약+상태만 유지 —
   전면 재작성하지 않는다(중복 유지보수 방지).
