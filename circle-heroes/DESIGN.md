# Circle Heroes — 게임 설계 확정안

주인님과의 논의로 확정된 게임 설계. 변경 시 이 문서를 갱신한다.

## 코어 확정 사항

| 항목 | 확정 내용 |
|---|---|
| 장르 | 방치형 수집 RPG. 자동전투, 환생(프레스티지) 없음 |
| 지향 레퍼런스 | **마이티 아레나·AFK아레나 계열** — 소수 정예(5인) + 크고 개성 있는 캐릭터. 대군 스웜 아님(초기 오해 정정). 유닛 머리 위 속성+수치 배지, 큼직한 데미지 숫자, 회화풍 배경 문법 채택 |
| 화면 | **세로** (420×740 논리 해상도) |
| 아트 | 애니메이션풍 일러스트 (ASSETS.md Rev.B). 이미지 제작=주인님, 조립=Claude |
| 덱 | **5명** 동시 출전 |
| 가챠 | 보석 소환: 1회 10💎 / 10연 90💎 / **천장 50회** (추후 조정 가능) |
| 방치 보상 | **접속 종료 중에도 적립** (분당 스테이지×5G, 최대 240시간 — 비율 추후 조정) |
| 영웅 획득 | 가챠 + 미션/스테이지 해금 혼합 |
| 육성 | 레벨업 + 장비 강화 + 각성(동일 등급 영웅 재료 합성) + 진영 시너지. 스킬트리 없음 |
| 히든 | Unknown 등급 히든 영웅 + 전용 히든 장비 (연출 등급 체계는 아이디어 단계 — 추후 재점검) |
| 장비 뽑기 | **도입 안 함** (장비는 파밍으로만) |
| 편성 | 뽑기만으로는 전투 합류 안 됨 — **편성(최대 5)해야 출전**. 영웅 탭에서 관리 |
| 무료 상자 | 일일 보석 100개 |
| 플로팅 | 우상단 **가로형** (이벤트·우편·설정 + 접기) |
| 레벨업 | 골드 소비, 레벨당 능력치 +10%, 비용 40G에서 15%씩 증가 (모두 추후 조정 가능) |
| 성장 양축 | **레벨업(골드) + 수집→합성(중복 영웅) 대등** — 마이티식. 같은 영웅을 모아 성급 상승 |
| 보유창 UI | 진영(속성)별 탭 + 카드에 수집 카운트(예: 4/4) 표시 — 마이티식 |

## 메뉴 구조 (Rev.C 확정)

하단 5탭, 전투 중앙 강조. 각 탭은 "메인 뷰 + 하단 보조바 서브메뉴(P2)" 구조.

```
[영웅]        [소환]         [전투★중앙]    [상점]        [임무]
 보유·편성(M)   영웅소환(M)     무한 스테이지(M)  골드상점(M)    일일임무(M)
 장비(가방·강화) 천장진행·확률표  요일던전         보석상점       주간임무
 승급(각성합성)                무한의탑         일일무료상자    업적
 도감                        아레나(AI덱)
 (진영시너지·추후)            (보스러시·추후)
```

- **우측 상단 플로팅** (원신식): 🎁이벤트 · 📮우편함 · ⚙설정(+백업) — 새 소식 빨간점 배지, 접기 토글
- 아레나: AI 임의 덱 상대. 추후 실유저 덱 연동 확장 여지
- 서브메뉴 바는 5탭 전체에 일관 적용
