# 오늘의 코칭 — Microsoft Store 리스팅 텍스트 (한국어)

## 앱 이름 (우선순위)
1. `오늘의 코칭`
2. (중복 시) `오늘의 코칭 by GlowHalo`
3. (그래도 중복 시) `KPC 셀프코칭 - GlowHalo`

## 가격
2,000원 ~ 4,000원 승인 범위 내 권장가: **3,900원**
(무료 체험 없음 — 웹 버전이 이미 무료라 별도 체험판 불필요. 스토어 설치판만 유료.)

가격을 mindmap(2,900원)보다 상단 쪽으로 권장하는 이유: 마인드맵은 범용 생산성 도구라 가벼운
가격이 맞지만, 이 앱은 ICF/KCA 코칭 역량 기반의 다단계(합의→경청→질문→알아차림→실행) 시스템
프롬프트로 설계된 특화 대화 상대라 체감 가치가 더 높다고 판단. 승인 범위(2,000~4,000원) 안에서
회장 판단으로 2,900원으로 낮춰도 무방.

## 연령 등급
전체 이용가(폭력/도박/성인 콘텐츠 없음, 셀프코칭 대화 도구) — IARC 설문에서 전부 "해당 없음"으로 답변.
단, 설명에 "심리치료 대체 목적이 아니며 임상적 위기 신호 시 전문가 연결을 권합니다"라는 면책 문구를 포함.

## 설명 (Description, 그대로 붙여넣기)

조언 대신 질문으로, 스스로 답을 찾게 돕는 셀프코칭 대화 상대예요. 한국코치협회(KCA)/국제코칭연맹(ICF)
핵심역량을 따르는 대화 구조로 설계됐어요.

주요 기능
- 합의 → 경청·반영 → 강력한 질문 → 알아차림 → 실행 설계, 5단계로 자연스럽게 이어지는 대화
- 매 대화 끝에는 오늘 다룬 주제·알아차린 것·이번 주 실행 약속을 담은 세션 요약 카드 제공
- 본인의 Gemini API 키를 넣으면 무제한으로, 키가 없어도 기기당 3세션(요약 카드가 나올 때까지)
  무료로 체험할 수 있어요
- 설치하면 오프라인에서도 앱 화면이 바로 열려요(대화 자체는 인터넷 연결이 필요해요)

바쁜 하루 중 잠깐 멈춰서 스스로를 돌아보고 싶을 때, 출퇴근길이나 잠들기 전 가볍게 써보기 좋은
도구예요. 대화 내용은 서버에 저장되지 않고, 이 기기(브라우저)에만 남아요.

이 앱은 심리치료나 상담을 대체하지 않아요. 우울, 자해, 트라우마 등 어려움을 겪고 계시다면
전문가(정신건강의학과, 상담센터, 자살예방상담전화 1393) 도움을 받으시길 권해요.
