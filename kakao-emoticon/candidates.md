## 향후 확장 후보

### OGQ마켓 — ❌ 검증 결과 부적합 (2026-08-15)

웹서치로 실제 심사 기준 확인: **"생성형 AI를 통해 제작된 스티커는 심사 반려됩니다"**가 공식 가이드에 명시돼 있음([OGQ 크리에이터 스튜디오 가이드](https://creators.ogq.me/guides/contents/sticker)). 우리 파이프라인(Leonardo AI 생성) 전체가 이 조건에 걸려 등록 자체가 불가능 — AI 생성 사실을 숨기는 건 정직성 원칙 위반이라 시도하지 않는다. **후보에서 제외.**

### LINE 스티커샵(Creators Market) — ✅ 유망, 착수 가능 (2026-08-15)

웹서치로 실제 규격·정책 확인 완료:
- **AI 생성 콘텐츠 허용** — 단, 제작 시 "AI 사용" 표시를 해야 하고 구매 화면에 자동으로 AI 사용 여부가 노출됨(투명성 요구, 숨기는 게 아니라 밝히는 조건이라 문제없음). 제3자 저작권물이나 유명 캐릭터를 모방한 AI 생성물은 금지 — 우리 캐릭터(일잘봇·새침냥이)는 독자 디자인이라 해당 없음. ([LINE Creators Market 가이드라인](https://creator.line.me/en/guideline/sticker/))
- **규격**: 스티커 이미지 370×320px 투명 PNG(가로세로 짝수, 72dpi 이상, RGB) · 세트 구성 8/16/24/32/40종 중 선택(**우리는 이미 32종 완성돼 있어 딱 맞음**) · 메인 이미지 240×240px(스토어 커버) · 탭 이미지 96×74px(채팅창 입력 트레이 아이콘) · 여백 권장 10px. ([공식 PDF](https://static.line.naver.jp/line_creators_market/img/CMS/pdf/SalesManual_EN_1.5.0.pdf))
- **우리 자산 재활용성 높음**: 기존 360×360 정사각 아트워크(일잘봇·새침냥이 각 32종)를 370×320 캔버스에 리사이즈+중앙배치만 하면 됨 — 새 이미지 생성 없이 후처리만으로 제작 가능.
- **계정 가입은 회장 승인 필요(2026-08-11 보류 원칙)** — 예슬이 먼저 가입 시도하지 않고, 자산만 제작해두고 승인 후 회장이 가입하거나 예슬이 승인받고 진행.
- 진행 상황: [`execution/A5-line-sticker-shop.md`](execution/A5-line-sticker-shop.md)

## A3-2 (가칭) — 움직이는 이모티콘 확장 리서치 (2026-08-12, 착수는 정지형 A3 승인 확인 후)

정지형 32종 심사 결과 대기 중 리서치만 진행. **결론: 방향성은 유효, 착수 시점만 A3 승인 확인 후로 미룸.**

### 시장 신호 — 움직이는 쪽이 확실히 유리
- 카카오 상위 20위권 이모티콘 중 정지형은 1개뿐, 나머지는 전부 애니메이션 — 구매자 선호가 움직이는 쪽으로 뚜렷하게 쏠려 있음.
- 초코 가격도 정지형(200초코) 대비 움직이는 이모티콘(300초코)이 더 높게 책정되는 게 일반적 — 단가 자체가 유리.
- 2026년 트렌드는 텍스트 의존도를 낮추고 캐릭터 동작만으로 의미가 전달되는 "논버벌(non-verbal)" 스타일이 라인(LINE) 등 해외 플랫폼 확장성 평가에서도 좋은 평가를 받는 추세.

### 제작 요건 (기존 인수인계 문서에 이미 확인된 내용, 재확인)
- **제안(심사) 단계**: GIF 3종(흰 배경, 애니메이션) + PNG 21종(투명배경, 정지) = 총 24종.
- **승인 후 최종 제작**: 24종 전부 WEBP 포맷으로 다시 애니메이션 제작 — GIF 제안과 WEBP 최종본은 별개 공정이라 승인 후 추가 작업이 한 번 더 필요함(정지형보다 공정이 하나 많은 이유).
- 정지형과 동일하게 360×360px 캔버스 기준.

### 우리 파이프라인 재사용 가능성 — 낮지 않은 리스크로 판단
- `kakao-emoticon/execution/products/kakao-emoticon-art/scripts/`의 Leonardo AI 기반 정지형 파이프라인(고정 시드 87008451, 몸통 프롬프트 고정 + 표정만 교체)은 **정지 이미지 생성**용이라 그대로 애니메이션에 못 씀 — 프레임 간 일관성(같은 캐릭터가 매 프레임 미세하게 달라지지 않는 것)을 담보하는 별도 작업이 필요.
- 카카오 이모티콘 스튜디오 자체에 "모션 스튜디오"라는 레이어 기반 편집 도구가 있어(레이어로 캐릭터·소품·텍스트를 나눠 일부만 움직이는 방식, 점프·바운스 등 프리셋 코레오 템플릿 제공) — 정지형 아트워크(특히 몸통·팔다리가 이미 여러 표정에 걸쳐 일관된 32종)를 레이어로 분해해 이 도구로 움직임만 얹는 경로가 이미지 재생성보다 리스크가 낮아 보임. **단, 로그인 필요한 SPA라 이 세션에서 화면 UI를 직접 확인은 못했음 — 착수 시 실제 화면에서 재확인 필요.**
- 대안: Leonardo AI 등에서 프레임별 재생성 후 후처리로 정렬하는 방식은 캐릭터 일관성 리스크가 커서(이미 정지형에서도 시드 고정에도 미세한 개체차가 있었음) 후순위.

### 다음 액션 (착수 시점 되면)
1. 정지형 32종 승인 확인.
2. 24종 중 어떤 문구를 움직이는 버전으로 낼지 우선순위 선정(정지형 1~12번처럼 반응 좋은 것부터 추천).
3. 카카오 이모티콘 스튜디오 "모션 스튜디오" 실제 화면 확인(로그인 필요 — 회장 브라우저 또는 국가차단 안 걸리는 경로).
4. 파일 규격(용량 제한, 프레임 수, 재생시간 등 세부 스펙)은 로그인 후 실제 제안 화면에서 재확인 — 이번 리서치는 텍스트 검색 기반이라 세부 수치는 착수 시점에 다시 확인 필요.
