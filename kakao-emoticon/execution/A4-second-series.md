# A4 기획 — 두 번째 이모티콘 시리즈 "새침냥이" (가칭)

> 2026-08-12, 예슬 작성. A3("일잘봇") 카카오 심사 대기 기간(2~4주) 동안 놀리지 않고 두 번째 상품을 준비하기 위한 기획서. **아직 회장 확인 전 — 컨셉·문구 확정, 실제 아트워크 제작(Leonardo API 호출)은 이 문서 확인 후 착수.**

## 왜 지금, 왜 이 컨셉인가

- A3 결과가 나올 때까지 예슬의 실행 액션이 없는 게 아니라 "카카오 심사"라는 **외부 병목 하나만 비어있는 것** — 그 사이에 두 번째 제안을 준비해두면, A3 결과와 무관하게 바로 다음 제안을 낼 수 있어 계정 전체의 심사 처리량이 늘어난다(카카오는 창작자당 동시 제안 개수 제한이 공식적으로 명시돼 있지 않음 — 여러 제안 동시 진행 사례가 흔함).
- A3(일잘봇)는 "직장인 유머"가 타겟인데, 같은 타겟·같은 톤으로 두 번째를 내면 (a) 승인/거절이 같은 이유로 같이 갈 위험(상관관계)이 있고 (b) 잠재 구매자 풀이 겹친다. **완전히 다른 타겟·톤을 골라 포트폴리오를 분산**하는 게 리스크 관리 관점에서 낫다고 판단.
- 시장조사 결과(2026-08-12, WebSearch 기반): 카카오 이모티콘 상위권에서 반려동물(특히 고양이의 "시크함/도도함"을 코미디로 쓰는) 컨셉은 꾸준히 스테디셀러 카테고리 — 유행을 타는 밈형 캐릭터보다 검증된 장르가 리스크가 낮음.

## 캐릭터 컨셉 — "새침냥이"

- **정체성**: 작은 통통한 고양이 마스코트. 뾰족귀·짧은 꼬리·큰 눈, 무심하고 도도한 기본 표정이 디폴트. "일잘봇"과 마찬가지로 **눈+입 두 요소로만 감정 표현**하는 문법을 그대로 따름(기존 파이프라인 재사용 목적 — 아래 "제작 계획" 참고). 수염 각도를 표정 보조 요소로 하나 추가(로봇엔 없던 표현 축이라 차별화에 도움).
- **색상**: 크림/베이지 웜톤 — 일잘봇의 민트/시안 계열과 명확히 구분되는 팔레트라 브랜드 혼동 없음, 고양이 캐릭터 시장에서도 익숙한 색상군이라 낯설지 않음.
- **타겟**: 반려묘 집사(전 연령, 카카오 이모티콘 구매자 성비상 2030 여성 비중이 높은 걸 감안하면 이 카테고리와 궁합이 좋음) — 일잘봇(직장인)과 겹치지 않는 새 구매자 풀.
- **한 줄 컨셉**: "도도한 우리 집 고양이가 집사한테 보내는 톡" — 다정한 강아지형 반려동물 캐릭터가 이미 시장에 많아서, 반대로 "무심하고 시크하지만 결국 다정함이 새어나오는" 태도로 차별화.

## 제작 계획 — 기존 파이프라인 100% 재사용

A3에서 이미 검증·저장소에 커밋된 파이프라인(`kakao-emoticon/execution/products/kakao-emoticon-art/scripts/`)을 그대로 재사용한다. 새로 필요한 건 **새 캐릭터의 몸통 프롬프트 + 새 고정 시드** 하나뿐:

1. `generate.py`용 새 프롬프트("작은 통통한 고양이, 크림색 몸통, 뾰족귀, 짧은 꼬리, 두꺼운 검은 외곽선, 스티커 스타일") + 새 고정 시드로 표정 3종 비교 그리드 먼저 생성 → 캐릭터 일관성 확인.
2. 확인되면 1~12번 문구 생성 → 배경제거(`postprocess.py`, 마젠타 크로마키 재사용) → 360×360 크롭 → 합본 미리보기(`make_contact_sheet.py`).
3. 반응 보고 13~32번 확장(A3와 동일 순서).
4. 아이콘 이미지(78×78)는 제출 직전 A3와 동일 방식으로 별도 제작.

**예상 소요**: A3 실적 기준(1~12번 1일, 13~32번 같은 세션 내 추가 진행) 참고하면 **전체 1~2일 내 완료 가능** — 로그인·화면 필요 없는 구간(생성~후처리~합본)은 전부 예슬 단독 진행 가능.

## 제출 단계 — A3와 동일한 제약 있음

정지형 아트워크가 완성돼도 **카카오 이모티콘 스튜디오 실제 제출(로그인 필요)은 A3와 같은 이유로 여전히 회장 액션이 필요할 가능성이 높다** — 자세한 재조사 결과는 [`A3-kakao-emoticon.md`의 "업로드 자동화 재조사(2026-08-12)"](A3-kakao-emoticon.md) 섹션 참고. 다만 그 섹션에서 제안하는 "1회성 국가인증 → 허용 국가 등록" 경로가 실제로 뚫리면, A4 제출부터는 예슬이 완전 자동으로 진행할 수 있을 가능성이 있다.
