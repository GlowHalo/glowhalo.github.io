## 결함 발견 및 수정 — "배경 배지/카드" 결함 (2026-08-18)

첫 32장 배치 생성 후 검수에서 **전량에 걸쳐 배경이 캔버스 전체를 채우지 못하고 원형/둥근카드 모양의 "배지"로 렌더링되는 결함**을 발견. `postprocess.py`의 플러드필 알고리즘은 정상 작동(실제 이미지 코너의 흰색/회색을 배경으로 정확히 감지) — 문제는 Leonardo 생성 자체가 코너까지 색을 채우지 않은 것.

세 차례 수정 시도 모두 실패:
1. **프롬프트 강화 1차**: "배경이 코너까지 빈틈없이 채워진다"를 명시적으로 강조 + NEG에 배지/카드 관련 용어 추가 → 원형이 둥근사각형으로 미세하게만 바뀜, 근본 결함 그대로.
2. **프롬프트 강화 2차**: "sticker style/professional character design" 등 아이콘 연상 문구 제거 + NEG 대폭 보강 → 변화 없음.
3. **시드 교체**: A8("합격토끼")에서 겪었던 "시드 고착" 사례를 참고해 시드를 55201983 → 71349502로 교체 → 변화 없음. 시드 고착 가설 기각.

**4차 시도(성공)**: 정상 동작 중인 A10(kakao-dog-art)의 프롬프트와 직접 비교한 결과, 진짜 원인을 발견 — A10은 배경 지시가 단순히 `"plain solid bright blue background"` 한 줄인데, A12는 `"...fills every corner of the image with sharp square corners..."`처럼 **"코너(모서리)"라는 단어를 명시적으로 두 번 언급**하고 있었다. 이게 오히려 모델에게 "이미지의 모서리를 시각적 요소로 그려라"는 신호로 잘못 해석되어 카드 프레임/배지를 만들어낸 것으로 추정.

→ 배경 문구를 A10과 동일한 단순 형태(`"plain solid bright teal background"`)로 되돌리고, NEG의 배지/카드 관련 추가 용어도 원래 불필요했던 것으로 확인되어 제거. 3장 테스트로 즉시 해결 확인 후 32장 전체 재생성 — 이번엔 전량 정상(교정된 코너 색상 `bg≈(70-87, 168-177, 172-180)`, 흰색/회색 잔여 없음).

**교훈(향후 시리즈 프롬프트 작성 시 적용)**: 배경 지시는 단순하게 — "코너까지 채운다"·"모서리가 각지다" 같은 구체적 지침을 덧붙이지 말 것. 오히려 결함을 유발할 수 있다.
