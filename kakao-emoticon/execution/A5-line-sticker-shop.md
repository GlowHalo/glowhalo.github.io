# A5 기획 — 라인(LINE) 스티커샵 진출 (일잘봇 32종 재활용)

> 2026-08-15, 예슬 작성. "다음 것 기획·제작해"(회장 지시, A4 회장 확인 대기 중 병행 작업)에 따라 착수.

## 왜 이 채널, 왜 지금

- `candidates.md`의 "향후 확장 후보"였던 OGQ마켓·라인 스티커샵을 웹서치로 실제 검증한 결과, **OGQ는 AI 생성 콘텐츠를 심사 반려**하는 반면 **LINE은 AI 생성 콘텐츠를 (표시 조건부로) 허용** — 우리 파이프라인이 100% AI 생성이라 LINE만 현실적 후보로 남았다.
- LINE 세트 구성이 8/16/24/32/40종 중 선택인데, **일잘봇이 이미 정확히 32종 완성돼 있어 문구 하나도 새로 안 만들어도 됨** — 순수 포맷 변환(리사이즈+캔버스 배치)만으로 새 채널에 낼 수 있는 가장 저비용 확장.
- 카카오는 "심사 결과가 이미 나온 뒤에만" 다음 걸 진행하는 게 아니라, **플랫폼이 다르면 동시에 여러 채널 심사를 병행해도 문제 없음** — 카카오 A3/A4와 별개로 진행.

## 제작 계획

1. 기존 `kakao-emoticon-art/01-*.png` ~ `32-*.png`(360×360 정사각, 투명배경)를 소스로 사용 — **재생성 없음**, 순수 후처리.
2. 각 이미지를 370×320 캔버스 중앙에 배치(비율 유지, 최대 300×300 안에 들어가도록 축소 — 상하 여백 확보).
3. 대표 이미지 1개를 골라 메인 이미지(240×240) 제작.
4. 탭 이미지(96×74)는 대표 캐릭터 얼굴만 크롭해서 작게 제작(채팅창 트레이에서 작게 보이므로 몸통보다 얼굴 위주가 인식성이 좋음).
5. 계정 가입은 회장 승인 필요(2026-08-11 CLAUDE.md 보류 원칙) — 자산만 준비해두고 가입은 회장 지시 대기.
