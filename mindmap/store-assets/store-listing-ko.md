## 설명 (Description, 그대로 붙여넣기)

브라우저 하나로 끝나는 마인드맵 편집기예요. 설치 없이 웹에서도 바로 쓸 수 있지만, 앱으로 설치하면 오프라인에서도 곧바로 열려요.

주요 기능
- Tab/Enter로 하위·형제 노드를 빠르게 추가
- 드래그로 카드 재배치, 접기/펼치기로 큰 맵도 깔끔하게 정리
- 여러 마인드맵을 라이브러리로 관리하고, URL 하나로 다른 기기·다른 사람과 공유
- ✨ AI로 만들기 — 회의록, 아이디어 메모, 목차 같은 텍스트를 붙여넣으면 AI가 자동으로 계층 구조의 마인드맵을 만들어드려요. 본인의 Gemini API 키를 넣으면 무제한으로, 키가 없어도 기기당 3회 무료로 체험할 수 있어요.

기획, 회의 정리, 공부 노트 정리에 가볍게 쓰기 좋은 도구예요. 데이터는 기기(브라우저)에 저장되고, AI 기능을 쓸 때 붙여넣은 텍스트만 생성 요청에 사용돼요.
