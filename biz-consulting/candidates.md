# GlowHalo 12 — 회장 상담 아이디어 로그 (Living Doc)

회장이 상의한 아이디어를 시간순으로 기록한다. 각 항목은: 날짜 · 아이디어 요약 · 중복 확인 결과(다른 계열사 candidates.md와 겹치는지) · 표준 필터 평가 · 판단(편입/신설/리서치 후 재논의/파킹).

## 로그

### 2026-08-13 — Round 1: "클로드 MCP 연동 서비스" 활용 신사업 발굴 (회장 지시)

회장이 특정 아이디어를 가져온 게 아니라 방향("클로드 MCP가 있는 서비스를 활용, 계정 생성+연결만 해주면 이후 전부 Claude가 자동 진행, 1원이라도 단기수익 우선, 최대한 많이 제안")을 지시 — GlowHalo 12로서는 이례적으로 다연(biz-scouting)·이든(brief-ai)식 능동 발굴 라운드에 가깝게 진행. 방법: ① 현재 세션 연결 커넥터 확인(`ListConnectors`) ② MCP 레지스트리 검색(`SearchMcpRegistry`)으로 결제/이커머스/디자인/생산성 카테고리 스캔 ③ 다른 계열사 11곳의 `candidates.md` 전체(11개 파일)를 읽어 중복 확인 ④ 유망 후보 2건(Stripe 한국 개설 가능 여부, Canva Autofill 요건)은 실제 웹서치로 사실관계 검증.

**⚠️ 부수 발견 — 다른 계열사 기존 전제에 영향 가능성, 회장 공유 필요**
- **Stripe는 한국 개인·법인 모두 계정 자체를 열 수 없다** (미국/호주/캐나다 법인 전제, 해외법인 우회는 ToS 위반+정지 리스크 — [출처](https://bendh.kim/2024/09/03/%ED%95%9C%EA%B5%AD%EC%9D%98-%EA%B0%88%EB%9D%BC%ED%8C%8C%EA%B3%A0%EC%8A%A4feat-stripe/)). `biz-scouting/candidates.md` E1("Stripe/토스페이먼츠", 토스페이먼츠 병기라 대체재는 있음)과 `brief-ai/candidates.md` 브리프AI("Stripe/Paddle 개인 판매")가 결제수단으로 Stripe를 전제하고 있는데, 실제 계정 개설 단계에서 막힐 수 있다 — 아직 두 사업 다 결제 연동 전 단계라 당장 사고는 아니지만, 착수 시점에 다연·이든이 재확인해야 한다. Paddle은 MoR(Merchant of Record) 구조라 Stripe와 무관하게 별도 확인 필요.
- **Canva의 Autofill API(데이터 기반 대량 자동생성)는 Canva Enterprise 멤버십 전제** — 개인/무료 계정으론 "여러 디자인을 한 번에 배치 생성"하는 완전자동화가 안 된다([공식 문서](https://www.canva.dev/docs/connect/autofill-guide/)). 기본 디자인 생성/내보내기는 가능해 보이나(엔터프라이즈 불요 추정), 검증은 실제 연결 후 재확인 필요.

**중복 확인 결과**: 11개 계열사 candidates.md 전수 확인, MCP 커넥터를 명시적으로 다룬 기존 후보는 없음(niche-api가 RapidAPI 등 REST API는 다뤘지만 Claude MCP 커넥터 관점은 처음). Notion(A1)·Stripe(E1·브리프AI 전제)·PayPal(biz-scouting Displate 정산 언급)은 이름만 겹침, 새 아이디어와는 별개.

### 2026-08-13 — Round 2: "Capafy 같은 AI 스킬 판매처" (회장 제안)

회장이 구체적 아이디어(Capafy — Claude/Codex 등 AI 에이전트용 "Skill"을 창작자가 게시하고 실행될 때마다 수익을 받는 마켓플레이스)를 가져옴.

**중복 확인**: company1~11 candidates.md 전체에 "스킬"/"skill" 키워드 재검색 — 없음. 신규 카테고리. (인접한 것: company1 A1은 인간이 읽는 노션/시트 템플릿, company11 브리프AI는 완성형 SaaS — 둘 다 이번 아이디어와 산출물·구매자층이 다름. "AI 에이전트가 실행하는 지침서"를 파는 건 처음.)

**시장 확인(웹서치)**: 2025-12 레지스트리 1곳→2026-Q2 마켓플레이스 8곳으로 급성장 중인 실존 신생 카테고리. Capafy(closed-source 실행, "실행할 때마다 정산" + "다운로드 1회성" 두 모델) 외 Agensi(창작자 70% 배분, Stripe Connect 정산), ClaudeSkillsMarket 등 확인.

**표준 필터 평가**:
| 항목 | 판정 | 근거 |
|---|---|---|
| 겸업 창업자 개입 최소화 | ✅ | 스킬 제작(우리가 이미 잘하는 일)만 끝나면 판매는 완전 무인, 반복 CS 거의 없음 |
| 사업자등록 불가 | 🔍 미확인 | Capafy·Agensi 둘 다 가입 요건에 사업자등록 명시 안 함(개인 창작자 대상 표방) — 실제 가입 화면에서 확인 필요 |
| 무자본 우선 | ✅ | 가입 무료, 판매할 스킬 자체가 이미 우리가 다른 사업에서 만들어본 노하우(PR 리뷰 페르소나, 템플릿 생성 파이프라인 등) 재포장이라 원가 사실상 0원 |
| 오프라인 대면 배제 | ✅ | 완전 비대면 |
| 정산 계좌직접입금 | 🔍 미확인 | Capafy는 정산수단 문서에 미기재. Agensi는 **Stripe Connect** — Round 1에서 확인한 "한국은 Stripe 계정 자체를 못 연다"는 제약과 겹칠 수 있어 **재확인 1순위** (단 Connect의 커넥티드 계정은 독립 Stripe 계정과 정책이 다를 수 있어 직접 확인 전엔 예단 금지) |
| 채널 API/CLI 자동운영 | 🟡 부분 | Capafy는 `capafy-publisher` CLI로 검색·번들링은 자동화되지만, 확인파일·모드선택·최종제출 3곳은 웹 수동 — "완전자동"은 아니고 "CLI 중심 반자동". Agensi는 문서상 수동 제출만 확인됨 |

**판단 — 리서치 후 재논의 아님, 유망도 높아 바로 가입 검증 단계 제안.** 새 계열사보다는 **GlowHalo 12가 첫 자체 사업 라인으로 착수**하는 걸 추천 — A1(인간 대상 템플릿)·company11(완성형 SaaS) 어디에도 깔끔히 안 맞고, "우리가 이미 만든 자동화 노하우를 다른 AI 에이전트 운영자에게 재판매"라는 성격이 상담 창구보다 실행에 가까워지긴 하지만, company1의 "신설 vs 기존편입" 로직상 맞는 기존 계열사가 없으면 신설(혹은 제안한 계열사가 흡수)이 맞는 순서.

**팔 만한 스킬 후보(원가 0원, 이미 있는 노하우 재포장)**: (1) company1 A4의 "3인 페르소나 PR 코드리뷰" 로직, (2) A1의 니치 디지털템플릿 생성 파이프라인, (3) 회의록 요약+액션아이템 추출(브리프AI와 겹치지 않게 "완성 SaaS"가 아니라 "스킬 단품"으로 차별화), (4) 이커머스 리스팅 SEO 타이틀/설명 생성.

**다음 액션(회장 확인 필요)**: Capafy 이메일 매직링크 가입 1건 진행 승인 요청(2026-08-11~12 정책상 신규가입은 회장 승인 후 진행) — 가입 즉시 실제 화면에서 사업자등록 요건·정산수단(계좌 직접입금 여부)을 확인하고 바로 재보고.

### 2026-08-18 — Round 3: "갤럭시워치 앱/배경화면(워치페이스) 판매" (회장 제안)

회장이 갤럭시워치용 앱·워치페이스 개발/판매를 문의. 웹서치로 실제 유통 구조부터 확인.

**중요 사실관계(웹서치 검증)**:
- 갤럭시 스토어 셀러 가입 자체는 누구나 무료. 단 **스마트폰용 앱은 유무료 무관 법인(사업자) 명의 계정 전환이 필수** — 회장 리소스 제약(사업자등록 불가)과 정면 충돌, 이미 `app-portfolio`(GlowHalo 6)가 Circle Heroes 건에서 동일 이유로 삼성 채널을 보류한 전례 있음.
- **워치 전용 콘텐츠는 개인 계정으로도 업로드 가능하다는 조항이 남아있지만, 갤럭시워치4부터 OS가 Tizen→Wear OS로 전환되며 신규 워치 콘텐츠는 갤럭시 스토어가 아니라 구글 플레이스토어로만 유통된다(중국 제외, [Samsung Developer 공지](https://developer.samsung.com/galaxy-watch-tizen/notice.html))** — 즉 "갤럭시 스토어 개인 워치 업로드"는 사실상 레거시 조항이라 실질 경로가 아님. 갤럭시 스토어에 남은 워치페이스 신규 등록 경로도 Samsung "Watch Face Review Team" 승인이 걸려있어 자유 개인등록이 아님.
- **실질 경로는 구글 플레이 콘솔(개인 계정)**: [$25 1회 결제](https://support.google.com/googleplay/android-developer/answer/6112435), **사업자등록 불필요**(D-U-N-S 번호는 법인 계정에만 요구), 신분증 인증 + (한국 개발자는) 휴대폰 번호 인증만 필요. 워치페이스는 Samsung 무료 툴 **Watch Face Studio**(PC/Mac, 코딩 불필요)로 제작해 Wear OS용으로 내보낼 수 있고, 일반 워치앱은 Android Studio/Wear OS SDK로 개발.
- **서드파티 대안 — Facer**: 앱스토어 가입 없이 Facer Creator로 코딩 없이 워치페이스 제작·무료 게시 가능(진입장벽 최저). 단 **유료 판매("Premium Designer")는 초대제** — 먼저 무료로 올려 다운로드 실적을 쌓아야 하고, 수익쉐어 비율도 비공개. 즉시 수익화는 어려움.

**표준 필터 평가**:
