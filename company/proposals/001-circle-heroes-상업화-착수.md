# 제안서 001 — Circle Heroes 상업화 착수

- **날짜**: 2026-08-05
- **상신자**: 사장 (CEO)
- **검토**: CSO · CTO · CMO ([창립 이사회 회의록](../board/2026-08-05-창립이사회.md))
- **상태**: ⚪ 범위 재조정 — 개인 프로젝트 영역으로 이관 (회사 안건 아님)

> **2026-08-05 회장 코멘트 반영**: 이 회사의 목적은 기존 사이드 프로젝트를 사업화하는 것이 아니라, 그것과 무관하게 백지상태에서 새로운 사업을 탐색하는 것으로 명확해졌다. circle-heroes는 회장의 개인 취미/사이드 프로젝트 영역에 남고, 이 문서는 "첫 논의가 어떻게 잘못된 전제로 시작됐는지"를 보여주는 이력으로만 보존한다. 이 회사의 실제 첫 탐색은 [제안서 002](002-신사업-백지탐색-1라운드.md) 참고.

## 요약

임원 3인이 서로 의견을 맞추지 않고 독립적으로 검토했는데, **만장일치로 `circle-heroes`(방치형 수집 RPG)를 첫 사업 트랙으로 추천**했습니다. 근거는 하나로 모입니다 — 광고(AdSense)·후원(Ko-fi) 수익화 배선이 이미 90% 끝나 있고, 부족한 건 트래픽뿐이라는 것. 즉 "새로 만드는" 사업이 아니라 "이미 만들어 둔 것을 켜는" 사업입니다.

세컨드 베팅으로 CSO가 `dividend-passbook`(배당현황) 병행을 제안했습니다 — 결제 전환 가능성이 후보들 중 가장 현실적이라는 이유입니다.

## 사장 종합 판단

3개 부서가 각기 다른 렌즈(시장성/기술/그로스)로 봤는데 결론이 일치한다는 건 신뢰도가 높은 신호라고 판단합니다. 특히 CMO와 CTO가 코드를 직접 확인해서 낸 구체적 사실(광고 슬롯 ID가 비어있다, 애널리틱스가 없다, AdSense 심사가 아직 진행 중일 수 있다)은 "감"이 아니라 검증된 현황이라 실행 우선순위로 바로 쓸 수 있습니다.

**1순위: circle-heroes 상업화 즉시 착수.**
**2순위(세컨드 베팅): dividend-passbook — circle-heroes에 올인하지 않고 소규모로 병행.**

목표 KPI는 "대박 흥행"이 아니라 **낮은 유저획득비용의 꾸준한 소액 수익 + 포트폴리오 가치**로 잡을 것을 제안합니다. 1인+AI 체제에서 대형 스튜디오와 흥행 경쟁을 하는 건 리스크 대비 기대값이 안 맞습니다.

## 실행 로드맵 (승인 시 즉시 착수)

### Phase 0 — 스위치 켜기 (비용 없음, 승인 즉시 진행 가능)
- [ ] AdSense 배너 광고 단위 발급 → `AD_BANNER_SLOT_ID` 채우기 (현재 빈 문자열이라 배너 자리에 아무것도 안 뜸)
- [ ] AdSense 사이트 심사 승인 상태 재확인
- [ ] 최소 애널리틱스(GA4 등) 설치 — 지금은 전무해서 채널별 유입/전환을 측정할 수 없는 상태
- [ ] Firestore 개방형 보안규칙(`allow read, write: if true`) 현황 문서화 (지금은 허용 가능한 트레이드오프, 추후 재검토 지점으로 기록만)

### Phase 1 — 정식 유통 채비 (소액 예산 승인 필요)
- [ ] Google Play 정식 등록 (**$25, 1회성** — 회장 승인 필요)
- [ ] 릴리스 서명 키(keystore) 발급 및 서명 빌드 파이프라인 구축 (현재는 디버그 APK만 빌드 중)

### Phase 2 — 트래픽 유입
- [ ] Phase 0/1 완료 **후에만** 커뮤니티 3~5곳(디시 방치형겔러리, 루리웹, 인벤, 오늘의유머, 네이버카페) 동시 게시
- [ ] itch.io / APKPure 등 보조 채널 등록 (무료)

> 순서가 중요합니다 — 광고/추적을 안 붙인 채로 먼저 트래픽을 태우면 가장 값진 "첫 유입" 데이터를 그냥 날리게 됩니다.

## 회장 승인이 필요한 사항

1. **Play Store 등록 비용 $25 지출** 승인 여부
2. **"메인 circle-heroes + 세컨드 베팅 dividend-passbook" 투트랙** 방향 승인 여부 (또는 circle-heroes 단독 집중)
3. 목표 KPI를 **"흥행"이 아닌 "꾸준한 소액 수익 + 포트폴리오"**로 잡는 것에 대한 동의 여부
4. AI 생성 캐릭터 아트의 **저작권/스토어 정책 리스크** — 별도 법적 검토가 필요한지 여부

## 참고 — 이번 검토에서 발견된 기술부채 (승인과 무관하게 인지만 해두면 되는 항목)

- circle-heroes 저장소 용량 537MB(`.git` 254MB 포함) — 캐릭터 자산이 계속 늘어나면 관리가 필요해질 수 있음
- `kpc-coach-chat`은 현재 실제 LLM 연결이 없는 목업 — 향후 AI 챗봇 라인을 확장한다면 여기서부터 실제 백엔드(서버리스 프록시) 구축이 필요
- `baby-place-registry`의 "링크 자동분류"는 CORS 문제로 서버리스 프록시 없이는 정식 구현 불가
