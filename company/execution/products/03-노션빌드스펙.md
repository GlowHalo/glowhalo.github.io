# 노션 빌드 스펙 — Notion 연동 승인되는 즉시 실행

> 목적: Notion MCP 인증만 떨어지면 아래를 그대로 옮겨서 완성하도록, 페이지/DB/속성/문구를 전부 확정해둔다. 생각하는 단계는 여기서 끝내고, 연동 후에는 기계적 실행만 남기는 게 목표.

## 페이지 트리

```
📁 AI Board of Directors  (템플릿 루트, 이 페이지를 통째로 duplicate)
  ├─ 📄 Start Here (3단계 사용법 + 데모 라운드로 바로 링크)
  ├─ 📄 Company Charter
  ├─ 🗄 Board Minutes  (database)
  ├─ 🗄 Proposals  (database)
  ├─ 🗄 Candidate Tracker  (database, Kanban)
  ├─ 📄 Execution Plan (template page, "New" 버튼으로 복제해 쓰는 서브페이지 템플릿)
  └─ 📄 Prompt Sets  (15개, role별 toggle)
```

## Start Here (첫 화면, 가장 중요 — 여기서 이탈 결정됨)

```
# Start Here

1. Duplicate this page into your own workspace (top-right → Duplicate).
2. Open "Prompt Sets" → pick one prompt → paste into ChatGPT or Claude (free tier is fine).
3. Paste the answer into a new row in "Board Minutes."
4. Do this once per role (Strategy / Tech / Growth) for the same decision.
5. When all three are in, open "Proposals" and write the one-line call.

Want to see it filled in first? → [Board Minutes, Round 1] (링크, 데모 데이터로 이동)
```

## Company Charter (텍스트 그대로 사용)

```
# Company Charter

## Mission
[One sentence: what you're trying to build, and for whom.]

## Budget rule
[Hard cap per idea before it needs a real decision — e.g. "$0 to validate; ask before spending real money."]

## The Board
- Strategy — sanity-checks the idea itself: is this worth doing, for this segment, at this price
- Tech — sanity-checks feasibility: can this actually run with the time/skills you have
- Growth — sanity-checks distribution: will anyone find this, and how

## Operating principle
Each exec reviews independently, before seeing the others' answers. Disagreement is the point —
if all three agree without prompting, that's a stronger signal than one AI agreeing with you.
```

## Board Minutes — database

**Properties**:
| Property | Type | Notes |
|---|---|---|
| Round | Title | e.g. "Round 1 — coffee subscription" |
| Date | Date | |
| Exec | Select | Strategy / Tech / Growth |
| Note | Text | the exec's actual review, 2-4 sentences |
| Related Proposal | Relation → Proposals | |

**Demo rows** (pre-filled, 3 rows, one per exec, all tagged Round 1 — content = the coffee-subscription example already drafted in `02-실제콘텐츠-프롬프트및데모.md`)

**Default view**: Table, grouped by Round.

## Proposals — database

**Properties**:
| Property | Type | Notes |
|---|---|---|
| Title | Title | |
| Status | Select | Reviewing / Pending / Approved / Rejected / Parked |
| Owner | Select | Strategy / Tech / Growth / You |
| Related Minutes | Relation → Board Minutes | |
| Verdict | Text | one-line call |

**Demo row**: "Test the $5 curation guide before the box" — Status: Approved, Verdict text from the demo minutes.

## Candidate Tracker — database (Kanban)

**Properties**: Candidate (Title) · Proposed By (Select) · Category (Select) · Validation Cost (Select: $0 / <$50 / <$200) · Status (Select: Idea / Validating / Keep / Kill)

**Board view**: grouped by Status. **Demo cards** (2, so the board isn't empty on open): "Coffee curation guide" (Validating), "Local roaster subscription box" (Kill — logged reason: fails zero-touch test).

## Prompt Sets 페이지

`02-실제콘텐츠-프롬프트및데모.md`의 15개 프롬프트를 role별 toggle 3개(Strategy/Tech/Growth) 안에 5개씩 code block으로 그대로 붙여넣기. 변수는 `[대괄호]`로 표시된 부분 그대로 유지 — 사용자가 채워넣는 자리라는 게 시각적으로 바로 보여야 함.

## 연동 후 순서
1. Notion에 위 페이지 트리 생성
2. 데모 데이터 입력 (Board Minutes 3행, Proposals 1행, Candidate Tracker 2카드)
3. 전체를 하나의 상위 페이지로 묶고 "Duplicate" 템플릿으로 공개 설정
4. 스크린샷/GIF 캡처 → 목업 판매페이지의 "Exhibit A" 자리에 실제 화면으로 교체
5. 회장님 or 베타테스터에게 duplicate 링크 전달해 실사용 테스트
