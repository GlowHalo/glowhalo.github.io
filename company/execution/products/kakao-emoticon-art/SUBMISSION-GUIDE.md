# 카카오 이모티콘 스튜디오 제출 가이드 — "일잘봇" 정지형 32종

> 2026-08-08 작성. 이 문서는 회장이 로그인 후 그대로 따라할 수 있게 만든 단계별 안내문이다.
> **로그인·클릭·실제 업로드는 카카오 계정 인증이 필요해 회장만 할 수 있다** — Claude가 대신 처리할 수 없는 구간.

## 사전 준비 상태 (완료됨)

- 파일 위치: `company/execution/products/kakao-emoticon-art/01-annyeonghaseyo.png` ~ `32-oneul-harudo-kkeut.png` (32개, 번호순 정렬됨)
- 규격: 전량 360×360px, PNG(RGBA 투명배경), 72dpi, 90.7KB~111.8KB (카카오 요건 150KB 이하 충족)
- 합본 미리보기: `00-contact-sheet-preview.png` (실제 제출 파일 아님, 육안 확인용)
- 문구 리스트·순서는 `A3-kakao-emoticon.md`의 "정지형 32종 문구 리스트"와 동일

## 왜 이 정도까지만 조사했는지 (정직한 고지)

카카오 이모티콘 스튜디오(`emoticonstudio.kakao.com`)는 로그인 후에만 실제 제안 화면이 열리는 SPA라, 로그인 없이는 화면 텍스트를 못 읽는다. 이 세션에서 헤드리스 브라우저(Playwright)로 로그인 없이도 볼 수 있는 공개 페이지(가이드라인 등)라도 렌더링해보려 시도했으나, **이 실행 환경의 프록시-Chromium 간 TLS 비호환 문제로 막혔다**(`example.com` 같은 무관한 사이트도 동일하게 실패 — 카카오 사이트 자체의 문제가 아니라 이 세션 환경의 한계, A1에서 Gumroad 자동화 시도 때도 같은 패턴이 있었음). 그래서 아래 절차는 **공개 검색 결과(창작자 블로그 후기, 카카오 공식 가이드라인 페이지 요약)와 일반적으로 알려진 UI 흐름을 종합한 것**이며, 버튼 문구·화면 순서 등 세부 사항은 **실제 로그인 화면에서 다를 수 있다**. 아래 각 항목에 확인 여부를 표시해뒀다.

## 단계별 절차

### 1. 로그인
- `https://emoticonstudio.kakao.com` 접속
- 카카오 계정으로 로그인 (사업용으로 계속 쓸 계정인지 먼저 정해서 로그인 — 이 계정이 향후 정산 계좌 연동, 콘텐츠 공급계약의 당사자가 됨)

### 2. 제안 시작
- 로그인 후 홈 화면에서 "제안하기" 계열 버튼 클릭 *(정확한 버튼 문구는 로그인 화면에서 확인 필요 — 미확인)*
- 이모티콘 유형 선택 화면에서 **"멈춰있는 이모티콘"**(정지형, 32종) 선택 — "움직이는 이모티콘"이나 "큰 이모티콘"이 아님 *(유형 구분 자체는 검색으로 확인됨)*

### 3. 이모티콘 정보 입력
아래 값을 그대로 복사해서 쓰면 된다 (문항명은 실제 화면에서 다를 수 있으나 의미는 아래와 대응):

| 항목 | 제안 값 |
|---|---|
| 시리즈명(상품명) | 일잘봇 |
| 캐릭터명 | 일잘봇 |
| 한 줄 소개 | 일은 잘하고 싶은데 마음은 딴 데 있는 직장인의 속마음을 대신 표현하는 로봇 |
| 상세 설명/기획 의도 | 작은 원형 로봇 마스코트 "일잘봇"이 직장인이 회사에서 하고 싶지만 못 하는 말을 대신 해줍니다. 안테나 하나, 모니터 얼굴에 눈과 입 표정만 바뀌는 심플한 캐릭터 문법으로, 개발자·직장인·1인 창업자의 하루 감정(퇴근하고 싶다, 넵 넵 넵, 배포했습니다 등)을 32가지 표정으로 담았습니다. |
| 타겟 | 직장인, 개발자, 1인 창업자 |

### 4. 이미지 업로드
- 32개 PNG를 **번호 순서대로**(01→32) 업로드. 파일명 앞자리(01~32)가 곧 노출 순서와 같도록 만들어뒀으니, 업로드 시 파일 선택 창에서도 이름순 정렬로 골라 순서가 섞이지 않게 확인
- 화면에 "대표 이모티콘"(썸네일) 선택 항목이 있으면, 인지도 높은 인사말 계열을 추천: **01번(안녕하세요)** 또는 **24번(화이팅)** — 첫인상에서 캐릭터 성격이 바로 전달되는 두 장
- 배경이 안 빠지고 하얗게 나오면 원본 PNG가 아니라 다른 파일을 올린 것이니 재확인(전량 RGBA 투명배경으로 만들어뒀음)

### 5. 약관 동의 및 제출
- 저작권/이용약관 동의 체크 후 제출

### 6. 검수 대기
- 검수 기간은 자료마다 8~13일, 1~2주 등으로 다르게 언급됨 — **2~4주로 넉넉히 잡고 기다리는 게 안전**
- 결과는 카카오 이모티콘 스튜디오 내 알림 또는 가입 시 등록한 이메일로 통보되는 것으로 보임(미확인)
- 승인되면 그 다음에 카카오와 콘텐츠 공급계약을 맺는 절차가 이어짐(정산 계좌 등록 포함) — 이 시점에 정산 방식(원칙 5, `A3-kakao-emoticon.md` 하단 참고)을 다시 한번 확인해두면 좋음
