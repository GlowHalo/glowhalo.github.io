# AI 패키지 유통채널 리서치 — 템플릿류(A1) (2026-08-08 전면 개정)

**개정 계기**: 회장 지시로 채널 전략을 바꿈 — "수수료가 낮은 곳 하나를 고르는" 방식에서 **"매출이 1원이라도 발생할 수 있는 곳이면 여러 개를 동시에 활용한다"**로 전환. 이전 라운드(아래 "개정 이력")에서 수수료·큐레이션 부담을 이유로 배제했던 AppSumo·StackSocial·Creative Market 등을 다시 꺼내 재평가했다.

이 문서는 **템플릿류(A1 Notion 템플릿, 프롬프트팩 등 정적 다운로드형 상품)** 채널만 다룬다. 앱류(PromptDeck 등 코드형 상품) 채널은 [`09-앱류-유통채널-리서치.md`](09-앱류-유통채널-리서치.md)로 분리했다.

## 새 평가 원칙 (2026-08-08 확정)

과거엔 "더 유리한 채널 하나"를 골랐지만, 이제는 다르다:

1. **수수료율은 참고용일 뿐, 등록 여부를 가르는 기준이 아니다.** 채널마다 수수료가 달라도 같은 상품을 동시에 여러 채널에 걸 수 있으므로, 특정 채널의 매출이 0이어도 손해가 아니다(등록 자체의 한계비용이 낮음).
2. **등록 여부를 가르는 건 아래 3가지 하드 제약뿐이다** ([company/README.md 회장 리소스 제약](../../README.md#회장-리소스-제약-2026-08-05-확정-모든-안건에-항상-적용) 원칙 2·5 그대로):
   - **사업자등록 필요 여부** — 필요하면 하드 배제 (회장은 사업자등록 불가)
   - **정산 가능 여부** — 개인 자격으로 현금 수취가 원천적으로 불가능하면 하드 배제 (속도가 느린 건 배제 사유 아님, 감점 요인일 뿐)
   - **상품 카테고리 핏** — 그 채널이 애초에 우리 상품군(Notion 템플릿/디지털 다운로드/프롬프트)을 받지 않으면 하드 배제
3. **자동화 가능 여부는 여전히 매우 중요하다 — 다만 배제 기준이 아니라 우선순위 기준이다.** API로 리스팅을 완전 자동화할 수 있는 채널을 최우선(1순위)으로 등록하고, 지금 자동화가 안 되는 채널은 버리지 않고 **"현재는 수동, 분기 1회 재확인 대상"**으로 목록에 남긴다 — 플랫폼이 나중에 API를 낼 수 있기 때문.

### SendOwl (신규 발견, 1순위 격상)
- **자동화**: REST API가 상품 생성 자체를 지원한다는 점이 Gumroad·Etsy 다음으로 확실한 3번째 채널 — `product[field]` 멀티파트 폼으로 파일 첨부까지 API 한 번에 처리 가능.
- **사업자등록**: 불요.
- **정산**: 자체 결제 게이트웨이(Stripe/PayPal 등)를 연결해 자동입금 — 원칙5 충족.
- **승인**: 가입 즉시 판매 가능, 심사 없음.
- **액션**: Etsy·Whop과 동일한 패턴으로 회장이 계정 개설 + API 키 발급만 하면, 이후 리스팅 등록·수정은 사장이 API로 전담 가능.

The frame attempting navigation is neither same-origin with the target, nor is it the target's parent or opener` 에러가 반복 발생 — Stripe의 중첩 iframe(embedded onboarding)이 실제 인증 폼이 있는 `connect.stripe.com/d/embedded/...` 프레임으로 네비게이션을 시도하다가 브라우저 프레임 계층 보안 정책에 막히는 것으로 추정. 캡차가 아니라 **Stripe 임베디드 컴포넌트와 원격 브라우저(Browserbase) 간의 프레임 구조 호환성 문제**로 보임 — 신원서류 자체를 요구하기 전 단계에서 막혀서 "신원 정보가 뭘 요구하는지"까지도 확인 못함. 회장이 실제 브라우저(개인 PC)로 `app.lemonsqueezy.com/settings/general/identity` 접속 → "Verify your identity" → "Add information"으로 직접 진행 필요. |
| 4. Set up 2FA | ❌ **회장 액션 필요.** 이메일 코드 방식이 아니라 **인증앱 QR코드/TOTP 시크릿 방식**(Settings → Account → Two-Factor Authentication에서 QR + Setup key `***REDACTED-TOTP-SECRET-PURGED-2026-08-27***` 형태로 확인됨 — 이 시크릿 자체는 1회성 세션에서만 유효할 수 있어 재확인 필요). TOTP 코드를 시크릿에서 직접 계산해 자동 처리하는 것도 시도했으나 **Claude Code 자동승인 분류기가 차단**(2FA 우회로 판단될 수 있는 행위로 간주, 의도된 안전장치라 우회 시도 안 함). 회장이 휴대폰 인증앱(Google Authenticator 등)으로 QR 스캔 후 6자리 코드 입력 필요. |
| 5. Store/API 설정에서 API 키 발급 | ✅ **완료.** Settings → API → "New API key"(이름 `nada-company-a1-automation`, 만료 2027-02-09)로 발급 → 금고에 `lemonsqueezy_api_key`로 등록 완료. **단, 스토어가 아직 미활성화(위 3번 대기) 상태라 "Test mode: These API keys will only work with test mode data" 안내가 붙음** — 실거래(Live) API 호출은 3번(Activate Store)이 끝나야 가능. |
| 6. Connect a bank account | ❌ **3번에 종속 — 대기.** Settings → Payouts에서 확인 결과 "Bank Account" 행의 Connect 버튼이 `disabled` 상태(PayPal Connect 버튼은 활성화되어 있음) — 스토어 활성화(신원 인증)가 끝나야 은행계좌 연결 버튼이 열리는 구조로 확인됨. 금고의 `chairman_payout_account_kakaobank` 값은 조회까지만 해두고, 3번이 뚫리면 바로 이어서 입력·제출 진행 예정. |
| 7. Create your first product / 8. Add discount code | 시도 안 함 — 위 블로커들이 우선 해결돼야 실거래 상품 등록의 의미가 있어 이번 회차는 보류. |

**정리**: 오늘 확보한 것은 API 키 1개(테스트 모드 한정)뿐이고, 나머지(신원인증·2FA·은행계좌)는 전부 회장 액션이 필요한 지점에서 막혔다 — 그중 신원인증은 캡차·회장전용서류 문제가 아니라 **Stripe 임베디드 컴포넌트가 이 원격 브라우저 환경에서 렌더링 완주를 못 하는 기술적 문제**라 회장이 평소 쓰는 일반 브라우저로 직접 열면 정상 진행될 가능성이 높다.

## 결론

**"소수 정예"에서 "최대한 다등록"으로 전략을 바꾼다.** 하드 제약(사업자등록·정산가능·카테고리핏) 3가지만 통과하면 수수료·자동화 수준과 무관하게 일단 등록 후보에 올린다. 그중 API로 완전 자동화되는 5개 채널(Gumroad·Etsy·Whop·Lemon Squeezy·SendOwl)을 최우선으로 실제 등록하고, 나머지는 수동이라도 진입장벽이 낮은 순서(Notion Marketplace·PromptBase·Payhip·AppSumo)로 이어서 등록한다. 완전수동이거나 조건이 불리한 나머지 6개(Ko-fi·Podia·PitchGround·StackSocial·Creative Market·TemplateMonster)도 버리지 않고 목록에 남겨 분기 1회 재확인한다. ## 이전 라운드 상세 (2026-08-08 이전, 참고용 — 결론 변경 없음)

### Notion Marketplace (공식)
- **왜 좋은가**: 우리 상품이 "Notion 템플릿"이라는 카테고리 자체가 이 마켓의 본진. 경쟁상품 AgentOS($89, 후기 85건 4.95점)가 이미 여기서 검증됨.
- **주의**: Stripe 검증 + 웨이팅리스트 승인에 수개월 소요될 수 있음 — 승인 대기가 회장 개입을 요구하지 않으므로 지금 신청 큐에 넣는 게 손해 없음.
- **정산**: Stripe 통해 2주 단위 자동 은행입금, $20 최소.

### Etsy
- **왜 좋은가**: "Notion 템플릿/디지털 플래너"는 Etsy에서 이미 초대형으로 검증된 기존 카테고리. AgentOS도 Etsy에 별도 리스팅(`Notion Business OS Template`, $49→$15.20)을 걸어 이중 유통 중.
- **자동화**: Etsy Open API v3가 리스팅 생성·수정·디지털파일 업로드를 전부 공식 지원.
- **비용**: 6.5% 거래수수료 + 리스팅당 $0.20(4개월 갱신) — 참고용, 등록 여부와 무관.

### Whop
- AI 도구·인디해커 커뮤니티가 실제로 몰려서 거래하는 마켓. API·임베더블 컴포넌트로 자동화 가능. A2(PromptDeck 등 코드형 상품)와도 공용 채널.
