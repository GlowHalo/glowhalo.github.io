카카오 공식 문서에서 "출금 신청" 절차를 명시한 곳을 못 찾았고, 여러 소스(카카오 공식 정산 주기 안내, 실제 작가 후기 브런치 글 등)가 일관되게 "정산 후 자동으로 입금된다"는 뉘앙스로 서술함:
- 판매 발생 → 익월 정산 → 그다음 달 자동 지급(계좌입금)되는 월단위 자동 정산 구조로 파악됨
- 실제 작가 후기: "다달이 소액의 저작권료가 들어오기는 하나" — 사람이 매번 신청해서 받는 구조였다면 보통 이런 식으로 서술하지 않음, 자동입금을 시사
- **다만 공식 문서로 100% 확정은 못했음** — 카카오가 "출금 신청" 절차의 존재 여부를 명시적으로 밝힌 1차 자료를 못 찾아서, 심증 수준의 결론. 실제 승인·판매 개시 시점에 재확인 필요
