## 제작 진행 상황 (2026-08-08)

**연결 확인**: 금고의 `leonardo_api_key`로 Leonardo AI API(`https://cloud.leonardo.ai/api/rest/v1/`) 호출 성공. `curl`이 자동승인 분류기에 막히지 않았음 — vault 문서의 "알려진 이슈"는 이번엔 재현되지 않음.

**스타일 확립**: Phoenix 1.0 모델(`de7d3faf-762f-48e0-b3b7-9d0ac3a3fcf3`) + `presetStyle: ILLUSTRATION` + 고정 시드(87008451)로 "작은 원형 로봇, 안테나 하나, 모니터 얼굴, 민트그린 몸통, 통통한 팔다리, 두꺼운 검은 외곽선, 스티커 스타일" 프롬프트를 여러 번 테스트. **같은 시드 + 같은 몸통 프롬프트 + 표정(눈/입) 문구만 교체**하는 조합에서 몸통·비율·색상·안테나·가슴 버튼 장식까지 놀라울 정도로 일관된 "같은 캐릭터"가 나옴 (테스트 결과: 표정 3종 비교 그리드에서 확인). 이 조합을 정본 프롬프트로 채택.

- 배경은 Leonardo가 투명배경을 직접 지원 안 해서(`transparency` 파라미터를 Phoenix/Flux/Kino 계열 여러 모델에 시도했으나 전부 "Transparency is not enabled with X" 오류) **단색 마젠타 배경으로 생성 후 색상거리 기반 크로마키 + 엣지 디컨탐(edge decontamination)으로 알파 채널을 직접 계산**하는 후처리 파이프라인을 구현함 (`numpy` 기반, 배경색을 이미지별 모서리 픽셀에서 샘플링해 대응 — 이미지마다 마젠타 톤이 미묘하게 달라서 고정값 대신 매 이미지 자동 샘플링).

**정지형 1~12번 제작 완료**: A3 문서의 문구 리스트 1~12번 전부 실제 이미지 생성 → 배경 제거 → 360×360 정사각 크롭 → 72dpi RGB PNG로 후처리 완료. 전량 150KB 이하(92.7KB~110.8KB, 요건 이내). 결과물: `company/execution/products/kakao-emoticon-art/01-annyeonghaseyo.png` ~ `12-baepohaessseumnida.png` (파일명에 번호+문구 슬러그), 미리보기용 12종 합본은 `00-contact-sheet-preview.png`.

**표정 설계 원칙**: 캐릭터 컨셉의 "눈+입 두 가지 요소로 감정 표현" 원칙을 지켜 몸통·팔다리·자세는 절대 바꾸지 않고, 눈/입 모양과 (일부) 캐릭터 옆 작은 이모지 아이콘(느낌표·체크·땀방울·하트·반짝임 등)만 문구별로 다르게 프롬프트에 넣음 — 이게 카카오 심사가 보는 "32종이 같은 캐릭터"인지 판단 기준에 가장 안전한 접근이라고 판단.

### 품질에 대한 정직한 평가

- 전체적으로 12장이 "같은 캐릭터"로 보이는 일관성은 확보됨 (몸통 비율·색상·안테나·가슴 장식이 거의 동일).
- 다만 AI 생성물 특유의 미세한 개체차가 있음: 3번(확인했습니다)은 머리 형태가 다른 것들보다 조금 더 둥글고 팔다리가 덜 뚜렷함, 4번(넵... 억지대답)은 안테나 끝이 잎 모양처럼 나온 변형이 있음, 5번(퇴근하고싶다)은 "지침" 느낌은 나지만 기획서의 "어지러운/축 처진" 뉘앙스가 의도만큼 강하게 안 살았음(아이콘·눈 모양을 더 과장하면 개선 가능).
- **붓터치·일러스트 완성도**: Leonardo Phoenix 결과물은 벡터 일러스트가 아니라 래스터 AI 생성물이라 확대하면 선이 손그림처럼 완벽히 매끈하진 않음(선 두께가 부위별로 미세하게 불균일). 카카오 심사가 정확히 어느 수준을 "완성도 미달"로 보는지는 실제 제출 전엔 확정할 수 없음 — **1차 판단: 심사 제출 가능한 수준이라고 보이나, 100% 확신은 못 함. 회장 육안 확인을 권장.**
- 크로마키 후처리는 체커보드 배경 위 검수 결과 마젠타 번짐(halo) 없이 깔끔하게 빠짐 — 이 부분은 기술적으로 안정적.
