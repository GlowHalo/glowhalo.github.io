# A3 실행 준비 — 카카오톡 이모티콘 "일잘봇"

> 2026-08-06, 6시간 자율 생산 구간. **A3는 실제 캐릭터 일러스트가 필요한데 이 세션엔 이미지 생성 도구가 없다.** 그래서 "AI가 끝까지 만들 수 있는 부분"까지만 준비하고, 최종 아트워크는 회장이 일러스트레이터 섭외나 별도 이미지 생성 도구로 채워야 하는 지점을 명확히 표시해둔다.

## 제출 요건 (카카오 이모티콘 스튜디오, 직접 조사해 확정)

| 구분 | 제안(심사) 단계 | 승인 후 최종 제작 |
|---|---|---|
| **멈춰있는 이모티콘** | PNG 32종, 360×360px, 투명배경, 1개당 150KB 이하, 72dpi RGB | 제안 시안과 동일(별도 재작업 없음) |
| **움직이는 이모티콘** | GIF 3종(흰 배경, 애니메이션) + PNG 21종(투명배경, 정지) = 총 24종 | 승인 후 WEBP 포맷으로 24종 전체 애니메이션 제작 |

심사 기간 약 2~4주. **정지형이 제작 난이도·리스크가 낮아 1차로 이걸 추천** — 애니메이션은 승인 후 GIF가 아니라 WEBP로 다시 만들어야 해서 공정이 하나 더 필요함.

## 캐릭터 컨셉 — "일잘봇"

- **정체성**: 작은 원형 로봇 마스코트. 안테나 하나, 모니터 모양 얼굴에 표정만 바뀜(눈+입 두 가지 요소로 감정 표현 — 그림 난이도를 낮추면서도 카카오에서 검증된 "심플 캐릭터" 문법 그대로 따름, 예: 오조오억·잔망루피류 성공 사례와 같은 축)
- **색상**: 민트/시안 계열(#3FA66B 인접 톤) — 우리 브랜드(가상 사무실 CMO 컬러)와 자연스럽게 연결되면서도, 기존 카카오 이모티콘 시장의 노랑/핑크 포화 색상군과 차별화
- **타겟**: 직장인·개발자·1인 창업자 — "회사에서 못 하는 말을 로봇이 대신 해준다"는 톤. 이미 검증 중인 A1/A2 타겟(인디해커/솔로 창업자)과 결이 겹쳐서, 나중에 로열티 유입처를 서로 교차 홍보할 여지도 있음
- **한 줄 컨셉**: "일은 잘하고 싶은데 마음은 딴 데 있는 직장인의 속마음을 대신 표현하는 로봇"

이미지 생성 도구 없이도 확인 가능한 범위까지는 시도함 — 헤드리스 브라우저로 HTML/CSS를 그려서 360×360 PNG 3장을 만들어봄(`company/execution/products/kakao-mockups/`). **이건 실제 제출용 아트워크가 절대 아니고**, 손 그림이 아니라 도형 조합이라 카카오 심사 기준(붓터치·일러스트 완성도)에 못 미침 — 색감·구도 방향성만 회장이 감 잡는 용도.
