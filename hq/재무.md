# GlowHalo Group 재무 관리

**상태**: 신설(2026-08-10, 회장 지시). 지금은 전 계열사 매출 0원, 비용만 소액 발생/예정인 초기 단계.

## 원칙

- **관리 기준은 개인사업자(회장 명의) 준용.** 아직 실제 사업자 등록 전이지만, 나중에 사업자를 낼 때 그대로 옮길 수 있도록 지금부터 "매출 / 필요경비 / 자본금"을 구분해서 기록한다.
  - **매출**: 실제 판매·서비스 대가로 들어온 돈.
  - **필요경비**: 매출을 만들기 위해 나간 돈 — 플랫폼 수수료, API·툴 구독료, 1회성 등록비 등.
  - **자본금(출자)**: 경비가 아니라 밑천으로 넣은 돈(예: GlowHalo 3 초기자금 30만원). 손익 계산에 넣지 않고 별도 추적한다.
  - **순손익 = 매출 − 필요경비** (자본금 제외)
- **공용 툴/인프라는 HQ가 관리한다.** 여러 계열사가 같이 쓰는 것(Cloudflare, Browserbase, 금고 등)은 특정 계열사 비용으로 나누지 않고 이 문서에서 HQ 공용 경비로 관리한다. 계열사 전용 툴(예: 업비트는 컴퍼니3만)은 해당 계열사 `재무.md`에 기록.
- **기록 시점**: 실제로 결제/입금이 확정된 시점에 기록한다. "승인 대기"·"예정"은 상태 컬럼에 표시하고 합계에는 넣지 않는다.
- **각 계열사는 자기 `company*/재무.md`를 스스로 갱신한다** — 매출·지출이 발생하면 그 즉시 해당 세션이 기록. 이 문서(HQ)는 공용 비용 + 전체 롤업만 다룬다.

## Cloudflare Workers Paid ($5/월) — 결제 완료, 계기 기록

브라우저 자동화 유료화가 필요해지면 **Browserbase Developer($20/월)보다 Cloudflare Workers Paid($5/월)를 먼저 추천**한다.

| | Cloudflare Workers Paid | Browserbase Developer |
|---|---|---|
| 월 비용 | **$5** | $20 |
| Browser Rendering | 10시간/월(현재 하루 10분→월 최대 300분에서 **600분**으로, 동시 3→10개) | 100시간/월(별도 서비스) |
| 부가 효과 | Workers 요청 한도·KV·Durable Objects 등 **그룹 전체가 쓰는 Cloudflare Worker(vault, glowhalo-hq API, niche-api link-preview 등)에도 같이 적용** | 브라우저 자동화 외 효과 없음 |

이유: (1) 4배 싸다, (2) 이미 여러 관계사 Worker가 무료 티어 한도에 서서히 다가가고 있어(공용 자원이라 동시 사용이 잦음) 어차피 조만간 필요해질 업그레이드다, (3) Browserbase는 백업 용도로만 쓰면 충분해서 무료 플랜 그대로 유지 가능. **승인해주시면 Cloudflare 대시보드 결제만 회장님이 하시고(카드 등록 필요, Claude가 대신 못하는 영역), 이후 설정은 제가 처리하겠습니다.**

## 결제 채널 전략 — PayPal 우선순위 (2026-08-23 회장 지시)

**아직 특정 상품/계열사에 매인 지시는 아님 — 앞으로 새 상품이 나올 때마다 기본으로 참고할 방향.**

- **PayPal을 우선순위 높은 결제수단으로 적극 붙인다.** PayPal Business 계정은 이미 완전히 정비됨(표준계정·2FA·국내 IBK 계좌 연결·claude.ai 커넥터까지 전부 완료 — 계정원장 참고). 새 상품을 낼 때 결제 채널을 고를 일이 생기면 PayPal을 기본 후보에 넣고 검토한다.
- **또는, 고객이 여러 결제 플랫폼 중 선호하는 걸 직접 고를 수 있게 세팅한다** — 하나로 고정하지 않고 Stripe/PayPal/Lemon Squeezy 등 옵션형 구조로. 어떤 상품에 어떤 조합이 맞을지는 그 상품이 실제로 정해질 때 판단.
- 지금 당장 착수할 구체 작업은 없음(대상 상품 미정) — 다음에 계열사가 결제수단을 고르는 시점(예: 브리프AI의 Stripe/Paddle/PayPal/Creem.io/Polar.sh/FastSpring 선택 등)에 이 방향을 먼저 고려한다.
