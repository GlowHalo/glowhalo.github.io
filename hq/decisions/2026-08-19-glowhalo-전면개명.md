## 결정한 것

1. **표기 우선순위**: **영문 "GlowHalo" 1순위.** 이유 — GitHub 계정·도메인·마켓플레이스(Gumroad·Etsy·Product Hunt 등)가 전부 라틴 문자 고정이라 기술적 앵커가 영문이고, 이름 자체가 영어 합성어(Glow+Halo)라 한글 표기(글로우헤일로)는 발음 표기에 가까움. 한국어 문장 안에서도 "GlowHalo"를 라틴 문자 그대로 쓰는 걸 기본으로 하되(국내 스타트업들이 자기 조어형 영문명을 한글 문장에도 그대로 쓰는 관행과 동일), 카카오 등 완전히 한국어 플랫폼의 작가명처럼 라틴 문자가 어색한 자리에는 "글로우헤일로"를 병기.
2. **그룹명**: "나다그룹" → **"GlowHalo Group"**(정식), 한글 문서에선 "글로우헤일로 그룹"도 병기 가능. "그룹"이라는 단어 자체는 회장이 선호를 밝힌 적 있어(2026-08-18 후보 목록에 "나다그룹" 포함) 의도적으로 유지.
3. **계열사 번호 표기**: "나다컴퍼니N" → **"GlowHalo N"**("컴퍼니/Company" 접미어는 제거 — 애초에 회장이 "컴퍼니"라는 단어 자체를 "좀 별로"라고 평했던 것과 같은 맥락). 예: 나다컴퍼니1 → GlowHalo 1, 나다컴퍼니12 → GlowHalo 12.
4. **개인 대표 페르소나 이름(정연·하윤·은성·채원·라온·시우·도현·예슬·다연·은우·이든·지호·다온)은 그대로 유지** — 이건 그룹명이 아니라 개별 캐릭터 이름이라 개명 대상 아님.
5. **작업 순서**: 저장소 이전보다 **개명을 먼저** 이 저장소(`tossneon/tossneon.github.io`) 안에서 끝내고, 완성된 최종 상태를 그대로 새 저장소(`glowhalo/GlowHalo.github.io`)로 미러 이전한다 — 같은 작업을 두 번 하지 않기 위함.
6. **역사 기록은 손대지 않는다**: `hq/decisions/2026-08-11-그룹명-리브랜딩-검토.md`처럼 "그때 이름이 무엇이었는지"가 서술의 핵심인 문서는 본문을 고치지 않고 맨 위에 개명 사실만 각주로 추가한다 — 안 그러면 "나다그룹/나다컴퍼니가 실제 회사와 충돌하는지 검토"라는 문서의 논지 자체가 깨진다.
