# 나다그룹/나다컴퍼니 리브랜딩 검토

**상태**: 🟡 보류 — 실제 사업자 등록 시점에 다시 결정 (2026-08-11 회장 확정: "회사명은 나중에 사업자 낼 때 고민하자. 일단 현재 나다컴퍼니 그대로.")

**제기**: 회장 — "나다그룹"/"나다컴퍼니" 상표 써도 되는지 문의하면서 시작.

## 배경

"나다그룹"/"나다컴퍼니"가 실제 상표·상호와 충돌할 수 있는지 검토하다가, 발음이 거의 같은 **"난다"(주식회사 난다, 스타일난다/3CE, 2018년 로레알 인수)**와의 유사 위험, 그리고 **"나다컴퍼니"라는 동명의 실제 회사**가 이미 존재한다는 걸 발견했다. 다만 지금은 이 이름이 내부 조직명·문서·비공개에 가까운 내부 대시보드로만 쓰이고 있어 법적 문제 가능성은 낮다고 판단, 실제 상표등록·정식 브랜드 확정 전에 대안을 미리 탐색해두기로 했다.

## 탐색 과정 (요약)

회장이 준 소스(해·수박·자동화·돕는마음·꾸준하게·길게·동그라미·배려)를 바탕으로 여러 라운드에 걸쳐 후보를 좁혔다. 최종 압축된 방향은 "은은하게 빛나는 행성" — 스스로 타오르지 않고 빛을 받아 부드럽게 반사하며, 정해진 궤도를 꾸준히 도는 이미지.

**최종 Top 2**:

| 후보 | 뜻 | 비고 |
|---|---|---|
| **오르빗(Orbit)** | 해(회장+Claude)를 중심으로 계열사들이 각자 궤도를 도는 지금 조직 구조를 그대로 담음 | 국내외 검색 충돌 없음, 구조적 정합성 가장 높음 |
| **오브(Orb)** | 손에 쥔 구슬처럼 안에서부터 은은하게 빛나는 이미지, 서사보다 물성 | 국내는 깨끗하나, **영어 브랜드로는 주의 필요** — Worldcoin(현 World Network)의 홍채인식 기기 "ORB"가 미국에 실제 상표 출원돼 있고(Tools For Humanity Corp, 일련번호 90882382) AI 업계에서 유명·논쟁적이라 혼동 위험 있음 |

탐색 중 제외한 후보들과 이유(라운드컴퍼니=동명 아동복 회사, 스피어=코스닥 상장 항공우주/바이오 기업, 풀문=제주 행사기획사 등 실존 충돌)와 전체 후보 목록·실사용 목업(대시보드/Gumroad/파비콘)은 아래 아티팩트에 정리되어 있다.

- 비교 아티팩트: https://claude.ai/code/artifact/dc1a0106-8fdc-4097-acd3-c03d1afd4712

## 검증 한계 — 명확히 남겨둠

이 검토는 전부 **일반 웹 검색 기준**이다. 키프리스(KIPRIS) 정식 상표 데이터베이스는 이 세션 도구로 직접 조회하지 못했다(첫 페이지가 자바스크립트 리다이렉트 껍데기라 실제 검색 결과는 로그인/JS 상호작용 뒤에 있음). 공공데이터포털(`data.go.kr`)에 KIPRIS 상표검색을 공개 REST API로 제공하는 서비스가 있어 무료가입으로 정식 조회가 가능하다는 것까지는 확인해뒀다 — 실제 상표등록을 진행할 시점에 이 API로 재검증하거나 변리사 확인을 거칠 것.

## 다음에 이 안건을 다시 열면

1. 위 두 후보(오르빗/오브)부터 검토 시작 — 이미 상당한 조사가 돼 있음.
2. 시간이 지났으면 웹 검색을 한 번 더 돌려서 그사이 새로 생긴 동명 회사·상표가 없는지 재확인(특히 "오브"는 Worldcoin 관련 뉴스가 계속 나오는 영역이라 상황이 바뀔 수 있음).
3. 정식으로 굳히기 전 KIPRIS Open API(`data.go.kr`) 또는 변리사로 최종 확인.
4. 확정되면 로고 톤(은은한 인디고/네이비 + 소프트 글로우)·nada-group 대시보드·Gumroad 스토어명·문서 전반의 "나다그룹/나다컴퍼니" 표기 교체까지 진행.
