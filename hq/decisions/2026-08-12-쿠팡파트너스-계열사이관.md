# 결정: 쿠팡파트너스 딜봇(C1)을 나다컴퍼니2에서 별도 계열사로 이관

**상태**: 확정(회장 지시, 2026-08-12) — 담당 계열사는 미정, 배정되는 대로 이 문서와 원본 문서에 기록

## 배경

나다컴퍼니2(하윤)는 Round 1~4에서 두 트랙을 병행 검증했다 — B1(니치 API 프로덕트/RapidAPI Hub)과 C1(쿠팡파트너스 특가 알림 채널 "나다특가"). 회장이 다음과 같이 정리 지시:

1. 나다컴퍼니2는 앞으로 **니치 API 프로덕트를 메인 사업으로 추진**한다 — RapidAPI 하나에 의존하지 않고 대상 플랫폼을 최대한 넓힌다(Zyla API Hub, APILayer, LimitPear 등 — 상세는 [`company2/products/니치API-플랫폼-전략.md`](../../company2/products/니치API-플랫폼-전략.md)).
2. **C1(쿠팡파트너스)은 별도 계열사로 업무를 이관**한다. 나다컴퍼니2는 더 이상 이 트랙을 진행하지 않으며, 진행하던 내용은 참고 자료로만 남긴다.

- 라이브 서비스: https://nada-company2-coupang-dealbot.tossneon.workers.dev (디스코드 "나다특가" 채널에 실제 게시 중)

## 담당 계열사 배정 시 할 일

1. 이 문서와 `company2/products/coupang-dealbot/README.md`의 "담당 계열사" 표기를 확정된 계열사명으로 갱신.
2. 필요하면 `company2/products/coupang-dealbot/` 폴더를 새 계열사 폴더로 `git mv` — Cloudflare Worker는 그룹 공용 계정에 있어 재배포 없이 그대로 유지됨.
3. `company2/candidates.md`의 C1 항목 상태도 "이관 완료"로 갱신, 새 계열사의 `candidates.md`(또는 상응 문서)에 정식 편입.
