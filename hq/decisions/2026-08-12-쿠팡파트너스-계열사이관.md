# 결정: 쿠팡파트너스 딜봇(C1)을 GlowHalo 2에서 별도 계열사로 이관

**상태**: 완료(회장 지시, 2026-08-12) — **GlowHalo 7(대표 도현) 신설·배정 완료.** 폴더도 `niche-api/products/coupang-dealbot/` → `coupang-partners/products/coupang-dealbot/`로 실제 이동(git mv, 배포 URL은 그대로 유지).

## 배경

GlowHalo 2(하윤)는 Round 1~4에서 두 트랙을 병행 검증했다 — B1(니치 API 프로덕트/RapidAPI Hub)과 C1(쿠팡파트너스 특가 알림 채널 "나다특가"). 회장이 다음과 같이 정리 지시:

1. GlowHalo 2는 앞으로 **니치 API 프로덕트를 메인 사업으로 추진**한다 — RapidAPI 하나에 의존하지 않고 대상 플랫폼을 최대한 넓힌다(Zyla API Hub, APILayer, LimitPear 등 — 상세는 [`niche-api/products/니치API-플랫폼-전략.md`](../../niche-api/products/니치API-플랫폼-전략.md)).
2. **C1(쿠팡파트너스)은 별도 계열사로 업무를 이관**한다. GlowHalo 2는 더 이상 이 트랙을 진행하지 않으며, 진행하던 내용은 참고 자료로만 남긴다.
