# 저장소 이름 — 현행 유지, 커스텀 도메인은 필요시 나중에 (2026-08-13 회장 확정)

## 배경
Notion 워크스페이스를 "나다컴퍼니"로 분리·정비한 것처럼, GitHub 저장소(`tossneon/tossneon.github.io`)도 이름을 바꾸거나 새로 만들어 정리하고 싶다는 논의가 있었음.

## 검토한 옵션
- **A안 — 커스텀 도메인만 연결**: 저장소·계정은 그대로, 도메인만 구매해 GitHub Pages에 연결. 방문자는 새 브랜드 도메인만 보게 됨. 위험 없음, 되돌리기 쉬움.
- **B안 — 새 GitHub Organization으로 이전 + 이름 변경**: Notion의 "새 워크스페이스"에 가장 가까운 개념이지만, GitHub Pages는 저장소 이름이 바뀌면 기존 URL이 리다이렉트 없이 그대로 죽는다 — 이미 외부(Gumroad·itch.io·RapidAPI 등)에 뿌려진 모든 상품/게임 링크가 한 번에 깨짐. 실익 대비 리스크가 안 맞음.
- **C안 — 현행 유지**: 저장소 이름·구조 그대로. 내부 문서는 이미 전부 "GlowHalo Group"/"나다컴퍼니"로 부르고 있어서, `tossneon.github.io`는 순수 기술적 호스팅 주소일 뿐.

## 결정
**C안(현행 유지)** — 저장소 이름·계정 그대로 둔다. **B안(조직 이전+이름변경)은 하지 않는다.**
**커스텀 도메인(A안)은 지금 당장 사지 않고, "필요한 상황이 되면"(예: 브랜드 노출이 실제로 사업에 문제가 될 때) 그때 구매해서 덮기로 한다** — 지금은 대기 상태.

## 후속 조치
- 외부에 "tossneon" 브랜드가 불필요하게 노출되지 않도록 별도로 점검(공개저장소 내용·상품 페이지 등) — 진행 중, 결과는 별도 기록 예정
- 저장소 내부 폴더 구조(companyN 등) 정비는 별도 논의 — 저장소 이름 자체와는 독립적인 주제
