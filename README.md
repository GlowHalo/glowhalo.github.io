# glowhalo.github.io

이 저장소는 GlowHalo Group의 **배포 전용 공개 저장소**입니다. 개발 작업은 여기서 하지 않습니다.

- 승인된 공개 항목만 이 저장소의 루트에 올라옵니다. 승인 절차·판단 기준은 비공개 작업저장소의
  `.claude/rules/repo-visibility.md`를 따릅니다.
- 히스토리는 2026-09-04에 정리(초기화)됐습니다 — 이전 히스토리가 필요하면 비공개 작업저장소
  (`glowhalo-hub`)에 전체가 보존돼 있습니다.
