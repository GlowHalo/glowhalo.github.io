## GlowHalo 1 A5 · GlowHalo 9 E2와의 관계 — 흡수는 확정, 플랫폼은 검토 중

GlowHalo 1(정연)의 A5(니치 유료 뉴스레터, 컨셉명 "The Independent Board")가 **이미 콘텐츠·가격·창간호 초안까지 완성돼 있고**, 결제 수단으로 **스티비(Stibee)**를 쓰기로 검증까지 끝난 상태였다([niche-templates/candidates.md](../niche-templates/candidates.md) A5 항목, [niche-templates/execution/A5-newsletter.md](../niche-templates/execution/A5-newsletter.md)). GlowHalo 9(다연)의 Round 1 서칭에서도 독립적으로 "E2 니치 AI 뉴스레터"가 Tier A 확정됐다([biz-scouting/candidates.md](../biz-scouting/candidates.md) E2).

**2026-08-12 회장 1차 지시로 방향 확정**: "정연이 검토했던 뉴스레터는 멈춘 상태고 은우가 흡수하는 게 좋겠다" → **A5를 GlowHalo 10이 승계하는 것으로 확정.** 다만 "유료 플랫폼을 지금은 쓰고 싶지 않다"며 플랫폼(스티비 유지 vs Beehiiv 등)은 폭넓게 점검 후 다시 논의하기로 함 — 은우가 스티비·Beehiiv·Substack·Ghost·Kit·Buttondown·MailerLite 7곳을 조사해 [`candidates.md`](candidates.md#뉴스레터-발행-플랫폼-폭넓은-비교-2026-08-12-회장-지시--최대한-많이-점검)에 비교표로 정리. **결론: "지금 당장 무료로 유료구독까지 가능한" 곳은 스티비·Substack·Ghost(셀프호스팅) 셋뿐이고, 이 중 API 자동화·콘텐츠 재사용까지 갖춘 건 스티비뿐 — 회장의 "현재안(스티비)"이 가장 타당.** 최종 확정은 회장 판단 대기.

## 플랫폼 비교 요약 (2026-08-12, 자동화 범위 조사 완료)

Beehiiv·스티비 포함 7개 플랫폼의 이용료/유료구독 조건/API/정산방식을 전부 비교한 표는 [`candidates.md`](candidates.md#뉴스레터-발행-플랫폼-폭넓은-비교-2026-08-12-회장-지시--최대한-많이-점검) 참고. 핵심만 요약하면: **스티비**(무료+API 있음+검증완료)가 회장의 "유료 플랫폼 지금은 안 씀" 제약에 가장 잘 맞고, **Beehiiv**(유료구독은 Scale $43/월부터)·**Kit**($39/월)·**MailerLite**($12/월)는 전부 유료구독을 켜는 순간 고정비가 생기며, **Substack**은 무료지만 공식 발행 API가 없어 자동화 원칙에 안 맞고, **Ghost 셀프호스팅**은 수수료 0%지만 서버 운영이라는 새 개입 지점이 생긴다.
