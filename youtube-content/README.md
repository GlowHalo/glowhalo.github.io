회장이 기존에 개인적으로 진행하던 유튜브 프로젝트 **"몬스터트럭 파닉스"**(Notion 워크스페이스에서 진행 중이던 유아용 한글/알파벳 파닉스 시리즈)를 GlowHalo Group 체제로 승격 편입한다 — `niche-templates/README.md`의 "개인 프로젝트와의 관계(포크형 vs 승격형)" 중 **승격형**에 해당. 원본 기획·자산은 Notion에 그대로 있고, 이 폴더는 GlowHalo Group 조직 문서(대표·재무·후보사업)만 관리한다.

## 제작 인프라 (2026-08-12 정정 — Notion "시리즈 세팅값" 원본 재확인)

원래 계획서엔 "이미지→비디오(Kling 등)"가 있었지만, **실제로는 2026-07-15~17에 "무편집·Vrew 단독" 노선으로 전환 완료**돼 있었다 — 외부 이미지/영상 생성 툴은 안 쓴다.

- **대본** → Vrew에 그대로 붙여넣기(flat, 빈 줄 없이 한 줄씩)
- **장면 이미지**: Vrew 3단계 "비디오 꾸미기"에서 자동 생성(모델 GPT Image 2 Low, 스타일 3D모델, 고화질 ON) — 대본 한 줄당 이미지 1장, Vrew가 자동으로 몇 줄씩 묶어줌. **Leonardo API는 이 파이프라인에선 안 씀** (금고에 있는 `leonardo_api_key`는 다른 용도 — 필요하면 재검토).
- **무음(pause) 삽입**: 회장이 이미 만들어둔 `inject-pause.ps1`(PowerShell) 스크립트로 `.vrew` 파일을 직접 조작 — 기술 사양은 세팅값 문서에 실측 검증까지 완료돼 있음.
- **성우/속도/자막강조/클립길이 등**: 전부 세팅값 문서에 고정값으로 확정돼 있어 매 회차 재논의 불필요.
- **Vrew 자체는 데스크톱 앱**이라 이 세션(클라우드)에서 직접 조작 불가 — 대본·장면 계획까지는 Claude가 준비하고, 실제 Vrew 조립·크레딧 소모·내보내기·업로드는 회장이 직접 진행(또는 향후 로컬 자동화 스크립트로 보완).
