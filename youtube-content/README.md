## 계열사 신설 배경 — 승격형 편입

회장이 기존에 개인적으로 진행하던 유튜브 프로젝트 **"몬스터트럭 파닉스"**(Notion 워크스페이스에서 진행 중이던 유아용 한글/알파벳 파닉스 시리즈)를 나다그룹 체제로 승격 편입한다 — `niche-templates/README.md`의 "개인 프로젝트와의 관계(포크형 vs 승격형)" 중 **승격형**에 해당. 원본 기획·자산은 Notion에 그대로 있고, 이 폴더는 나다그룹 조직 문서(대표·재무·후보사업)만 관리한다.

## 1호 사업 — 몬스터트럭 파닉스 🚑

- **컨셉**: 4세 유아용 한글/알파벳 발음학습 유튜브 시리즈. 몬스터트럭 캐릭터들이 등장해 글자 소리를 알려준다.
- **제작 파이프라인(2026-08-12 정정)**: 대본 작성 → Vrew에 flat 텍스트 붙여넣기(이미지 자동생성 내장, 외부 이미지/영상 툴 안 씀) → 무음삽입 스크립트(`inject-pause.ps1`) → 강조색 등 수동 보정 → 1080p 내보내기 → 유튜브 업로드. 상세는 아래 "제작 인프라" 참고
- **전체 계획**: 한글 모음 21종 → 한글 자음 19종 → 알파벳 26종, **총 66회차** 예정
- **진행 상황(2026-08-14 갱신 — 로컬 Google Drive 원본 대조 후)**: ㅏ 업로드 완료([영상](https://youtu.be/pfLhSzKvCGY)). ㅑ·ㅠ는 로컬에 `_완성.vrew`까지 있어 최종 검수·업로드만 남음(Notion 트래커가 그동안 실제보다 뒤처져 있었음, 이번에 동기화). ㅓ·ㅕ·ㅗ는 대본 완성, Vrew 작업 전. 나머지는 기획 단계. 상세는 `execution/2026-08-14-*` 로그 참고.
- **원본/상세 관리처**: Notion — [몬스터트럭 파닉스 메인 페이지](https://app.notion.com/p/3bbdea9b558f81baa31cce899c84fb9c) (2026-08-13 "나다컴퍼니" 전용 워크스페이스로 이관된 버전, 이 세션 Notion 연동이 가리키는 현재 링크 — 예전 링크(`39efc7dfab7...`)는 이 세션에서 더 이상 연결 안 됨, 회장 확인 필요). 이 저장소엔 진행 로그·의사결정만 `execution/`에 남긴다.
- **Vrew 작업 파일 저장소**: Google Drive `G:\내 드라이브\claude\몬스터카파닉스` (회장 PC 로컬 동기화 경로) — `.vrew` 프로젝트 파일과 대본 텍스트를 여기 모아두고, 라온이 Drive API로 오가며 표준화 작업을 하는 왕복 폴더.

## 제작 인프라 (2026-08-12 정정 — Notion "시리즈 세팅값" 원본 재확인)

원래 계획서엔 "이미지→비디오(Kling 등)"가 있었지만, **실제로는 2026-07-15~17에 "무편집·Vrew 단독" 노선으로 전환 완료**돼 있었다 — 외부 이미지/영상 생성 툴은 안 쓴다.

- **대본** → Vrew에 그대로 붙여넣기(flat, 빈 줄 없이 한 줄씩)
- **장면 이미지**: Vrew 3단계 "비디오 꾸미기"에서 자동 생성(모델 GPT Image 2 Low, 스타일 3D모델, 고화질 ON) — 대본 한 줄당 이미지 1장, Vrew가 자동으로 몇 줄씩 묶어줌. **Leonardo API는 이 파이프라인에선 안 씀** (금고에 있는 `leonardo_api_key`는 다른 용도 — 필요하면 재검토).
- **무음(pause) 삽입**: 회장이 이미 만들어둔 `inject-pause.ps1`(PowerShell) 스크립트로 `.vrew` 파일을 직접 조작 — 기술 사양은 세팅값 문서에 실측 검증까지 완료돼 있음.
- **성우/속도/자막강조/클립길이 등**: 전부 세팅값 문서에 고정값으로 확정돼 있어 매 회차 재논의 불필요.
- **Vrew 자체는 데스크톱 앱**이라 이 세션(클라우드)에서 직접 조작 불가 — 대본·장면 계획까지는 Claude가 준비하고, 실제 Vrew 조립·크레딧 소모·내보내기·업로드는 회장이 직접 진행(또는 향후 로컬 자동화 스크립트로 보완).
