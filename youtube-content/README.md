### 왜 GlowHalo 5만 개인 계정을 쓰는가 (헷갈리지 말 것)
그룹 전체는 표준계정 `tossneon0@gmail.com`으로 통일 중이지만, **GlowHalo 5는 의도적 예외**다. `.claude/rules/cloudflare-vault.md`의 "Google Drive — 계정 두 개를 용도별로 나눠 쓴다(2026-08-23 회장 확정)" 원칙이 **"유튜브 영상 원본·편집 소스는 회장 개인 드라이브를 쓴다"**고 명시하고 있고, 채널 자체도 개인 계정에 있다. 즉 채널·Notion·Drive 세 축이 전부 개인 계정으로 일관돼 있는 게 **설계대로**다.

- 단, 같은 규칙에 "세션이 자동화로 Drive를 쓰게 되면 착수 전 어느 계정인지 확인하고, 개인 드라이브면 회장에게 알릴 것"이라는 단서가 있다 — GlowHalo 5는 **개인 드라이브를 자동화로 쓰는 유일한 사례**이므로 이 단서에 해당한다. 2026-08-25 회장에게 보고했고, 파이프라인이 정상 동작 중이라 현행 유지.
- 반대로 **Gmail MCP는 표준계정(`tossneon0`)에 붙어 있다**(CLAUDE.md 2026-08-17). 즉 이 세션의 Drive/Notion은 개인계정, Gmail은 표준계정으로 **서로 다른 계정**에 연결돼 있다 — 개인 계정 메일함이 필요한 작업(예: 유튜브 관련 구글 알림 확인)은 이 세션에서 불가하다.

### 유튜브 업로드 자동화 선결과제 (5단계 블로커)
1. **YouTube Data API v3 OAuth** — 채널이 있는 `tossneon@gmail.com` 계정으로 Google Cloud 프로젝트 생성 → API 활성화 → OAuth 클라이언트 발급 → 1회 동의로 refresh token 확보 → 금고에 `youtube_*`로 등록. **동의 화면 클릭은 회장만 가능**(금고 `google_login_password` 항목: 자동화 브라우저의 구글 로그인은 구조적으로 차단, 2FA도 SMS/패스키).
2. 등록 이름은 그룹 공용 규칙에 맞춰 `youtube_oauth_client_id` / `youtube_oauth_client_secret` / `youtube_refresh_token` 으로 한다 — **다른 계열사도 유튜브를 쓰게 될 수 있으므로 `glowhalo5_` 접두어를 붙이지 않는다**(금고는 저장소 전체 공용).
