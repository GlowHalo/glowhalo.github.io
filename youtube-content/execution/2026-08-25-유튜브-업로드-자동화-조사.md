# 2026-08-25 — 유튜브 업로드 자동화: 실현 가능성 조사

회장 지시("네가 자동으로 업로드 할 방법을 잘 찾아봐")에 따라 조사. **결론부터: 진짜 병목은 자격증명이 아니라 구글의 컴플라이언스 심사(audit)다.**

## 핵심 사실 (2026-08-25 웹 확인, 기억 아님)

1. **심사 안 받은 API 프로젝트로 업로드한 영상은 전부 비공개로 잠긴다.** 2020-07-28 이후 생성된 프로젝트에 적용. ([공식 도움말](https://support.google.com/youtube/answer/7300965), [Videos: insert 문서](https://developers.google.com/youtube/v3/docs/videos/insert))
2. **그 잠금은 스튜디오에서 손으로 못 푼다.** 구글 도움말 원문: *"Unlike user-selected private videos, you will not be able to change the video's state until after you have successfully submitted the video for re-review."* → "API로 올리고 회장이 수동으로 공개 전환" 이라는 우회로는 **없다.**
3. **할당량(quota)은 더 이상 문제가 아니다.** 예전엔 `videos.insert`가 1회 1,600 units라 하루 6개가 한계였는데, **2025-12 구글이 약 100 units로 인하** — 기본 무료 10,000 units/일로 **하루 약 100개** 업로드 가능. 66회차 전체를 하루에 올려도 남는다. ([Phyllo 정리](https://www.getphyllo.com/post/youtube-api-limits-how-to-calculate-api-usage-cost-and-fix-exceeded-api-quota), [공식 quota 문서](https://developers.google.com/youtube/v3/guides/quota_and_compliance_audits))
4. **심사 내용**: 사용 사례 상세 기술 + OAuth 흐름 시연 영상 + 개인정보처리방침/이용약관 + YouTube API ToS 동의. **소요 2~4주**, 반려 사례도 흔함.
5. **제3자 서비스 우회**: Buffer·Publer 같은 이미 심사를 통과한 스케줄러를 쓰면 공개 업로드가 되지만 전부 유료 구독이고, 그쪽에 우리 채널 OAuth를 내줘야 한다. n8n은 2025-06 기준 미검증이라 같은 벽에 막힌다.

## 선택지

| 안 | 내용 | 자동화 수준 | 비용 | 리드타임 |
|---|---|---|---|---|
| **A. 자체 심사 통과** | Google Cloud 프로젝트 만들고 컴플라이언스 심사 신청 | **완전 자동**(라온이 메타데이터·썸네일·공개예약까지) | 무료 | 2~4주, 반려 가능 |
| **B. 심사 통과한 제3자 스케줄러** | Buffer/Publer 등에 채널 연결 | 부분 자동(그쪽 API 경유) | 유료 구독 | 즉시 |
| **C. 회장 수동 업로드** | 스튜디오에서 드래그&드롭, 예약공개 | 없음 | 무료 | 즉시 |

**라온 권고: A를 목표로 하되, 첫 10회차는 C로 먼저 내보낸다.** 심사는 "실제로 돌아가는 앱"을 보여줘야 통과 확률이 높은데, 채널에 영상이 하나도 없는 상태보다 실제 시리즈가 굴러가는 편이 유리하다. B는 월 구독이 나가고 채널 OAuth를 외부에 내주는 값을 치르는데, 우리 업로드 빈도(주 1~2회)로는 수지가 안 맞는다.

## ⚠️ 회장 결정 대기 중인 "표준계정 이전"과의 연결 — 심사보다 먼저 정해야 한다

회장이 "유튜브 채널을 표준계정에서 진행할지 고민 중"이라고 했다. **이 결정을 심사 신청보다 먼저 내려야 한다** — 심사는 API 프로젝트 단위로 붙고, 프로젝트는 채널을 소유한 구글 계정과 묶어 만드는 게 정상이다. 심사를 통과한 뒤 채널을 옮기면 재신청 리스크가 있다.

**표준계정(`tossneon0@gmail.com`)으로 옮기는 쪽이 자동화엔 유리하다:**
- 이 세션의 **Gmail MCP가 표준계정에 붙어 있다**(CLAUDE.md 2026-08-17) → 구글이 심사 과정에서 보내는 메일을 **라온이 직접 읽고 대응**할 수 있다. 개인 계정에 있으면 매번 회장이 메일을 확인해 전달해야 한다.
- Cloud 프로젝트·채널·금고 자격증명이 전부 그룹 관리 아래로 들어온다(공용 인프라 원칙).
- 반대급부: 금고 규칙의 "유튜브 영상 원본·편집 소스는 회장 개인 드라이브"(2026-08-23 확정)와 어긋나게 된다 — 채널만 옮기고 편집소스는 개인 드라이브 유지도 가능하나, 그러면 계정이 다시 갈라진다.
- 채널 이전 자체는 브랜드 계정 전환/소유자 추가로 가능하지만 구독자·영상은 유지되되 절차가 번거롭다. **지금 채널에 테스트 영상 1개뿐이라 이전 비용이 가장 싼 시점이다.**

## 라온이 준비해둘 것 (회장 결정 전에도 가능)
- 업로드 스크립트 자체(메타데이터·태그·재생목록·예약공개 포함)는 자격증명 없이도 미리 작성·테스트 가능 → 심사 통과 즉시 가동.
- 심사 신청서에 넣을 "사용 사례 기술"과 개인정보처리방침 초안도 미리 작성 가능(회장이 검토만).
