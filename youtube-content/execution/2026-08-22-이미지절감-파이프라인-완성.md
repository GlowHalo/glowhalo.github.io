## 그로 인해 발견한 문제 2건 → 즉시 수정
### ① 무음넣기가 병합본을 못 찾음
`run-all-v2.ps1`은 `<회차>.vrew`만 찾는데 실제 저장 이름은 `<회차>_병합.vrew`다. 회차마다 이름을 바꾸게 하는 건 마찰이므로 **스크립트가 폴백하도록 수정**:
`<회차>.vrew` 없으면 → `<회차>_병합.vrew` 사용(`(using merged file)` 표시).

### ② 병합 재실행이 이미지를 날릴 위험 ★
`1단계_클립병합.cmd`를 다시 돌렸을 때 `_raw.vrew`의 타임스탬프가 더 최신이면 **이미지가 들어간 `_병합.vrew`를 덮어써서 84크레딧이 증발**한다.
→ `merge-all.ps1`에 **하드 가드** 추가: 출력 파일 zip 안에 `.png/.jpg/.jpeg/.webp`가 하나라도 있으면 타임스탬프와 무관하게 **무조건 건너뛴다**.
```
[!] merged file already has generated images - SKIP (protecting credits)
```

두 스크립트 모두 **완전 ASCII**로 재작성해 Drive 교체 완료.
