# 2026-08-21 — ㅜ(우) 회차: "짧은 붙여넣기 + 무음 v2" 크레딧 절감 작전

## 배경 (요 회차 실험 결과)
ㅛ(요) 14줄 붙여넣기 → Vrew가 줄바꿈 무시하고 **문장/구두점 기준으로 ~23클립 재분할** → 이미지 23장 생성(절감 실패). "붙여넣기 줄 수로 클립 수 제어" 가설 기각. [클립 합치기]는 매 회차 수작업이라 비효율.

## 회장 확정 작전
붙여넣기를 **장면당 1문장으로 짧게(종결부호 .!? → 쉼표)** 써서 Vrew가 문장분할할 거리를 없앰 → 클립·이미지 최소화. 그 대신 최종 자막·구조는 **무음 스크립트가 대본대로 복원**한다.

## 구현 — inject-pause **v2** (핵심)
v1은 최종 자막/단어 텍스트를 `.vrew`(붙여넣기)에서 가져왔다. v2는 **대본(`_대본.txt`)에서 가져온다.** 실제 코드 차이 3곳:
- (A) 단어 정합성 경고 비교 시 구두점 무시(쉼표 vs !? 노이즈 방지)
- (B) 자막 파트에 `$w.text`(vrew) → `$bare`(대본) 사용
- (C) 단어 json text에 `$w.text` → `$bare` 사용 (타이밍·assetId는 vrew 그대로)
→ 붙여넣기가 쉼표범벅이어도 **최종 자막은 대본 원문(느낌표·물음표 포함)으로 복원.** TTS 음성은 붙여넣기 기준이지만 쉼표/느낌표는 발음이 사실상 동일. 단어 **수·순서는 반드시 일치**해야 하며(라온이 로컬 검증: 우 230토큰 일치), 불일치 시 v1과 동일하게 word count mismatch로 안전 실패.
