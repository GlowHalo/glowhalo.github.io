# 2026-08-22 — 이미지 크레딧 절감 연구 종료, 실전 생산 전환

## 결론: 생성 수량은 통제 불가 (회장 확인)
- 3단계(비디오 꾸미기)에 **이미지 자동삽입을 끄는 옵션이 없다**(회장 화면 확인). "텍스트로 비디오 만들기" 마법사를 쓰는 한 이미지는 무조건 프로젝트 생성 시점에 자동 생성된다.
- 따라서 `merge-clips.ps1`(생성 전 병합)은 **투입 시점이 존재하지 않아 폐기.** Drive에서도 제거(오용 방지). 코드 이력은 커밋 46b85fe 이전 참조.
- 텍스트 조작(줄바꿈·구두점·쉼표 치환)도 전부 실패. Vrew는 **붙여넣기 한 줄이 약 57자 이하일 때만 1클립 유지**하고 넘으면 길이 비례로 쪼개는데, 낱말·인트로 블록이 구조상 57자를 넘어 회피 불가.
- **회장 결정: 지금까지 결과 중 최소값 수준(21~23클립)에서 받아들이고 실전 생산으로 전환.**

|---|---|---|
| ㅛ(요) | 표준 구두점 | 23 |

쉼표 치환은 1클립(≈6크레딧) 밖에 못 줄이면서 TTS 억양(!·?)을 죽이므로 **표준 구두점으로 확정.**

## 파이프라인 단순화 — 회차별 cmd 폐지
회차마다 cmd를 만들던 방식(`1단계_클립병합.cmd`/`2단계_무음넣기.cmd`)은 파일명 번호가 어긋나면 바로 실패한다(실제로 8.으 vs 9.으 불일치 발생). 폐기하고 **폴더 전체를 훑는 방식**으로 통일:
- `run-all-v2.ps1` + `무음넣기_전체.cmd` — 작업폴더의 모든 `*_대본.txt`를 찾아 같은 이름의 `.vrew`가 있으면 `_완성.vrew` 생성. vrew 없으면 조용히 건너뜀, 이미 최신이면 스킵.
- 즉 **회차 몇 개를 만들어놨든 cmd 한 번**이면 전부 처리된다.
