# C1 실행안 — 쿠팡파트너스 특가 알림 채널 (가칭 "나다특가")

후보 C1(쿠팡파트너스 제휴 마케팅)을 실제로 굴리기 위한 구체 실행안. AI 대량생산 콘텐츠에 대한 구글의 "Helpful Content" 정책 단속이 갈수록 엄격해지는 걸 리스크로 보고, **검색엔진 노출에 기대는 블로그형이 아니라 구독 기반 알림 채널**로 설계한다.

## 컨셉

채널(텔레그램/디스코드)에 쿠팡 특가 상품을 자동으로 큐레이션해서 올리고, 각 상품 링크를 쿠팡파트너스 딥링크로 걸어 구매 발생 시 수수료(3%대)를 받는다. 구독자가 "지금 이 채널에 올라오는 걸 보고 싶어서" 자발적으로 구독한 상태라 opt-in이고, 검색엔진 알고리즘/정책 리스크와 무관하다.

## 채널 — 텔레그램 vs 디스코드 (2026-08-11 아직 미확정)

- **텔레그램**: "핫딜 알림봇" 장르가 이미 흔한 포맷(뽐뿌·지름신류)이라 국내 사용자에게 익숙함 — 다만 채널·봇 개설에 **전화번호 인증된 실제 계정**이 필요해서 `tossneon0` 표준(이메일/비밀번호) 방식으로 하윤이 자체 처리 못 함. 회장의 기존 개인 계정 또는 신규 번호 필요.
- **디스코드**: 이메일+비밀번호만으로 가입되고 전화번호 불필요 — `tossneon0@gmail.com` 표준 계정으로 하윤이 바로 자체 처리 가능. 다만 쇼핑/특가 정보 채널로서의 국내 사용자 접점은 텔레그램보다 약함.
- **코드는 채널 선택과 무관하게 재사용되도록** `publishToTelegram`/`publishToDiscord`를 인터페이스로 분리해서 구현해뒀다(`src/worker.js`) — 어느 쪽으로 정해지든 나머지 로직(특가 조회·중복방지·포맷팅)은 그대로 쓴다.

## 아키텍처

```
Cron Trigger (Cloudflare Worker, 하루 4회로 시작)
  → 쿠팡파트너스 API 호출 (골드박스/특가 조회 또는 상품검색)         [TODO: 승인 후 구현]
  → 카테고리 필터 + 할인율 기준 정렬 → 상위 N개 선정
  → 이미 게시한 상품 ID는 KV에 저장해두고 중복 제외                  ✅ 구현됨
  → 딥링크 생성 API로 각 상품을 어필리에이트 링크로 변환             [TODO: 승인 후 구현]
  → 텔레그램/디스코드 중 확정된 채널에 포맷팅해서 게시               ✅ 둘 다 구현해둠(택1)
```

B1(link-preview-api)과 같은 패턴 — Cloudflare Worker + KV, 무자본, 이 저장소의 "폴더 하나 = 프로젝트 하나" 구조를 그대로 따른다. **라이브 스켈레톤**: https://nada-company2-coupang-dealbot.tossneon.workers.dev (`/health`만 정상 동작, `/run`·cron은 쿠팡 API 연동 전이라 아직 에러)

## 단계별 실행 계획

### 1) 회장 액션 (물리적 본인인증이 꼭 필요 — AI가 대신 못 함)

쿠팡파트너스는 **본인 명의 휴대폰 인증**이 가입 필수 조건이라([근거](https://naligi.com/entry/%EC%BF%A0%ED%8C%A1%ED%8C%8C%ED%8A%B8%EB%84%88%EC%8A%A4%EB%A1%9C-%EB%8F%88%EB%B2%8C%EA%B8%B0-%EC%A0%88%EC%B0%A8-%EB%B0%A9%EB%B2%95-%EC%9A%94%EA%B1%B4-%EC%88%98%EC%88%98%EB%A3%8C%EC%9C%A8)) `tossneon0` 표준 자동화 계정으로 우회 불가 — 이건 회장님이 직접 하셔야 하는 몇 안 되는 지점이다.

- 가입 링크: https://partners.coupang.com/
- 필요한 것: 기존 쿠팡 계정(없으면 신규가입) + 본인 명의 휴대폰 인증 + **운영 중인 채널 URL 1개**(심사 항목이라, 아래 2번에서 제가 먼저 채널을 만들어 시딩 콘텐츠를 올려둔 다음에 신청하는 순서를 권장)
- 승인 후 로그인 정보(또는 API 발급용 정보)를 텍스트로 전달해주시면 금고(`coupang_partners_login_email`/`_password` 등)에 등록해서 이후는 제가 운영한다.
- **참고**: API 자동화는 누적 판매 15만원을 넘겨야 개방된다([근거](https://mg.jnomy.com/coupang-partners-verify)) — 그 전까지는 대시보드에서 수동으로 딥링크를 몇 개 만들어 초기 콘텐츠를 시딩하는 기간이 필요하다.

### 2) 하윤 자율 진행 — 여기까지는 회장 답 기다리지 않고 이미 완료

- **Cloudflare Worker 스켈레톤 배포 완료**(`src/worker.js`, `wrangler.toml`) — Cron 트리거(하루 4회), KV 중복방지, 메시지 포맷팅, 텔레그램/디스코드 발행 함수 둘 다 구현. 쿠팡파트너스 API 연동 부분(`fetchCoupangDeals`/`toDeepLink`)만 승인 후 채울 자리로 비워둠.
- 채널 브랜딩 초안(1차는 "생활용품/주방" 등 좁은 카테고리 하나로 시작 제안) — 텔레그램/디스코드 확정되면 바로 적용.

### 3) 회장 확인이 필요한 지점 (계속 대기)

- **채널 선택**: 텔레그램(회장 계정/신규 번호 필요) vs 디스코드(하윤이 자체 처리 가능) — 어느 쪽으로 갈지 알려주시면 바로 시딩 게시물부터 진행.
- 채널이 정해지면 회장님이 채널 URL을 쿠팡파트너스 심사에 낼 수 있도록, 딥링크 없이 일반 상품명·설명만으로 시딩 게시물 몇 건을 먼저 올려둘 예정(승인 전에는 어필리에이트 링크를 걸면 안 됨 — 승인 후 소급 교체).

## 확인이 더 필요한 것

- 쿠팡파트너스 API의 정확한 엔드포인트(딥링크 생성/상품검색/골드박스 조회)와 요청 스펙은 승인받아 API 문서에 실제로 접근해봐야 확정 가능 — 지금은 검색으로 존재만 확인, 상세 스펙 미확인.
- "골드박스" 같은 큐레이션 조회가 없다면, 자체적으로 상품 가격을 주기적으로 추적해 하락분을 탐지하는 로직이 추가로 필요할 수 있음(복잡도↑) — API 문서 확인 후 재설계.
- 쿠팡파트너스 이용약관의 "자동화된 포스팅" 관련 제약 여부 — 승인 후 약관 재확인 필요.
