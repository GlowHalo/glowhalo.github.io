# 나다컴퍼니2 — 관계사 헌장

나다그룹 산하 두 번째 관계사. 대표: **하윤** (2026-08-09 선임). 정연 사장이 이끄는 나다컴퍼니1(`company1/`)과 완전히 독립적인 신사업 탐색 트랙이며, 동시에 실행 전담(Gumroad 업로드 등)도 병행하기 위해 2026-08-08 신설됐다.

공유 원칙(예산·자율성·회장 리소스 제약·공개저장소 주의 등)은 루트 [`CLAUDE.md`](../CLAUDE.md)와 [`company1/README.md`](../company1/README.md)를 그대로 따른다 — 이 문서는 나다컴퍼니2만의 차이점만 적는다. Notion이 아니라 이 폴더가 나다컴퍼니2 경영 의사결정의 단일 소스다.

## 미션

**2026-08-12 회장 확정 — 니치 API 프로덕트가 나다컴퍼니2의 메인 사업이다.** Round 1~4에서 병행 검증하던 두 트랙(B1 니치 API, C1 쿠팡파트너스) 중 **C1(쿠팡파트너스 "나다특가")은 별도 계열사로 업무 이관** — 인수인계 자료는 [`products/coupang-dealbot/README.md`](products/coupang-dealbot/README.md) 상단, 이관 결정 기록은 [`hq/decisions/2026-08-12-쿠팡파트너스-계열사이관.md`](../hq/decisions/2026-08-12-쿠팡파트너스-계열사이관.md) 참고. **B1은 RapidAPI(Nokia 인수 이후 불안정) 하나에 의존하지 않고 대상 플랫폼을 최대한 넓히는 방향으로 확장** — 전략은 [`products/니치API-플랫폼-전략.md`](products/니치API-플랫폼-전략.md).

나다컴퍼니1과 동일하게 **백지상태(blank slate) 신사업 탐색**도 계속 병행하지만, 우선순위는 니치 API 라인 확장이 우선이다.

**2026-08-11 회장 확정 — 아이디어 발굴은 나다컴퍼니1과 완전히 독립적으로 진행한다.** 창립 지시부터 "정연 쪽 결과를 베끼거나 종속되지 않고 처음부터 다시 발굴·검증"하라는 게 원칙이었는데, Round 1~4에서 `company1/candidates.md`를 참고해 겹치는 도메인을 의도적으로 피하는 방식으로 운영해온 게 이 원칙 위반이었다는 걸 회장이 지적·확정했다. **아이디어를 찾고 평가하는 단계에서는 `company1/candidates.md`를 보지 않는다** — 겹치는 후보가 나오면 그 자체가 (정연과 하윤이 독립적으로 같은 결론에 도달했다는) 신호이지, 피해야 할 문제가 아니다.
- 회장 리소스 제약([원칙 1~6](../company1/README.md#회장-리소스-제약-2026-08-05-확정-모든-안건에-항상-적용))·예산(1건당 최초 30만원 이내, 무자본 최우선)·정산 계좌 직접입금 우선·**"플랫폼이 자동화를 공식 API/CLI로 지원하는가" 1차 필터**는 특정 계열사의 아이디어가 아니라 회장이 정한 그룹 전체 운영 규칙이라 계속 그대로 따른다 — 위 정정은 "아이디어 자체"에만 해당한다.
- 조직 운영 원칙(승인 라인, 조직 확장은 사후 기록·사전 승인 불필요, 신규 역할은 실명 없이 역할명만, 공개 저장소 원칙)도 [`company1/README.md`](../company1/README.md)와 동일하게 적용한다 — 이것도 운영 규칙이라 위 정정과 무관.

**2026-08-12 회장 확정 — 하윤은 니치API 라인(B1 등)에 집중.** 그동안 병행하던 C1(쿠팡파트너스)은 나다컴퍼니7로 분사·이관했다 — 신규 담당자 "도현"이 이어받는다. 관련 코드/문서는 `products/coupang-dealbot/` → [`company7/products/coupang-dealbot/`](../company7/products/coupang-dealbot/)로 이동 완료. 나다컴퍼니2는 앞으로 "니치 API 프로덕트" 카테고리 확장(RapidAPI Hub 등)에 집중한다.
