- 조직 운영 원칙(승인 라인, 조직 확장은 사후 기록·사전 승인 불필요, 신규 역할은 실명 없이 역할명만, 공개 저장소 원칙)도 [`company1/README.md`](../company1/README.md)와 동일하게 적용한다.
