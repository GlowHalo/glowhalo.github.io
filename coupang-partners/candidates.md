## 향후 확장 후보 (아직 착수 전)

도현이 C1 안정화(누적매출 15만원, API 개방) 이후 자율적으로 발굴·추가한다. 검토했다가 제외된 후보(앱인토스, 토스쇼핑 쉐어링크 — 사업자등록 필요/모바일 앱 전용이라 자동화 불가)는 `niche-api/candidates.md`의 과거 기록 참고, 재검토 가치는 낮음.

| # | 후보 | 형태 | 상태/비고 |
|---|---|---|---|
| C2 | 알리익스프레스 어필리에이트 | 같은 채널(디스코드/텔레그램)에 알리 특가 병행 게시, 공식 Open API(AppKey/Secret) 지원 — 딥링크 생성·상품 검색 전부 API로 가능 | 🔵 조사 완료(2026-08-15), 착수 전 — API 신청 절차에 **실명 인증(신분증 업로드·주민등록번호)이 필수**라 표준 자동화 계정으로 우회 불가, 쿠팡파트너스 가입과 같은 성격의 회장 액션 필요. 승인만 나면 이 계열사가 이미 만든 봇 인프라(중복방지 KV·포맷팅·게시 로직)를 그대로 재사용 가능해서 착수 비용은 낮음 |
| C3 | Amazon Associates (PA-API) | 해외 특가, Product Advertising API로 상품 데이터·딥링크 공식 지원 | 🔵 조사 완료(2026-08-15), 착수 전 — 가입 후 **180일 내 최소 판매 3건**이 없으면 계정이 자동 폐쇄되는 유지조건이 있어, C1이 스스로도 아직 매출 0원인 지금 병행 착수하면 두 트랙 다 유지조건을 못 채울 리스크. C1이 15만원(=API 개방) 넘긴 뒤 착수가 안전. 세금정보(W-8BEN 등) 제출은 회장 확인 필요 |
| C4 | 네이버 쇼핑 커넥트 | 국내 최대 쇼핑 트래픽 | ⚪ 조사 불충분(2026-08-15) — 딥링크 자체는 2024년부터 허용되지만, 제3자가 프로그래매틱하게 딥링크를 발급받는 공개 오픈 API가 있는지 이번 조사로는 확인 못 함(스마트스토어 판매자용 커머스 API와 혼동 주의). 재조사 필요, 지금은 우선순위 낮음 |

*최근 조사: 2026-08-15 (도현)*
