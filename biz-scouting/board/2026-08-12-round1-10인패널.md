# Round 1 — 10인 분석가 패널 1차 스캔 (2026-08-12)

대표 다연 주재. 10명(소비자트렌드/콘텐츠·크리에이터/이커머스·리테일/B2B SaaS/교육·에듀테크/헬스케어·웰니스/핀테크/로컬·오프라인/글로벌/AI·자동화 교차검증)이 각자 독립적으로 조사(웹서치 근거 포함)한 뒤, AI·자동화 담당이 상위 후보 10개를 다시 한번 자동화 관점에서 교차검증했다. 최종 필터링·스코어링 결과는 [`../candidates.md`](../candidates.md) 참고 — 이 문서는 원자료(각 분석가 원안) 보존용.

## 1. 소비자 트렌드
- **AI 반려동물 초상화 (Etsy)** — 시장 12억달러(2025)·성장세 확인. ⚠️ 교차검증에서 치명적 함정 발견: Etsy 리스팅은 구매자 전원에게 동일 파일만 자동전달, "사진 업로드→맞춤생성" 개인화 배송 API가 없어 주문마다 수동 발송 필요 → 자동화 점수 2/5로 하향.
- 필코노미 스몰브랜드 큐레이션 뉴스레터 — 협찬 컨택이 관계형이라 회장 관여도 높음, 후순위.
- 숏폼 커머스 크리에이터 어필리에이트 — TikTok Shop은 사업자등록 필수라 배제, 네이버클립/오늘의집으로 한정 시에도 팔로워 성장 시간비용 큼.

## 2. 콘텐츠/크리에이터 이코노미
- **니치 AI 큐레이션 뉴스레터 (Beehiiv)** — Beehiiv Create Post API + Stripe Connect 내장으로 발행·결제 전구간 자동화. 교차검증 자동화 5/5, TOP 3 선정.
- AI 생성 스톡 이미지/영상 (Adobe Stock 등) — 시장은 크나 포트폴리오 볼륨 확보까지 매우 느림, Shutterstock은 외부 AI 도구 생성물 거부.
- Amazon KDP 미드콘텐츠 출판 — Amazon의 "대량생성/AI미고지" 단속 강화로 정책 리스크 중~상.

## 3. 이커머스/리테일
- Etsy 디지털 다운로드(프린터블) — 후보1과 유사 함정 공유 가능성.
- **POD 굿즈 스토어 (Printify/Printful+Etsy)** — Printify API로 등록, 인쇄·배송은 파트너 전량 위임. 교차검증 자동화 4/5, TOP 3 선정.
- Amazon KDP 로우콘텐츠북 — 공식 업로드 API 부재, 정산도 한국은 EFT 미지원이라 후순위.

## 4. B2B SaaS
- **AI 코딩 에이전트 팀 스펜드 대시보드** — 기술 자동화는 되나(Anthropic/GitHub Usage API), 교차검증에서 "B2B는 영업·CS가 병목"이라는 구조적 함정 지적 — 자동화 3/5로 하향, 겸업창업자 시간예산과 충돌 우려.
- 인디개발자용 LLM 옵저버빌리티 — 이미 강한 경쟁자(Langfuse, Braintrust 등) 다수, 진입장벽 높음.
- GitHub Actions 마켓 자동화 도구 — 아이디어 차별화 약함, 후속 조사 필요.

## 5. 교육/에듀테크
- **TPT/Etsy 스타일 AI 워크시트 판매** — 교차검증 결과 **TPT는 공식 셀러 API가 없어 전량 수동** — TPT 배제하고 Etsy 단일채널(개인화 불필요한 고정 PDF라 Etsy 구조와 궁합 좋음)로 운영 시 자동화 4/5.
- AI 비동기 첨삭 리포트(자소서) — "과외 신고" 경계선 설계 필요, 크몽 등에서 실시간 상담으로 흐를 위험 관리 필요.
- 니치 시험 대비 모의고사+플래시카드 — 니치 커뮤니티 의존도 높고 유지보수 부담.

## 6. 헬스케어/웰니스
- **웨어러블 헬스데이터 AI 웰니스 인사이트 리포트** — 마켓플레이스 종속 없는 자체 파이프라인(Stripe 웹훅→Claude 분석→PDF→이메일). 교차검증 자동화 5/5, **TOP 1 선정**. 비의료 문구 설계만 셋업 단계에서 주의.
- 완경기 여성 셀프케어 키트 — 효능 문구 리스크 관리 필요.
- 직장인 뉴로웰니스 마이크로루틴 — B2C 한정 설계 필요(B2B 기업계약은 배제).

## 7. 핀테크
- **ISA/IRP/연금저축 절세계좌 콘텐츠 허브** — 국가법령정보 공동활용 Open API로 세법 자동수집 가능(크롤링 아닌 합법 API). 교차검증 자동화 4/5. YMYL 애드센스 심사·유사투자자문업 리스크만 주의.
- N잡러 종합소득세 셀프신고 가이드 — 대리신고로 흐르면 세무사법 위반 소지, "계산+셀프제출 안내"로 선 관리 필요.
- AI 가계부 노션템플릿 — GlowHalo Group 내 기존 노션템플릿 라인과 중복도 높아 후순위.

## 8. 로컬/오프라인 서비스
- AI 정책자금 사업계획서+상권분석 대행(크몽) — 시장 근거는 탄탄하나 교차검증에서 **크몽 자체 셀러 API 부재**(전량 수동) + 정책자금 특성상 오류 시 고객 생계 영향 커 품질검수 필수 → 자동화 2/5로 하향.
- 화이트라벨 로컬SEO 재판매 — 약한 후보, 순수 제휴 콘텐츠로 축소해야 파킹을 면함.
- **파킹 3건**(네이버플레이스 AI대행/예약관리챗봇대행/로컬맛집 큐레이션) — 상시 CS·물리적 방문 필요로 겸업창업자 제약과 정면충돌.

## 9. 글로벌 시장
- **텔레그램 스티커/이모지 스토어** — Bot API(createNewStickerSet)+Stars 인보이스(sendInvoice)로 생성·판매 자동화. 교차검증 자동화 4/5, 다만 Stars→TON→원화 환전은 거래소 KYC 필요해 정산만 월 1회 수동. TOP 3 후보.
- 니치 업종별 웹사이트 템플릿(Envato) — Claude 코딩 역량과 직결되나, **Envato는 셀러 등록 API가 없고 전량 사람 심사(soft/hard reject 반복 가능)** — 자동화 2/5로 하향, 시간예산과 안 맞음.
- Etsy 다국어 프린터블 — 기존 Etsy 채널(A1)과 카니발라이즈 우려로 후순위.

## 10. AI/자동화 기술 실현가능성 (교차검증)
자동화 관점 TOP 3: ① 웨어러블 헬스데이터 AI 웰니스 리포트(5/5) ② 니치 AI 큐레이션 뉴스레터(5/5) ③ POD 굿즈 스토어(4/5, 조건부 4위 동급으로 AI워크시트/Etsy단일채널).
공통 경고: **"Etsy Open API v3가 있다"는 이유만으로 자동화된다고 판단하면 안 된다** — v3는 리스팅·주문·샵 관리만 커버하고 구매자-판매자 개인화 파일 전달 API는 없다. 개인화 불필요 상품(워크시트, POD 디자인)은 안전하지만, 반려동물 초상화처럼 주문마다 다른 산출물을 전달해야 하는 모델은 이 구멍에 걸린다.
