## 계정 현황 (2026-08-17 확인)

- **Etsy — 이미 있음.** 금고에 `etsy_login_email`/`etsy_login_password`(`tossneon0`, 2026-08-12 가입, 상점 등록비 $19 이미 지불) 등록돼 있음 — 신규 가입 불필요, 바로 재사용.
- **Printify — 없음.** 실제 상품 제작·자동 리스팅·주문 처리를 담당하는 핵심 채널인데 계정이 없어 `hq/가입대기.md`에 등록해뒀다. Printify는 가입 자체는 무료([printify.com](https://printify.com/etsy/))이고, Etsy 연동은 대시보드에서 "Manage My Stores → Connect"로 OAuth 승인만 하면 된다(가입 승인 후 다연이 바로 진행 가능).
- Printful은 후보에서 제외 — Printify 하나로 Etsy 자동 연동·다품목 공급사 비교가 다 되고, 계정을 두 개 만들 이유가 없음(중복 가입 방지).

## 기술 흐름 (2026-08-17 리서치)

[printify.com](https://printify.com/etsy/), [listybox.com 가이드](https://listybox.com/blog/printify-etsy-integration-step-by-step-guide) 기준:

1. Printify 대시보드에서 Etsy 스토어를 OAuth로 연결(1회, Etsy 정책상 POD 파트너 공개 표시 의무 있음 — 상품 설명에 "Printify로 제작" 명시 필요).
2. 상품 디자인 업로드 → Printify가 목업 생성 → Etsy에 리스팅 자동 게시(Printify Publish API).
3. 주문 발생 시 Etsy → Printify로 주문 자동 전달, 결제 자동 청구, 생산 파트너에게 자동 라우팅(승인 대기시간 1시간/24시간/매일 정해진 시각 중 선택 가능 — 오발주 방지용 완충시간).
4. 인쇄·배송은 파트너가 전담(사람 개입 0), 생산 큐 통상 1~3영업일.
5. 클레임·IP 유사도 검수만 사람(다연) 개입 필요 — candidates.md에서 이미 "자동화 4/5" 감점 사유로 반영됨.

**정산**: Etsy Payments → Payoneer 경유 필요(candidates.md 기존 메모). Payoneer 계정도 금고에 없음 — 착수 임박 시 `hq/가입대기.md`에 추가 예정(지금은 실제 매출 발생 전이라 급하지 않음, 매출 나면 그때 등록).

3단계 필터(시장크기→채널접근성→자동화적합성) 기준으로 **"업로드형 개인화 불필요, 고정 디자인 카탈로그"** 조건을 최우선으로 걸었다 — Round 1에서 "AI 반려동물 초상화"가 정확히 이 지점(주문마다 다른 산출물)에서 자동화 2/5로 탈락했기 때문에, 그 함정을 되풀이하지 않는 니치만 후보로 남겼다.
