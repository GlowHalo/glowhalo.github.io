# 스마트스토어 상품 등록 초안 (v1)

> 실제 네이버 스마트스토어 판매자센터 로그인·등록은 이 세션에서 수행하지 않았다 (로그인 세션·브라우저 접근 없음, 그리고 상품 등록은 실제로 고객에게 노출되는 행위라 확정 전 검토가 필요하다고 판단). 아래는 등록 전에 채우고 검토할 **초안**이다. 확정되면 사용자가 직접 등록하거나, 다음 세션에서 앱 내장 브라우저로 함께 진행하면 된다.

## 1. 포지셔닝

"버크만 진단지 구매대행"이 아니라 **"버크만 진단 + 시그니처 디브리퍼의 1:1 해설"**을 판다. 진단지 자체는 버크만코리아가 직접 팔지 않고(기업/자격자 경유 판매 구조), 원본 리포트도 표준 해석까지만 준다. 차별점은 "표준 해석을 나에게 맞게 다시 풀어주는 사람"이라는 점 — 상세페이지 전체를 이 포인트로 끌고 간다.

## 2. 상품명 후보

1. `버크만 성격진단 + 1:1 AI 디브리핑 해설 (자격 디브리퍼 검수)`
2. `버크만 진단 리포트 해설 서비스 | 숨은 강점·욕구까지 읽어드립니다`
3. `[버크만코리아 정품] 성격유형 진단 + 맞춤 해설 리포트`

→ **후보 1 또는 2**를 추천. "AI"를 앞세우기보다 "자격 디브리퍼가 검수"를 신뢰 포인트로 강조하는 쪽이 진단 서비스 카테고리에서 더 설득력 있음.

## 3. 상품 구성 (옵션)

버크만 진단지 자체는 단일 상품(리포트 유형 1종)으로 시작하고, 옵션은 **디브리핑 형태**로 나누는 걸 권장:

| 옵션 | 구성 | 비고 |
|---|---|---|
| 기본 | 버크만 진단 + 서면 디브리핑 PDF | 메인 상품 |
| (검토) 상담 추가 | 진단 + 서면 디브리핑 + 30분 화상/전화 해설 | 초기엔 서면만으로 시작 후 수요 보고 추가 검토 |

대상자 여러 명(예: 팀/커플)을 한 번에 묶는 옵션은 초기엔 만들지 말고, 개인 단건으로 먼저 검증할 것을 권장 — 대상자별 등록·발송·PDF 관리가 수작업(Phase1 오케스트레이터 미완성 구간)이라 초기에 묶음 주문이 들어오면 처리 부담이 커진다.

## 4. 가격 구조 (템플릿 — 원가만 채우면 됨)

```
버크만 진단지 원가 (버크만코리아 구매가)       : ___________ 원   ← 채워야 함
+ 디브리핑 부가가치 (검수·해설 작업 마진)       : ___________ 원   ← 채워야 함
─────────────────────────────────────────
= 판매가 (부가세 포함 여부 확인)                : ___________ 원

스마트스토어 수수료 (네이버페이 연동수수료, 카테고리별 상이, 보통 3~4%대) : 실제 % 는 판매자센터에서 카테고리 확정 후 확인
```

원가 정보가 없어 구체적 판매가는 못 정했다. 원가만 알려주면 목표 마진율(예: 원가 대비 40~50%)로 역산해서 채워줄 수 있다.

## 5. 상세페이지 구성 (카피 초안)

1. **후킹**: "성격검사는 많이 해봤는데, 결과를 보고도 뭘 해야 할지 모르겠다면?"
2. **문제 제기**: 버크만 리포트는 정확하지만 표준화된 해석이라, 본인 상황에 어떻게 적용할지는 별개 문제.
3. **차별점**: 버크만 시그니처 자격 디브리퍼가 **평소행동과 진짜 욕구의 격차(숨은 니즈)**까지 읽어 1:1로 풀어드림 — 리포트 재탕이 아님.
4. **진행 절차**: 구매 → 온라인 진단(20~30분) → 결과 리포트(버크만 발송) + 디브리핑 해설(판매자 발송, 영업일 기준 N일 이내).
5. **디브리핑 미리보기**: 목차 캡처 또는 샘플 1페이지 이미지 (개인정보 가림 처리 필수 — 차은경 샘플 쓰려면 반드시 비식별화).
6. **FAQ**: 검사 소요시간 / 결과 도착 기한 / 환불 규정(검사 시작 후 환불 불가 명시 필요) / 개인정보 처리.
7. **신뢰 요소**: 버크만시그니처 자격 배지·자격번호(선택), 후기(초기엔 없을 수 있음 → 생략 가능).

## 6. 등록 실무 체크리스트

- **배송 유형**: 실물 배송 없음 → "배송비 무료 / 배송 없음(디지털 전달)" 처리, 검사 링크·결과는 이메일로 전달.
- **정산 계좌 / 사업자 구분**: 개인 판매자로 등록 가능 여부와, 유지 가능한 매출 규모(초과 시 사업자 전환 필요)는 스마트스토어 판매자 가이드에서 최신 기준 확인 필요 — **여기 적힌 숫자는 없음, 정책은 자주 바뀌므로 등록 직전에 판매자센터 고지사항에서 재확인할 것.**
- **통신판매업 신고**: 소규모 거래는 면제 요건이 있으나(거래 횟수/금액 기준), 정확한 기준치는 시점에 따라 달라질 수 있어 여기서 단정하지 않는다. 등록 전 정부24 또는 스마트스토어 고객센터에서 확인 권장.
- **개인정보 수집**: 대상자 이름·이메일을 수집·버크만에 전달하므로, 상세페이지에 개인정보 수집·이용 동의 문구(스마트스토어 기본 템플릿에 포함되는지 확인) 필요.
- **카테고리**: "심리검사/성격유형검사" 유사 카테고리가 있는지 판매자센터에서 검색 후 선택 (전자책/디지털 콘텐츠 카테고리와 비교).
- **환불 정책**: "검사 시작(로그인/응답 시작) 이후 환불 불가" 명시 — 버크만 쪽 재판매 정책과 일치시킬 것(버크만코리아 환불 규정 별도 확인).

## 7. 다음 단계 제안

1. 원가·목표 마진 알려주면 → 4번 가격표 확정.
2. 상품명 1개 확정, 상세페이지 초안(5번)을 실제 문구로 다듬기 (원하면 전체 상세페이지 마크다운/HTML 초안 작성 가능).
3. 통신판매업 신고 여부·개인 판매자 매출 한도는 사용자가 스마트스토어centre 공지/정부24에서 최종 확인 (법적 사항이라 여기서 확정하지 않음).
4. 등록 자체는 다음 세션에서 판매자센터 로그인 후(사용자 로그인, Claude 조작) 진행.
