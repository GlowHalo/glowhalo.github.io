# 버크만 맵 — 상세페이지용 디자인 레퍼런스 (2026-08-12)

상세페이지에 버크만 사분면 맵을 그릴 때마다 다시 헤매지 않도록, 회장이 제공한 공식 샘플 리포트(셀프/베이직/커리어/시그니처, PDF)에서 실제 화면을 직접 열어보고 확인한 정본 스펙. **원본 PDF·이미지는 저작권 콘텐츠라 이 저장소엔 커밋하지 않음** — 아래는 색상 코드·기호 매핑 같은 사실 정보만 정리한 것.

## 사분면 배치 (고정, 절대 바꾸지 말 것)

- 가로축: 왼쪽 = **과제지향**, 오른쪽 = **사람지향**
- 세로축: 위 = **외향**, 아래 = **내향**
- 좌상단(외향+과제지향) = **적색** — "행동하는 사람"
- 우상단(외향+사람지향) = **녹색** — "소통하는 사람"
- 좌하단(내향+과제지향) = **주황**(버크만 표기는 "노랑"이지만 실제 렌더링은 주황/amber에 가까움) — "분석하는 사람"
- 우하단(내향+사람지향) = **청색** — "생각하는 사람"

참고 hex(육안 추출, 공식 브랜드 가이드 아님 — 근사치): 적 `#7a2130` / 녹 `#1f6e48` / 주황 `#d9822e` / 청 `#2e5d96`

## 4개 기호 — 모양이 곧 의미다, 절대 섞지 말 것

| 기호 | 개념 | 모양 |
|---|---|---|
| 흥미 (Interest) | 좋아하는 활동 | **★ 별** |
| 평소행동 (Usual Behavior) | 겉으로 보이는 강점·행동 | **◆ 다이아몬드** |
| 욕구 (Needs) | 숨겨진, 채워져야 할 필요 | **● 원** |
| 스트레스행동 (Stress Behavior) | 욕구 미충족 시 나타나는 반응 | **■ 사각형** |

기호는 흰색/밝은 색으로 컬러 배경 위에 얹어서 표시한다. 세모·화살표 같은 임의 도형으로 대체하지 않는다.

## 시각 효과 — 중심으로 갈수록 옅어지는 "동심 사각형"

바깥은 4사분면 원색 그대로, 그 안에 같은 4사분면 패턴을 더 작고(약 60%, 약 28% 크기) 반투명하게 겹쳐서 중심부가 흐려지는 효과를 낸다. 그라데이션이 아니라 **같은 패턴을 작게 반복해서 겹치는 방식**.

## 기호 위치

각 기호는 실제 진단 점수에 따라 사분면 안 어딘가에 점으로 찍힌다(정중앙에 가까울수록 그 성향이 약함/중립, 바깥 모서리에 가까울수록 강함). 우리 상세페이지처럼 "설명용 예시"를 그릴 때는 4개 기호를 서로 다른 사분면에 흩어 놓아 "이렇게 사람마다 다르게 나타난다"는 개념을 보여주면 된다 — 특정 실제 고객의 좌표를 재현하는 게 아니므로 정확한 수치는 필요 없다.

## 안전 원칙

- 로고(사각형 안에 배치된 4색 꽃잎 모양 버크만 공식 브랜드 마크)는 버크만 상표이므로 그대로 베끼지 않는다 — 우리는 색상 팔레트와 기호 개념만 참고해서 Reflect Lab 자체 스타일로 재구성한다.
- 이 문서에 적힌 것 외의 세부사항(정확한 폰트, 정확한 hex 코드, 브랜드 마크 등)이 필요해지면 다시 원본 PDF를 열어 확인하고, 추측으로 채우지 않는다.
