# 산출물 다운로드 허브

라이브: https://glowhalo.github.io/output-links-hub/

내가 만든 프로그램(오토클릭, 써클히어로즈 등)을 한곳에서 바로 받거나, 링크만 복사해서
다른 사람에게 전달할 수 있는 페이지. 새 산출물이 생기면 `index.html`의 `OUTPUTS` 배열에
객체 하나만 추가하면 카드가 자동으로 쌓인다.

각 카드는 프로그램 설명 + 다운로드/플레이 링크 목록으로 구성되고, 링크마다 실제 URL을
그대로 보여주면서 "🔗 복사" 버튼으로 클립보드 복사를 지원한다. 다운로드 대상이 여러 개면
(예: APK + 웹 플레이) 한 카드 안에 링크를 여러 줄로 나열한다.

## 참고: 이전 소스 아카이브

이 폴더는 원래 저장소 루트 `index.html`(전체 프로젝트 목록 허브)의 디자인 소스를
보관하던 곳이었다. 그 용도는 폐기하고 위 다운로드 허브로 전환했지만, 과거 참고용으로
React 버전 소스 두 개는 남겨둔다:

- `maker-journal-hero.jsx` — 저장소 루트 `index.html`의 기반이 된 디자인
- `maker-journal.jsx` — 더 이전의 카드형 버전 (참고용, 더 이상 사용 안 함)

프로젝트 전체 목록/상태는 여전히 저장소 루트의 [`index.html`](../index.html)과
[`registry.js`](../registry.js)에서 관리된다 (Notion "작업실 허브" 스냅샷).
