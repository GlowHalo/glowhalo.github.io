PromptDeck — Privacy Policy

Last updated: 2026-08-06

What PromptDeck stores

PromptDeck saves the prompt titles and text you enter, plus your license key if you activate one, using Chrome's built-in chrome.storage.sync API. This data is stored in your own Google account's Chrome sync storage — it is not sent to, or stored on, any server we operate. We have no backend and no analytics.

What leaves your browser

The only network request PromptDeck makes is to Gumroad's public license verification endpoint (api.gumroad.com/v2/licenses/verify), and only when you paste a license key into the options page to activate PromptDeck Pro. That request sends the license key you typed and nothing else — no prompt content, browsing history, or page content is ever transmitted anywhere.

Page access

PromptDeck requests permission to run on all pages so it can insert your saved prompt text into whatever text box is focused on the page you're using (e.g. ChatGPT, Claude, Gemini, or any other site). It does not read, log, or transmit the content of the pages you visit.

Contact

Questions about this policy: reach out via the support link on the PromptDeck Gumroad page.
