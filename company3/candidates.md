### 최종 판단 — **코인을 1차 자산군으로 선택**

**선택 근거**:
1. **"수익 최대화"라는 미션과 방향이 가장 잘 맞는다.** 30만원처럼 절대금액이 작을 때는 %변동폭이 큰 자산이 유리한데, 코인은 국내주식보다 변동성이 확연히 크고 해외주식(레버리지 ETF 없이)보다도 크다.
2. **24시간 거래 + API 완전 자동화**가 겸업 회장의 "직접 개입 최소화" 제약(company/README.md 회장 리소스 제약 원칙 1)과 가장 잘 맞는다 — 알고리즘이 시간대 제약 없이 돌아갈 수 있어, 국내주식(09~15:30 한정)이나 해외주식(새벽 시간대)보다 사람 개입 의존도가 낮다.
3. 진입장벽이 가장 낮다: 최소 주문 5,000원, 사업자등록 불필요, 개인 인증만으로 API 키 발급.
4. 세금은 2027년 시행 예정이지만 30만원 규모 이익은 연 250만원 기본공제 안에 거의 항상 들어와 지금도, 시행 후에도 실질적 걸림돌이 아니다.

**리스크 인지 및 대응**:
- 거래소 해킹·규제 제재 리스크는 실재하나, 원금 자체가 30만원으로 "잃어도 감내 가능한 범위"라는 전제로 수용한다.
- 수수료 구조상 초단타(스캘핑)는 매매 빈도가 늘수록 수익을 빠르게 잠식하므로 **저빈도 스윙/알고리즘 전략을 기본으로 한다** (아래 초기 전략 참고).
- 국내주식(KIS API 무료·무세금 인프라)은 **자동매매 시스템 검증용 보조 트랙**으로 병행 가치가 있다고 판단 — 실거래 게이트가 풀린 뒤 자본 배분 시 재검토.

## 초기 전략 방향 (Round 1 확정)

- **유형**: 저빈도 스윙 + 규칙 기반(알고리즘) 전략. 변동성 돌파형(전일 변동폭 기반 진입 임계값) 등 검증된 방식을 페이퍼 트레이딩으로 먼저 백테스트한다. 스캘핑(초단타)은 수수료 누적 문제로 1차 후보에서 제외.
- **종목 범위**: 비트코인·이더리움 등 대형 코인 중심(알트코인은 상장폐지·유동성 리스크가 커 후순위). 3~4종목 이내로 제한해 관리 복잡도를 낮춘다.
- **리스크 관리**: 종목당 최대 투입 비중 상한, 포지션별 손절 기준(예: 진입가 대비 -5~10%), 하루/주간 손실 한도 도달 시 그날/그주 매매 중단 규칙을 페이퍼 트레이딩 단계에서 함께 확정한다.
- **검증 순서**: (1) 과거 시세 데이터로 전략 백테스트 → (2) pyupbit/서드파티 도구로 실시간 페이퍼 트레이딩 수주~수개월 운영 → (3) 성과가 안정적이면 회장에게 전략 요약 보고 후 실거래 게이트 논의.
- 국내주식 KIS API 기반 자동매매 인프라 구축은 코인 전략과 별개로, 무비용·무세금 환경에서 시스템(주문/체결/리스크관리 로직) 자체를 검증하는 용도로 병행 가능 — 실거래 자본 배분 대상은 아님(1차는 코인에 집중).

## 실거래를 시작하려면 회장이 해야 할 일

1. **거래소 선택 및 계좌 개설**: 업비트(케이뱅크 실명계좌 필요) 또는 빗썸(KB국민은행 실명계좌 필요) 중 선택 — 두 은행 중 이미 계좌가 있는 쪽을 고르면 절차가 빠르다.
2. **본인인증(KYC)**: 회원가입 → 은행 실명계좌 인증(1원 송금 확인) → 신분증 인증. 100만원 이상 매매 시 추가 KYC가 필요하므로 30만원 운용 규모라면 초기 절차는 상대적으로 간단하다. 이 단계는 물리적으로 회장만 가능(신분증 촬영·본인 인증).
3. **API 키 발급**: 계좌 개설 후 거래소 개발자센터에서 개인 인증만으로 API 키(REST/WebSocket) 발급 — 이 단계는 발급 자체는 회장이 하되, 발급된 키를 은성에게 전달하면(금고 등록) 이후 조회·전략 실행은 은성이 자동화한다.
4. **매매 실행 권한 범위 확정**: 완전자율 / 건별승인 / 손실한도 내 자율 중 어느 방식으로 시작할지 회장이 결정. (예: "하루 손실 -3만원 넘으면 자동 중단, 그 안에서는 완전자율" 같은 조건부도 가능)
5. 계좌·API 정보는 발급 즉시 `cloudflare-api-vault/`에 등록해 관리한다(회장이 직접 값을 붙여넣기보다, 화면의 복사 기능으로 텍스트를 넘겨주는 방식을 권장 — CLAUDE.md 재발방지 규칙 3번).

이 5가지가 갖춰지기 전까지는 페이퍼 트레이딩·전략 고도화만 계속 진행한다.
