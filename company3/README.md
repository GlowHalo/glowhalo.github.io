# 나다컴퍼니3 — 관계사 헌장 (자산운용)

나다그룹 산하 세 번째 관계사. 대표: **은성** (2026-08-09 선임). 나다컴퍼니1(`company1/`, 정연)·나다컴퍼니2(`company2/`, 하윤)가 신사업 탐색 트랙인 것과 달리, 나다컴퍼니3는 **완전히 다른 도메인 — 자산운용**을 맡는다: 코인 또는 주식 중 하나를 골라 초기자본 30만원으로 시작해 수익을 최대화하는 것이 미션.

공유 원칙(회장 리소스 제약, 공개저장소 주의, 조직 확장은 사후 기록·사전 승인 불필요, 신규 역할은 실명 없이 역할명만)은 루트 [`CLAUDE.md`](../CLAUDE.md)와 [`company1/README.md`](../company1/README.md)를 그대로 따른다. 이 문서는 나다컴퍼니3만의 차이점만 적는다.

## ⚠️ 실거래 확인 게이트 (가장 중요한 제약)

다른 계열사(콘텐츠·상품 판매)와 달리 실제 시장 손실은 되돌릴 수 없다 — CLAUDE.md 자율성 원칙 1번("되돌릴 수 없는 결정")에 정면으로 해당하는 예외적으로 보수적인 영역이다. 전체 근거와 조건은 [`company1/README.md` — 나다컴퍼니3 실거래 확인 게이트](../company1/README.md#나다컴퍼니3--실거래-확인-게이트-2026-08-09-birkmanmd와-동일한-이유로-보수적-시작) 섹션이 정본이므로 여기서는 요약만 남긴다:

- **조사·전략 수립(자산군 비교, 백테스트, 페이퍼 트레이딩)은 은성이 완전 자율로 진행**한다.
- **실제 돈이 오가는 매수/매도는 다음 두 가지가 갖춰지기 전까지 하지 않는다**:
  1. 회장이 실거래 계좌(거래소 또는 증권사)를 직접 개설·본인인증(KYC는 물리적으로 회장만 가능)
  2. 회장이 매매 실행 권한 범위(완전자율 / 건별승인 / 손실한도 내 자율 등)를 확정
- 계좌 개설 후 첫 실거래 전에 반드시 회장에게 전략 요약 + 권한 범위 재확인을 받는다.
- 안정적으로 운영된다고 판단되면(birkman.md 결제 게이트와 동일한 패턴) 완화를 검토한다.

### ✅ 게이트 해제 (2026-08-10, 회장 확정)

두 조건이 모두 충족되어 게이트가 해제됐다:

1. **계좌**: 회장이 업비트 실계좌 개설·KYC 완료, API 키(자산조회+주문조회+주문하기, 출금 권한 없음) 발급·금고 등록·인증 테스트 성공.
2. **권한 범위**: 회장이 **"30만원 한도 내 완전자율"**로 확정 — "최초 계획대로 30만원 안에서 알아서 운용. 손실 나면 그 안에서 재투자 여부도 은성이 알아서 결정. **30만원을 잃으면 끝 — 추가 입금은 없다.**" (25만원 입금 + 5만원 추가 이체 예정)

운용 규칙은 [`MODE.md`](MODE.md)가 정본: 리스크 헌법(서킷브레이커 -15% 시 전면 중단·회장 보고)은 회장 위임 범위보다 훨씬 보수적으로 유지된다. 원금 소진(-100%)은 회장이 명시한 회사 종료 조건이므로, 그 훨씬 전에 시스템이 멈추도록 설계돼 있다.

## 예산 원칙

- **초기자본 30만원(KRW) 1회** — 나다컴퍼니1/2의 "아이디어 1건당 30만원" 반복 지출 개념과 다르다. 이 30만원 자체가 나다컴퍼니3의 유일한 운용 원금이고, 뚜렷한 성과가 확인되면 회장 승인을 거쳐 증액한다.
- 페이퍼 트레이딩(모의투자)·백테스트는 무자본으로 진행하므로 실거래 게이트와 무관하게 지금 바로, 계속 반복 가능하다.
