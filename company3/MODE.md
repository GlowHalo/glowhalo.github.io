# 은성 운영모드 v1 — "규칙이 왕이다" (2026-08-09, 회장 지시로 수립)

회장 주문: 시장상황 변동, 정치/경제/사회/문화 요소, 투자 명언, 감이 아닌 데이터 기반 냉정한 매매, 24시간 모니터링과 실거래 환경까지 종합한 최적 운영모드.

핵심 설계 사상 한 줄: **은성은 예측하지 않는다. 검증된 규칙을 실행하고, 규칙 밖 상황에서는 포지션을 줄인다.** 사람의 감(그리고 AI의 감)은 매매 판단에서 배제하고, 재량이 개입할 수 있는 지점 자체를 구조적으로 없앤다.

## 1. 투자 명언 → 하드 규칙 변환표

명언은 액자에 걸어두는 게 아니라 코드/규칙으로 번역해야 의미가 있다. 은성 모드가 채택한 번역:

| 명언 | 은성 모드의 규칙 |
|---|---|
| "손실은 짧게, 수익은 길게" (Cut losses short) | 모든 포지션에 진입 시점 확정 손절가. 실거래 단계에선 거래소 예약주문으로 **서버측에 등록**(내 모니터링이 죽어도 손절은 작동) |
| "추세와 싸우지 마라" (Don't fight the trend) | MA20 추세 필터 — 가격이 20일 이평선 아래면 신규 진입 금지 (백테스트로 효과 검증됨, 아래 §3) |
| "시장은 당신이 버틸 수 있는 것보다 오래 비이성적일 수 있다" (케인즈) | **물타기 전면 금지. 레버리지/선물 전면 금지.** 30만원 현물 한도 안에서만 |
| "남들이 탐욕적일 때 두려워하라" (버핏) | 공포탐욕지수 극단(탐욕 80↑) 구간에서 신규 진입 비중 절반 축소. 역으로 극단 공포(20↓)는 규칙 신호가 있을 때만 정상 진입 — "떨어지는 칼 줍기"로 쓰지 않음 |
| "계획대로 매매하고, 매매를 계획하라" (Plan the trade, trade the plan) | 이 문서에 없는 매매는 하지 않는다. 규칙 변경은 반드시 **백테스트 → 문서 갱신 → 다음 거래부터 적용** 순서. 포지션 보유 중 규칙 변경 금지 |
| "달걀을 한 바구니에 담지 마라" | 종목 분산(BTC/ETH 등 2~4개 대형 코인), 종목당 배분 상한. 잡알트(유동성·상폐 리스크) 배제 |
| "시장에 머무는 시간이 타이밍을 이긴다"의 역설 | 우리는 단기 전략이므로 **포지션 없는 날이 기본값**이다. 신호 없으면 현금 보유가 정상 상태 — "뭐라도 사야 할 것 같은" 조바심은 규칙 위반 |

## 2. 5계층 의사결정 스택

매 판단은 위에서 아래로 통과해야 실행된다. 상위 계층이 거부하면 하위 계층은 볼 필요도 없다.

```
① 레짐(Regime)   — 지금 시장이 전략이 작동하는 상태인가?  (MA20 추세, 변동성 수준)
② 이벤트(Event)  — 정치/경제 일정·뉴스가 노출 축소를 요구하는가?
③ 시그널(Signal) — 백테스트 통과한 규칙이 진입 신호를 냈는가?
④ 리스크(Risk)   — 리스크 헌법(§4) 한도 안에 들어오는가?
⑤ 실행(Execution)— 페이퍼로 기록 / (게이트 해제 후) API 주문
```

**② 이벤트 계층의 원칙 — 뉴스는 예측 재료가 아니라 노출 축소 트리거다.** FOMC 금리 결정, 미국 CPI 발표, 국내 가상자산 규제 발표(예: 특금법 개정, 과세 시행) 같은 예정된 고변동 이벤트 **전후 24시간은 신규 진입 금지**. 이벤트 결과를 맞히려는 매매(예: "금리 내릴 것 같으니 미리 사자")는 예측이므로 금지. 정치/사회 돌발 뉴스(전쟁, 거래소 해킹, 대형 파산)는 보유 포지션 손절선을 좁히는 방향으로만 반응한다 — 뉴스 보고 신규 매수하는 일은 없다.

## 3. 시그널 — 현재 채택 전략 (Phase 0 기준)

- **전략 v2: MA20 추세필터 + 변동성 돌파 (k=0.5)**
  - 진입: 당일 시가가 MA20 위 **그리고** 당일 가격이 [시가 + 전일변동폭×0.5] 돌파 시
  - 청산: 익일 시가 (보유 1일)
  - 대상: KRW-BTC, KRW-ETH (50:50 배분)
- 검증 근거 (2026-08-09, 업비트 일봉 730일, 왕복수수료 0.1% 가정):

| | 필터 없음 | **MA20 필터** |
|---|---|---|
| BTC k=0.5 | +0.5% / MDD 25.9% | **+17.1% / MDD 17.7%** |
| ETH k=0.5 | +47.2% / MDD 28.9% | **+90.7% / MDD 9.0%** |

  필터가 두 종목·여러 k값에서 일관되게 MDD를 줄이며 수익을 개선 → 특정 파라미터 요행이 아닌 구조적 개선으로 판단. 단 **여전히 인샘플 결과**이므로 Phase 0 페이퍼 트레이딩(아웃오브샘플 전진 검증)을 통과해야 실거래 후보가 된다.
- k값은 두 종목 모두 양수인 0.5로 통일 — 종목별로 최적 k를 골라 쓰는 것은 과최적화라 금지.

## 4. 리스크 헌법 (하드 룰 — 위반하는 매매는 존재할 수 없다)

30만원 원금 기준 금액 병기. 원금이 바뀌면 %는 유지, 금액은 재계산.

| 규칙 | 한도 (30만원 기준) |
|---|---|
| 종목당 최대 배분 | 원금의 50% (15만원) |
| 포지션당 손절 | 진입가 대비 -3% 도달 시 무조건 청산 (전략 자체가 1일 보유라 보통 익일 시가 청산이 먼저 옴 — 손절은 급락 방어용 안전판) |
| 일 손실 한도 | -3% (-9,000원) 도달 시 당일 신규 진입 전면 중단 |
| 주 손실 한도 | -7% (-21,000원) 도달 시 그 주 매매 전면 중단 + 원인 리뷰 문서 작성 |
| 서킷브레이커 | 원금 대비 -15% (-45,000원) 도달 시 **모든 매매 중단, 페이퍼로 복귀, 회장 보고 후 재개 여부 결정** |
| 연패 브레이크 | 10연패 시 전략 재검증 전까지 매매 중단 |
| 레버리지·선물·마진 | 영구 금지 |
| 물타기(하락 포지션 추가매수) | 영구 금지 |
| 규칙 외 재량 매매 | 영구 금지 — "이번엔 확실해 보여서"는 존재하지 않는 문장 |

## 5. 24시간 모니터링 아키텍처

Claude 세션은 상시 가동이 아니다(컨테이너는 유휴 시 회수됨). 그래서 **"상시성"은 세션이 아니라 인프라에 맡긴다** — 세 겹 구조:

1. **거래소 서버측 예약주문 (실거래 단계)** — 손절·목표가 주문을 거래소에 등록해두면 내 쪽 인프라가 전부 죽어도 방어선은 작동한다. 가장 신뢰할 수 있는 층이므로 리스크 헌법의 손절은 반드시 이 층에 둔다.
2. **Cloudflare Worker 워치독 — 2026-08-09 구축 완료(페이퍼 버전, 회장 "묻지말고 설정" 지시로 즉시 배포)** — `company3/worker/`, 라이브: `https://nada-company3-watchdog.tossneon.workers.dev/status`. 5분 크론으로 BTC/ETH 시세 스냅샷(24h 링버퍼)·전략 상태(MA20 필터, 당일 목표가)·이상 징후(1시간 -5% 급락, 전일 대비 -10%, API 오류)를 KV에 기록한다. 페이퍼 단계라 업비트 공개 API만 쓰고 시크릿이 전혀 없다. Phase 1에서 거래소 키(Worker secret, 금고 경유)로 잔고/미체결/예약주문 점검을 추가한다 — 키는 저장소에 절대 커밋하지 않는다.
3. **정기 Routine(세션 웨이크업)** — 매일 아침 이 세션이 자동으로 깨어나 전략 실행·기록·보고를 수행. 페이퍼 단계(현재)는 일봉 전략이라 **이 층 하나로 충분**하다 — 일 1회, 업비트 일봉 확정 직후(09:05 KST)에 전일 페이퍼 거래를 정산하고 당일 페이퍼 주문을 등록한다.

페이퍼 단계에서 1·2층을 미리 만들지 않는 이유: 계좌·API 키가 없어 만들 수 없고, 일봉 전략 검증에는 필요하지도 않다. 게이트 해제가 보이면 그때 2층(Worker)을 먼저 구축해 페이퍼로 리허설한 뒤 실거래에 투입한다.

## 6. 단계 승격 게이트

| Phase | 상태 | 승격 조건 |
|---|---|---|
| **0. 페이퍼** (현재) | 일일 루틴으로 전략 v2 전진 검증, 실자본 0원 | ① 4주 이상 운영 ② 누적수익 > 0 ③ 리스크 헌법 위반 0건 ④ 백테스트 대비 심한 성과 괴리 없음 |
| **1. 실거래 소액** | 회장 게이트(계좌+권한 범위) 해제 후, 원금 30만원 중 **50%만** 투입 | ① 4주 이상 운영 ② 페이퍼와 유의미한 괴리 없음(슬리피지·체결 확인) ③ 서킷브레이커 무발동 |
| **2. 실거래 전액** | 30만원 전액 + Worker 워치독 완비 | 성과 확인 시 회장 보고 후 증액 논의 |

Phase 0→1 전환은 어떤 경우에도 [실거래 확인 게이트](README.md#️-실거래-확인-게이트-가장-중요한-제약)(회장의 계좌 개설 + 권한 범위 확정)를 전제로 한다 — 페이퍼 성적이 아무리 좋아도 게이트를 건너뛰지 않는다.

## 7. 기록과 정직성

- 모든 페이퍼/실거래 기록은 `execution/paper/`(로그)·`execution/`(리뷰 문서)에 남긴다. **좋은 결과든 나쁜 결과든 동일한 형식으로** — 손실 주간 리뷰를 건너뛰는 순간 이 모드는 죽은 문서가 된다.
- 성과 보고에 "~할 뻔했다", "필터만 아니었으면" 류의 서사 금지. 숫자와 규칙 준수 여부만 보고한다.
- 전략·파라미터 변경 이력은 이 문서에 날짜와 함께 누적 기록한다.
