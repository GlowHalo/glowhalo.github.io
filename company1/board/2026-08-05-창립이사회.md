## 각 임원 결론 요약

### CSO (전략) — 시장성 관점
4개 후보 검토: ① circle-heroes 본격 사업화 ② checknote 마이크로 SaaS화 ③ dividend-passbook 유료 투자 유틸 ④ "1인+AI 임원진" 자체를 콘텐츠화하는 메타 사업.
**추천: ① circle-heroes.** 이유 — 수익화 배선이 이미 살아있고, 한계비용이 구조적으로 낮으며, 팀의 실제 관심과 시간이 이미 이 프로젝트에 쏠려 있음. 세컨드 베팅으로 ③ dividend-passbook(결제 전환 가능성 가장 현실적) 병행을 제안.

### CTO (기술) — 실현가능성 관점
코드베이스를 직접 확인. circle-heroes는 Firebase 클라우드 백업, AdSense 배너/보상형 광고, GitHub Actions APK 빌드까지 이미 배선 완료 — 매출까지 남은 일은 "새로 만들기"가 아니라 "이미 짜둔 스위치 켜기" 수준.
반면 kpc-coach-chat은 실제 LLM 연결이 전무한 목업이라, AI 챗봇 확장은 사실상 0에서 시작하는 신규 백엔드 구축임을 지적. LLM 기반 사업은 API 키 노출 금지 원칙상 서버리스 프록시가 반드시 필요하고 사용량 종속 변동비 리스크도 있음.
**추천: circle-heroes 고도화 + Play Store 정식 출시.**

### CMO (그로스) — 수익화 관점
코드 확인 결과 `AD_BANNER_SLOT_ID`가 비어있어 **지금 상태로는 트래픽이 와도 배너 광고가 안 뜨는 상태**를 발견. AdSense 사이트 심사 상태 확인 필요, 애널리틱스(GA4 등) 전무도 지적.
방치형 RPG 커뮤니티(디시/루리웹/인벤/네이버카페) 채널과 Play Store 정식 등록을 구체 액션으로 제시.
**추천: circle-heroes.** 근거 — 수익화 배선 90% 완료, 남은 건 5분짜리 설정과 트래픽뿐.

## 만장일치

3개 임원 부서가 독립적으로 검토했음에도 **circle-heroes 상업화**로 결론이 일치. 신뢰도 높은 시그널로 판단해 사장이 이를 [제안서 001](../proposals/001-circle-heroes-상업화-착수.md)로 종합해 회장께 상신.

## 이사회에서 나온 미승인 리스크/기술부채 (참고용)

- circle-heroes 저장소 용량 537MB(.git 254MB 포함) — 자산 계속 늘리면 관리 이슈화 가능
- Firestore 보안규칙이 개방형(`allow read, write: if true`) — 방치형 게임엔 허용 가능한 트레이드오프지만 IAP 확장 시 재검토 필요
- baby-place-registry "링크 자동분류"는 CORS 문제로 서버리스 프록시 없이는 정식 구현 불가
- AI 생성 캐릭터 아트의 저작권/스토어 정책 리스크는 별도 확인 필요
