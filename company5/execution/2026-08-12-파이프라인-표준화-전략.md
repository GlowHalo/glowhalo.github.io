# 2026-08-12 — 단어 교체 반영 + 제작 파이프라인 전략(회장 제안 검토)

## 1. 단어 교체 즉시 반영 (Notion 갱신 완료)

| 회차 | 기존 | 변경 | 사유 |
|---|---|---|---|
| ㅡ | 으뜼(오타) | **으뜸** | 오타 수정 |
| ㅝ | 훠궈(푸드트럭) | **워낭**(농장트럭 재배정) | 회장 지시로 교체. "훠궈"는 특정 외래 음식명이라 애매했음. "워낭"(소·말 목에 다는 방울, 표준어·순우리말·열린음절)으로 교체 — 이미 있는 워터파크/워터슬라이드/워밍업과도 안 겹치고, 농장 동물 비주얼이라 유아 눈높이에 더 맞음 |
| ㅙ | 쇄골(신체부위테마) | **쐐기벌레**(곤충트럭 재배정) | 회장 지시("대체 가능하면 교체, 어려우면 재검토")에 따라 대체 성공. "쇄골"은 해부학 용어라 4세에 부적합했음. "쐐기벌레"(ㅆ+ㅙ, 열린음절, 표준어)는 곤충이라 시각적으로 친숙하고, 같은 회차의 "왜가리"(새)·"돼지"(농장동물)와도 겹치지 않음(R규칙: 장면 혼동 방지) |

세 건 모두 Notion 에피소드 트래커에 반영 완료. 이견 있으시면 언제든 다시 바꾸겠습니다.

## 2. "ㅏ부터 모든 영상 표준화" — 작업 정의

현재 12개 회차 중 O규칙(열린음절)·Q규칙(표준어)·R규칙(장면혼동방지) 위반이 이미 3건(ㅑ 2건 기지정, ㅙ·ㅝ 이번 건) 발견된 걸 보면, 나머지도 재검증이 필요합니다. **표준화 감사 결과**(현재 "기획" 단계 회차 전수 재확인):

| 회차 | O/Q/R 규칙 | 비고 |
|---|---|---|
| ㅗ (오이·오리·오토바이·오징어·오뚝이) | ✅ 통과 | |
| ㅛ (요리·요가·요트·요요·요정) | ✅ 통과 | |
| ㅜ (우유·우산·우주·우체통·우물) | ✅ 통과 | |
| ㅡ (으뜸·으샤으샤·으르렁·으앙·으쓱) | ✅ 통과(오타만 수정) | |
| ㅣ (이야기·이불·이슬·이름·이마) | ✅ 통과 | |
| ㅒ | ⚠️ 미배정 | 차량·단어 자체가 "TBD" — 별도 결정 필요(문의 예정) |

**"ㅏ부터 모든 영상 표준화"**는 두 갈래로 해석해 둘 다 진행하겠습니다:
1. **콘텐츠 표준화**(제가 지금 할 수 있음) — 이미 기획된 단어·차량이 최신 확정 규칙(O/Q/R, 다섯친구찾기 템플릿 등)을 지키는지 전 회차 재검증. 위 표가 1차 결과. ㅒ만 남았습니다.
2. **파일 표준화**(회장 제안 파이프라인의 "너 표준화" 단계) — 아래 3번 참고, 이건 새 도구를 먼저 만들어야 합니다.

## 3. 제안하신 파이프라인 검토

> 기획 → Vrew생성 → **너(라온) 표준화**(쉼 구간 등 기존내용 정비) → Vrew_최종파일 생성 → **나(회장) 검수 및 영상생성** → **너(라온) 유튜브 업로드**

단계별로 "누가 할 수 있는가"를 다시 확인했습니다:

| 단계 | 담당 | 지금 가능? |
|---|---|---|
| ① 기획 | 라온 | ✅ 이미 하고 있음 |
| ② Vrew 1차 생성(대본 붙여넣기→AI 이미지·TTS 생성) | **회장(필수)** | Vrew는 공식 API/CLI가 없고(공식 답변 확인됨), 이미지·TTS 생성은 회장 계정에 물린 유료 크레딧 기능이라 원격 대체 불가 — 지난 검토와 결론 동일 |
| ③ 라온 표준화(무음삽입 등 파일 정비) | 라온 | ⚠️ **기술적으로는 가능, 지금 바로는 안 됨** — 아래 참고 |
| ④ Vrew 최종파일 생성 | 라온 | ③의 산출물 |
| ⑤ 검수+영상 내보내기(렌더링) | **회장(필수)** | 실제 화면 확인(무서운 요소 없는지 등 V규칙)과 크레딧/렌더링 소모가 걸린 단계라 사람 확인 필요 |
| ⑥ 유튜브 업로드 | 라온 | ⚠️ **지금은 안 됨** — 아래 참고 |

**결론: 이 6단계 구조 자체는 타당합니다.** 회장님 부담이 "Vrew 1차 생성 + 최종 검수·렌더링" 두 곳으로 줄어드는 구조라 지금보다 훨씬 낫습니다. 다만 ③·⑥ 두 곳은 새로 만들어야 하는 도구라 바로는 못 합니다 — 각각 뭐가 필요한지 정리했습니다.

### ③ "라온 표준화" — 필요한 것 2가지
1. **`.vrew` 파일을 라온이 받고 다시 돌려줄 경로.** 이 세션은 클라우드라 회장님 PC 파일에 직접 접근이 안 됩니다. 이미 연결된 **Google Drive**로 폴더 하나를 공유해주시면, 회장님이 Vrew에서 만든 `.vrew` 파일을 그 폴더에 올리고 → 제가 받아서 정비 → 완성본을 같은 폴더에 다시 올리는 식으로 왕복 가능합니다. (제안 폴더명: `company5-vrew-작업함` 같은 식 — 편하실 대로 정해주세요)
2. **정비 로직 자체를 지금 세션에서 재현 가능한 형태로 이식.** 세팅값 문서에 `.vrew` 구조(zip+json, 무결성 해시, 무음 3종 세트 등)가 실측 검증까지 끝난 사양으로 다 적혀 있어서, `inject-pause.ps1`(PowerShell)과 같은 로직을 제가 Python으로 새로 짜면 이 세션에서 그대로 돌릴 수 있습니다. **다만 첫 실행은 반드시 사본으로 테스트하고, 회장님이 원본을 따로 보관하시는 걸 전제로** 진행하겠습니다 — 파일이 깨지면 이미 쓴 이미지·TTS 크레딧이 날아가는 되돌리기 어려운 손실이라서요.

### ⑥ "유튜브 업로드" — 필요한 것
- **YouTube Data API 인증정보가 금고에 아직 없습니다** (확인 완료). 새로 만들어야 합니다: Google Cloud 프로젝트 생성 → YouTube Data API v3 활성화 → OAuth 클라이언트 발급 → 그 채널 계정으로 최초 1회 동의(로그인) — 이 마지막 "채널 계정으로 로그인해서 동의" 부분만 회장님(또는 그 계정 소유자)이 클릭 한 번 해주셔야 합니다. 나머지(프로젝트 생성, API 활성화, 클라이언트 발급, 이후 자동 업로드)는 제가 다 처리 가능합니다.
- **먼저 확인 필요**: "몬스터트럭 파닉스" 유튜브 채널이 금고의 자동화 전용 구글 계정(`google_login_email`)소속인가요, 아니면 회장님 개인 구글 계정 소속인가요? 전자면 제가 계정 로그인부터 동의까지 전부 자체 처리 가능하고, 후자면 마지막 동의 클릭만 회장님이 해주시면 됩니다.
