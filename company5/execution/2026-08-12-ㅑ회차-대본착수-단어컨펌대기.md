# 2026-08-12 — ㅑ회차 대본 착수: 학습단어 회장 컨펌 대기

## 배경
`git pull` 최신화 후 ㅑ회차 대본을 이어서 쓰려고 Notion 원본(에피소드 트래커 `ㅑ` 페이지, ⚙️ 시리즈 세팅값)을 재확인했다.

## 발견 — ㅑ회차는 "미착수"가 아니라 "이전 규칙 기준 초안"이 이미 있었음
`company5/README.md`엔 "ㅑ회차는 대본 미착수"로 적혀 있었지만, 실제 Notion `ㅑ` 페이지엔 이미 **구버전 34~38줄 초안**(반복+따라하기+복습 구조, "다섯 친구 찾기+카운트" 템플릿 도입 이전 버전)이 올라가 있었다. 상태값도 "대본작성"(기획 아님).

문제는 이 초안이 **이후 확정된 규칙 두 가지를 위반**하고 있다는 것 — 그래서 트래커가 "완료"가 아니라 "대본작성" 중간 상태로 남아있던 것으로 보인다:
- **O규칙(2026-07-17 확정, 열린 음절)**: "양"(ㅇ+ㅑ+ㅇ, 닫힌 음절) — 세팅값 문서에 ㅑ회차 예시로 **"양 ❌ → 야자수로 교체"**가 이미 명시돼 있음.
- **Q규칙(표준어)**: "야옹이"(구어체 애칭) — 세팅값 문서에 **"야옹이 ❌ → 야옹(표준 의성어) ✅"**로 이미 명시돼 있음.
- R규칙(장면 혼동 방지) 예시도 "야옹(나무) vs 야자수(바닷가 야자수) — 둘 다 나무라 구분 필요"로, 이 두 교체 단어가 이미 세팅값 문서 안에 못박혀 있었다.

즉 5개 단어 중 3개(야구·야채·야호)는 기존 등장차량 배정 그대로 유효하고, 2개(양→야자수, 야옹이→야옹)는 이미 세팅값 문서에 교체 방향까지 정해져 있었다.

## 추천 단어 (P규칙: 대본 전 회장 컨펌 필수)

**추천 5개** (기존 등장차량 배정 최대한 유지, 세팅값 문서 확정 교체만 반영):

| 단어 | 등장차량 | 비고 |
|---|---|---|
| 야구 | 몬스터 야구트럭 | 기존 그대로, 문제없음 |
| 야채 | 몬스터 야채트럭 | 기존 그대로, 문제없음 |
| 야자수 | (기존 "농장트럭(양)" → **몬스터 해변트럭**으로 재배정 제안) | O규칙 위반 교체 확정분 |
| 야옹 | 몬스터 소방차 | Q규칙 위반 교체 확정분("야옹이"→표준어) |
| 야호 | 몬스터 산악트럭 | 기존 그대로, 문제없음 |

**대체 5개** (모두 표준어·열린음절 조건 통과, 다만 4세 대상으로는 추천안보다 다소 추상적):

| 단어 | 비고 |
|---|---|
| 야영 | 캠핑 테마 트럭과 잘 어울림 |
| 야시장 | 포장마차/푸드트럭 테마 |
| 야식 | 푸드트럭 테마 |
| 야광 | 몬스터트럭 사이렌·조명 컨셉과 시각적으로 잘 맞음(반짝이는 빛) |
| 야자열매 | 야자수 대체용 — 코코넛 열매 단독 강조판 |

※ ㅑ로 시작하는 표준어·열린음절 단어 자체가 한글에서 유독 적어(대부분 "양"류처럼 받침이 붙음), 대체안 5개 모두 추천안보다 아이 눈높이 구체성이 다소 떨어진다는 점은 미리 알린다.

## 템플릿 선택 (추가 확인 필요)
- Notion 세팅값 문서 "작업 순서" 상 ㅑ는 2번째 회차(ㅏ→ㅑ→ㅓ→**ㅕ**...)라, "다섯 친구 찾기+카운트" 템플릿은 원래 "4.여부터 적용"으로 명시돼 있어 엄밀히는 ㅑ에 적용 대상이 아니다.
- 다만 ㅑ 대본이 아직 확정·업로드되지 않은 상태이므로, 라온 판단으로는 **새 템플릿을 소급 적용하는 게 낫다고 본다** — 이야기 재미 개선 목적에 부합하고 제작비 증가 0(34줄 골격 그대로, 인트로/마무리 문구만 교체). 이견 있으면 알려주시면 기존 ㅏ회차 방식(반복+따라하기+복습)으로 진행하겠다.
